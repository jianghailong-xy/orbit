title: 任务列表

---

[Tasks](orbit:/tasks) 显示不属于任何项目的任务。项目中的任务在项目页面上；标题下的说明会链接过去。

## 选择显示什么

页面标题是一个菜单：**All tasks**、**No list**，或你的某个列表。列表分为 **Task List** 和（完成后的）**Completed**。

列表是一组相关任务，由一个会话掌控。列表由 Agent 创建：让一个会话把工作整理成列表，它会先给你看一张卡片。在列表页面上，**Steering session ›** 打开掌控该列表的对话。

## 筛选和搜索

- 带数量的标签页：**All**、**Open**、**Ready**、**Running**、**Failed**、**Done**。
- **Tasks** / **Batches** 在单个任务和它们创建时所属的批次之间切换。
- **Search tasks** 和 **Labels** 进一步缩小列表。

## 一次操作多个

选择任务会出现批量操作栏：**Run**、**Stop**、**Set assignee**、**Delete**，以及用于取消选择的 **Clear**。

## 任务自己的页面

打开任务可以看到它的描述、完成定义、运行过它的会话、证据和评论。

完整指南：[Runner CLI: tasks and task lists](../../runner-cli.md#tasks-and-task-lists)。
