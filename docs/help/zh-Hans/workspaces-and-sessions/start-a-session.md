---
title: 启动会话
summary: 打开工作区，按 New session，描述你想完成的事。
---

会话是在工作区内与 Agent 的一次对话。对话记录保留每条消息、Agent 的每次工具调用及其结果。

## 启动

1. 从侧边栏的 **Workspaces** 打开一个工作区。
2. 按 **New session**。在已安装的应用中，Mac 上的快捷键是 ⌘N，其他平台是 Ctrl N。
3. 发送前检查输入框：它显示会话所用的**引擎和模型**、effort 以及**权限模式**。每一项都可以按会话更改。
4. 描述任务并发送。

会话在工作区的机器上运行。Agent 工作时，页头显示 **Running**。回合结束时显示 **Waiting for your reply**：会话并未关闭，你的下一条消息会带着它已经知道的一切继续。

## 阅读一个回合

- **Worked for …** 是回合的摘要行。下面是 Agent 的思考和工具调用，默认折叠。
- 展开一行工具调用，可以看到它的确切输入和输出。
- 对话记录中的审批卡片表示 Agent 正在等你。参见 [审批与权限模式](orbit:/help/workspaces-and-sessions/approvals-and-permission-modes)。

## 保持列表整洁

会话列表有三个视图：**Open**、**Completed** 和 **Trash**。会话会一直留在 Open 下，直到你把它标记完成或移到回收站。回收站中的会话会在 30 天后删除；打开它并按 **Restore to Open** 即可恢复。
