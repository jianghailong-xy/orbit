会话的权限模式决定 Agent 可以在无人参与时做什么。你在输入框里选择它；**Settings → General → Default permission mode** 设置新会话开始时使用的模式。

## 模式

| 模式 | 会发生什么 |
| --- | --- |
| **Default** | Agent 在执行尚未被允许的命令前询问。 |
| **Accept Edits** | 文件编辑直接运行；其他命令仍会询问。 |
| **Plan** | Agent 只阅读并制定计划。在你批准计划之前，它不会改动任何东西。 |
| **Auto** | Agent 自己的工具调用在工作区内直接运行，不再询问。 |
| **Don't Ask** | 不询问任何人：任何尚未被允许的操作都会被拒绝。 |
| **Bypass** | 跳过所有检查。 |

并非每个引擎都支持每种模式。当所选模式无法按原样执行时，选择器会在旁边说明，例如“unavailable on a root runner, runs as Auto”。那条说明才是会话真正做的事。

对于必须执行命令的无人值守工作，使用 **Auto**。**Don't Ask** 会拒绝任何无人允许的命令。

## 回答审批卡片

当 Agent 需要你时，当前回合会暂停，卡片显示工具及其确切输入。

- **Approve**（回车）允许这一次调用，回合继续。
- **Always allow …**（Mac 上 ⌘ + Enter，其他平台 Ctrl + Enter）为类似调用记住一条规则，在此处以及该工作区的其他会话中生效。你可以在工作区设置里撤销它。
- **Reject** 拒绝这次调用并告知 Agent，Agent 可以换一种方式尝试。

计划卡片则显示 **Approve & run** 和 **Keep planning**。

卡片按从旧到新的顺序回答：回车始终属于你可以回答的最旧卡片。如果回合已经结束，卡片按钮会被禁用；请改为发送新消息。

## Orbit 自己显示的卡片

有些操作在任何模式下都会询问你：创建任务或项目、连接供应商、更换 Agent。这些卡片来自 Orbit，而不是引擎。
