iOS 系统

  • 不新造外观：和 Background processes 同一张浮起卡（8pt 圆角、4% 底、发丝边、30pt 行），不用 .bar 材质。
  • 字号只用现成 token：标题 footnote semibold，计数 caption2 secondary；图标 checkmark.square，Orbit 链接卡片里任务用的就是它。
  • 点行 = 系统 push 到任务详情；展开列表有上限、里面滚，不把对话挤没。

Orbit 一致性

  • 状态词和颜色 = 任务列表的 TaskStatusPill，同一个任务在哪都是同一个词。
  • 计数句全是现成句子：N running（Background）、N failed（后台作业）、4/8 done（Tasks 标签进度）。
  • 1 条时写名字、展开底部 View all in Tasks ›——照 Watching 条（Manage in Watches ›）。标题对上任务详情的 Created from ‹会话›。

协调性

  • 三端同一顺序、同一文案（web WorkspaceView 与原生 ConsoleView），两种产出（任务、代码）挨着。
  • 被接替的任务显示接替者（它的状态 + Replaces ‹原任务›），计数也按它算——胶囊数和计数句对得上，不会假红。
  • 待确认 / 被拒的提案不进这行（在确认卡和 Needs you 里）；项目会话多一个 Open project ›，项目全貌留给项目页。
