工作区排序 · Web 侧边栏（P0）

两处改动：工作区上面加一个和 Projects 一样的 Workspaces 标题；顺序只能在编辑态改（悬停标题点 Edit，拖完点 Done），平时行拖不动。⌘1–9、⌘↑/⌘↓ 和默认打开的工作区都跟着这个顺序走。工作区行照抄你的截图；Projects 只画了折叠后的标题，数量是示意。

什么时候顺序和 ⌘N 会变

发生了什么顺序 / ⌘N
上线当天不变：迁移时按现在显示的顺序给每个工作区写好位置
不在编辑态不变：行拖不动，点击照常打开
在编辑态拖动每次松手就保存，⌘N 按新顺序重排
新建工作区放在最后，已有的 ⌘N 不变
删除工作区后面的依次上移一位
机器离线、会话在跑、有事等你位置不变，只改图标和角标
在 Runners 页拖机器只改 Runners 页，不再影响侧边栏
保存失败恢复原来的顺序，提示 Reorder failed（和 Runners 页一样）

工作区排序 · macOS 和 iOS（P1）

原生端读同一份顺序，下面显示的都是 Web ④ 的结果；三端都只有编辑态才能移动。macOS 去掉机器小标题，悬停 Workspaces 出现 Edit；iOS 在 Workspaces 标题右边加 Edit。macOS 每行的第二行（引擎 · 目录）是示意数据。
