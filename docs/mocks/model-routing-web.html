任务智能选择模型 · web 效果图

改动集中在三个地方：Agent 设置页多一个开关；任务详情多一个「难度」字段、运行列表写明每次用了什么模型以及为什么； 任务会话的输入框上，模型标签标出「这是智能选的」。没开启智能选择的 Agent，界面和今天一样（只多一行影子提示）。 界面文案沿用现在的英文，说明用中文。

虚线框 = 改动的地方 P5= 最后一期（跨引擎）才出现

1 · Agent 设置页：开关只能人来开

放在「Worktree isolation」下面，同一种 SettingRow。默认关闭。只有用户 API 能改，agent_update 改不了 —— 这是一个会影响花费的开关，不让 agent 自己打开。

2 · 任务详情 · Details：多一个「Difficulty」

难度由 coordinator 建任务时标（task_create 的 difficulty + 理由），人也可以在这里改。 Assignee 开了智能选择时，Model 的占位文字从「Provider default」变成「Smart selection」；在这里选定一个模型就是 pin，优先于路由。

3 · 任务详情 · Runs：每次运行用了什么、为什么

每一行副标题加上「模型 · effort · 档位」。档位标签 ✦M 是智能选的，↑ 表示因为上次失败升了一档。点开一行的档位标签，展开「为什么」。 没开智能选择的 Agent 也会显示一行紫色的影子提示：「如果开了会选什么」，帮你决定要不要开。

4 · 任务会话的输入框：模型标签标出「智能选的」

只在「由任务派发、且模型是路由选的」会话里变样：标签换成浅蓝底 + ✦。点开下拉，顶上一段说明为什么是它； 在这里换模型只影响这一次运行（就是今天的改配置），任务下一次运行仍然重新选 —— 想固定，去任务上 pin。
