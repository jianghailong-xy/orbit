iPhone / iPad 的列表行没有左侧状态图标（ChatGPT 式列表），状态只靠两处说：标题行尾部那格小标记（转圈 = 在干活、琥珀点 = 等你、红点 = 失败、 呼吸的终端 = 后台作业在跑）和第二行文字。这个会话今天在 iOS 上：尾部那格什么都没有，第二行是 Watching 1 target · 0 met——没说错，但看不出在等谁， 也和 web / macOS 的眼睛对不上。另外它若同时留着一个后台作业，尾部会呼吸终端图标，而 macOS 同一行画的是眼睛（契约 §9.2：watch 不借后台进程的图标）。
