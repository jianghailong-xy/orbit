#决定
D1 发信通道Resend HTTP API（POST https://api.resend.com/emails，带 Idempotency-Key 防重发）
D2 配置放哪管理后台 Admin → Email 页：API key 加密存库，保存即生效，可当场发测试邮件
D3 管理员建的账号也发，写明 "{admin} added you" 和登录方式
D4 失败处理自动重试 3 次 + Users 行内灰字 + ⋯ 菜单手动重发

落地（按代价排）

  1. 模板 + 渲染函数（纯函数；HTML/纯文本快照测试，覆盖 3 种登录方式 × 托管 runner 开/关）—— 小
  2. Resend 客户端 + Email 设置页 + 测试邮件（email_settings 迁移、加密、API、web 页；fetch 与结果分类；self-hosting 文档）—— 中
  3. outbox + worker：email_outbox 迁移，建账号事务内入队，SKIP LOCKED 发送、重试、Activity；pg spec 证明并发首登只一行、未配置记 SKIPPED、两个 worker 不重复发 —— 中
  4. Users 行失败提示 + 重发菜单 —— 小
