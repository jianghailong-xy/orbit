原生端规则相同：登录成功、账号出现在 Accounts 列表里、卡片里改过的名字已存上，卡片就收回成「Add Account」那一行；还在输入框里打字时，等按 Return 或点到别处。以后改名用长按（iOS）/ 右键（macOS）菜单里的 Rename…，和已上线的一样。失败或取消时卡片留着，Close 照旧。
  • 1完成后，一个名字只留一个编辑处：面板里的输入框只在添加过程中用，账号出现在列表里以后，改名都用那一行的铅笔（web）或 Rename…（macOS / iOS）。
  • 2不需要关闭按钮：成功的那一刻面板自己收起；没成功的时候（失败、取消、超时）面板里本来就有 Cancel。
  • 3收起的条件：登录成功、runner 的上报里已经有这个新账号、面板里的名字已经存上（没改过就不用存）。少一样就不收，名字不会丢。
  • 4不打断输入：输入框还有焦点时先不收，按回车或点别处保存后再收。
  • 5只在成功时收起，失败或取消时面板和现在完全一样。
  • 6备选：不自动收起，只在完成那一行加 Done。选它的话，① 的重复会一直留到点 Done。
  • 7macOS / iOS 同一套规则，卡片收回成「Add Account」那一行，不再需要点 Close。
