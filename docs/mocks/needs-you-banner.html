“Needs you” banner — one signal, one tap

A session blocked on an approval is stopped work, not an unread message. So: one amber bar that names where it is and teleports you there — not a badge trail you have to hunt down.

3 · Spec

Height36pt — 9pt padding above/below a single line
BackgroundColor.orange.opacity(0.12) light · 0.20 dark
Dot7pt solid .orange — the exact dot SessionLiveIndicator already uses for “needs you”, so it’s the same word in the same language
Text.primary + .orbitControl — never a bare system(size:), the font-tokens CI job hard-fails on it
Chevron.tertiary + .orbitMeta
Separatorshairline below only; the nav bar draws its own above
Motionnone — no pulse, no spring. It can sit there for hours while the transcript beneath it is being read
Hit targetwhole bar, .contentShape(Rectangle())
VoiceOver“wikova-develop needs you, button”
Copy{workspace} needs you / {n} sessions need you — English (repo standard), and “needs you” is already the product’s word for this state (SessionGroups.needsYou, web .tp-count.needs-you, menu bar “2 needs you”)
Excludesthe session you’re looking at — its approval card is already inline at the tail of the transcript
Mountone shared .needsYouBanner() via .safeAreaInset(edge:.top) on the console + the session list. Wrapping CompactSections instead would put it above the nav bar
Dataalready on the client — the cross-agent Open snapshot carries pendingApprovals per row, same rule the server’s GET /sessions/counts uses. No new endpoint

4 · Explicitly not building

  • Dot on the hamburger. Second telling of one fact; “something’s wrong somewhere” with no destination is pure anxiety.
  • Needs-you roll-up on collapsed runner rows. Only needed if the user has to find it themselves — they don’t anymore.
  • A “Needs you” section in the drawer. Still requires opening the drawer, and duplicates Recents.
  • A toast. Approvals persist for hours; a transient is missable by design.
  • Red. Red is failure in this app already (SessionLiveIndicator error dot). Amber is “waiting on a human”.
