“Project started” — drawn as a card, not as your message

Today the message Orbit sends the coordinator when a project is started (by Start the project or the Automatic switch) is prose written for the agent, and the transcript draws it as a bubble you typed — a whole phone screen. Proposed: the control plane records the facts beside that turn (the way it already does for an exception item, openItemDelivery), and web, iOS and macOS draw a compact card from them. The agent still reads the same words; the reader gets them one tap away.

Rules the card follows
  • Two starts, one card. Start the project → “Project started” + chip Criteria confirmed; the Automatic switch → “Project switched on” + chip Automatic on. The facts are a snapshot of when the coordinator was told, like the exception-item card's.
  • The tasks list only what waits on the coordinator (autoRunWhenReady=false): three shown, “Show N more” for the rest. None waiting → one line: “Every open task starts on its own.”
  • Nothing is dropped. The words the agent read fold under “What the coordinator was told”.
  • Queued (a turn is still running): the same card with a dashed border and the queue's own “Queued · Cancel” line, as the exception-item card does.
  • Older messages stay bubbles. The one sent at 06:14 today carries no card payload, so it is drawn as it is now.
  • Web, iOS and macOS share every word (a copy-parity test, as for the exception-item card).
