规则

  1. 进条的是：这个会话自己发出的、state = PENDING 的 owner request，且对话里正画着它的卡（useSessionOwnerRequestInserts 同一份数据），与证据行“有卡才指”的规则一致。
  2. 条上的字 = request.title（卡片标题原文），后面是等了多久（createdAt）。不加 kind 标签，条是一行。
  3. 按下 = 导航到 #owner-request-<id>，沿用 WAITING_CARD_GAP + 松开尾部钉住的落点；不在条上提供 Done / 回答按钮（条只指路，见 DecisionRail 注释）。
  4. 箭头 ↑/↓ 按卡片相对视口的实测位置给，和例外卡同一测法。
  5. 请求在别处结束（手机、Waiting on you 页）→ 下一次读到就从条上消失；条空了整条不画。
  6. 手机端同样上条（证据的 “waiting on you” 折叠组在手机上隐藏，那是另一回事，不受影响）。
