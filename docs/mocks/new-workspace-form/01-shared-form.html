New workspace · 01 设置卡和 Settings → New workspace 共用一个表单（含 From GitHub）

所有者 11-20 的两条要求：① Settings 里的 New workspace 和「机器注册好、还没有 workspace」时的设置卡共用一个页面；② 要支持 GitHub。 设置卡（MachineSetupCard）已经有 From GitHub，Settings 那张表单（NewWorkspacePage）是更早的写法，没跟上。 两边都调同一个 POST /workspaces（newFolder | github | workDir 三选一），服务端不用改，这是纯客户端的事。 帧是手写 DOM，但引的是 app 自己的样式表（index.css、ui/*.css、MachineSetupCard.css、Settings.css），类名照抄组件； 历史导入那段的单选框是示意（b- 前缀）。界面文案全部英文，黄底是要新加或改动的英文句子，其余是今天的原文。机器 orbit@austin，home 是 /Users/austin。
