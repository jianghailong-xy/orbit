规则 · 改动 · 已定 / 还待你定

规则

  1. 设置卡只问一件事：文件夹。登录不再是建 workspace 的前提（A）。
  2. 按钮 = 建 workspace + 跳到它的新会话页。按钮在文件夹被机器检查通过前不可点（同今天）。
  3. 建出来的 workspace 和 10-31 规则一致：名字取文件夹名、重名加「 2」、隔离关、新文件夹 autoCreateWorkDir（第一个会话被领取时由机器建）。
  4. 点了没发消息就离开：workspace 留着，就是普通 workspace（B）。
  5. 名字以服务端为准，在新会话页的 Created workspace 行里说（C）。
  6. 新会话页的引擎：沿用机器上能直接跑的那个（已登录或已配 key）；都不能跑时选第一个已装的，hero 下显示 Not signed in · Sign in。
  7. 设置卡这一页不再收消息：输入框置灰（「消息先等着」这套 held message 删掉，见待定 F）。
  8. 失败不跳页、不留半个 workspace（一个请求一个事务）。
  9. 四端同一批（D）；文案全英文，三端共用一份 copy。

E. 新会话页上引擎没登录，Sign in 在哪做？原地展开现有的 RunnerSignIn 卡（就是设置卡第 2 步原样搬过来），登录完收起，不离开页面。沿用今天的 Fix it：跳到机器设置页的引擎那一行登录，再自己回来。零新界面，但新用户第一次要绕一圈。A推荐
F. 设置卡页上还没选文件夹就打字发送？不收：输入框置灰，占位写 Pick a folder first。「消息先等着」那套（held message、Withdraw、Waiting for…）整个删掉，少一条路。保留：消息先等着，点建的同时把它一起发出去，跳到那个会话。今天的代码能复用，但多一种状态要四端都维护。A推荐
