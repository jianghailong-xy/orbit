Managed runner without a “Default” workspace · its setup card before it is up

Owner 2026-11-16: the managed runner no longer creates a Default workspace; it is a machine with no workspace, set up from the same card as any other (option A). Today that card turns everything off while the machine is offline, and a managed runner is usually still being set up or asleep. In the proposal, a managed runner that is not up still takes a new folder and makes the workspace. Its coding CLI is the one the server names (firstSessionProvider), not a sign-in on the card. The first message wakes it, as sending already does today.
