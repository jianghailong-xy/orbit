  • 1主按钮 = 这类待办要做的下一步，从服务端列出的门里挑（不是新造的门）。次按钮是同一件事的另一种做法（冲突/检查失败：Retry；任务失败：Open task session）。
  • 2看和停降级为文字链接：Open coordinator（去看协调会话）与 Cancel task（停掉任务）。这些都还在，只是不再和主按钮抢注意力；Cancel task 仍要确认才写。
  • 3效果图 5 里的 `Hand to owner` / `View full log` 今天没有对应的门（服务端不给这两个动作：没有「交给 owner」的入口，也没有单独的完整日志接口），所以次按钮取的是今天真实存在的动作。要补这两个门是另一件事，可以另开任务。
