  • 1DONE 之后多出「Integrating」一段：平台把任务 rebase 到集成线，在合并后的树上跑检查。检查失败或冲突直接显示在任务行上，写明谁在处理（这里是协调会话）。
  • 2下游不再笼统写「Blocked」，而是写明「在等哪个前置落地到 project/bg-jobs」。前置落地后自动开工，不再需要手动开工。
  • 3已落地的任务分两种：「On project/bg-jobs」（在项目分支上，还没进 main）和「On main」（已晋升进 main，淡出显示）。
  • 4判据的落地说明分项目分支和 main。原来只有「landed on the default branch」和「no merge receipt either way」两种，现在能看出「做完了、在项目分支上、还没进 main」。
