待你定 · 本稿建议
  1. 字段顺序：Landing check 在 Merge check 前；两者紧邻。是否同意？
  2. 窄屏确认卡用上下堆叠两层信息，不用双列挤压命令。是否同意？
  3. WAITING_BASELINE 增加短标题 Waiting for baseline fix；另两种等待也配短标题，完整服务端 summary 保留。是否接受这三条标题？
  4. 基线卡标题使用 Baseline checks failing on {branch}，不沿用容易误解为任务失败的通用标题。是否同意？
  5. MAIN 线仅显示“不使用”的说明，开始卡片不新增可编辑 Landing check。是否同意？
  6. 开始卡片与确认卡的 timeout 接线需下游扩展现有数据结构；本设计按命令、超时均可编辑画。由实现任务确认现有 proposal 门如何携带完整快照，不降低 §11.3 的逐字比对要求。
