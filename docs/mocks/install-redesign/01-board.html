设计原则

01 · WIZARD, NOT REPORT

安装器是向导，不是诊断报告

每一步先说「现在做什么」，再给一行结果。诊断信息留给 orbit doctor。

02 · SHOW WHAT YOU CAN DO NOW

只保留现在要做的决定

首屏只有两个决定：名字和审批；引擎状态、安装命令和诊断都交给 Orbit 机器页和 orbit doctor。

03 · THREE STATES

状态词只有三种

Orbit 机器页和 orbit doctor 里：ready / needs sign-in / 不出现。红色只留给真正的失败。

04 · WAITING IS UI

等待也是一个界面

链接、核对码、剩余时间、取消方式、结果。不能只留一行 Waiting...。

05 · DECLARE SIDE EFFECTS

副作用先声明再执行

后台服务、sudo、开机自启、自动安装软件，都要在执行前说清，并给出撤销命令。

06 · END WITH A RECEIPT

结束要有回执

机器名、在线状态、下一步入口、三条常用命令。不要停在日志命令上。

落地范围

改哪里

  • src/web/public/install.sh — 下载只留一行、开场说明自动安装、共享二进制提示降级为 dim、交接给 register。
  • src/runner-go/main.go — 名字提示、审批/等待/批准文案、删除引擎步骤与授权提问、默认 AutoInstallEngines=true、回执。
  • src/runner-go/doctor.go — 首屏不再调用；orbit doctor 保留完整清单与状态词。
  • src/runner-go/service.go — 服务安装前声明、完成后一行结果、失败时给可执行的修复。
  • src/web/src/pages/EnrollPage.tsx — 已重做；只需让「核对码」和批准后的「Open machine」与终端文案互相呼应。
  • src/apiserver/src/runner-api/runner-api.controller.ts#devicePoll（可选）— 返回审批账号和机器公开 id，回执里就能写账号与精确机器页链接；不返回也能用 /infrastructure。

不做什么

  • 不引入 TUI 依赖。二进制目前零依赖；ANSI 颜色 + \r 就够，非 TTY 自动退回纯文本。
  • 不在 register 里交互式装/登录引擎。现有的「按需安装 + 网页 RunnerSignIn」已经覆盖，终端不再造第二套。
  • 不把引擎步骤搬回来。状态放在回执和 Orbit 机器页；orbit doctor 保留完整清单。
  • 非交互注册也默认允许自动安装。provisioning 脚本不想装软件时，用 --no-auto-install-engines 关闭；这取代了原来「没有 TTY 就不授权」的默认。
  • CLI 文案保持英文。产品文案规则；本地化留给客户端界面。

验收

  • golden 输出：批准 / 拒绝 / 过期 / 服务失败 / 无引擎，交互与非交互各一份。
  • NO_COLOR 与非 TTY 快照必须仍可读，不出现 ANSI 残留。
  • 默认配置写 autoInstallEngines=true；--no-auto-install-engines 仍能关闭。
  • 手动跑三种环境：headless VPS（SSH）、桌面 macOS、已有引擎的机器。
