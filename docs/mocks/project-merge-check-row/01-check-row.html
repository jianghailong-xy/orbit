合入检查卡：抄「已合入」那一行的样子

现在这张卡（图 ①）讲的是「Orbit 正把这次改动合入 main」，用的是「灰底 + 13pt 蓝标题 + 右侧 checking + chevron」；同一件事做成的样子——时间线里的 Merged into main 行——是「30pt 圆图标 + 17pt 标题 + 右侧时间 + 15pt 明细」。同一件事的两个时刻，一个像设置项，一个像状态行。
推荐图 ②：保留灰底卡，但这一行换成和「已合入」完全同一套排版——圆 tile（蓝环在转）、17pt Merge check、右边放真正在动的那个数（已用时间）、第二行 15pt 灰字写状态和新鲜度。检查通过后卡片消失、时间线里出现 Merged into main：读者看到的是同一条行换了个状态，而不是一张卡换成另一张卡。
要定的两处：是抄「已合入」那一行（②），还是留在合入卡这一族、只把字补齐到和刚定的 Landing 卡一样（③）；灰底卡留不留（图 ④）。
