标题别和抽屉按钮挤在同一块玻璃里

你说的这一条我按字面理解：左上那块玻璃不能同时装着 ☰ 和标题。beta.106 之所以这样，是 iOS 26 自己干的—— 相邻的 leading 项会被并进同一块 platter（第三张图那块右胶囊也是这么来的），不是我们写的。所以「拆开」有两条路：
案 1（推荐）：标题回中间槽（.principal）——它本来就在那儿，只是长名字会被系统夹到左边。给它一个宽度上限就能永远居中， 代价是超过上限截断。你这台 440pt 机上的上限是 158pt：wikova-develop 实测 125.3pt，完整画下、不截断。
案 2（备选）：留在左边，但在 ☰ 和标题之间插一个 ToolbarSpacer，两块玻璃分开。全名永远在，代价是标题永远在左、且这个 API 是 iOS 26 才有的（要加 availability 判断）。
最终选的（这张图里没有）：留在左边、连玻璃都不要——.sharedBackgroundVisibility(.hidden) 把这一项的共享背景关掉， 名字直接画在 bar 上、☰ 保留自己的圆玻璃。模拟器实测（.ios-probe，分支 orbit/ios-title-slot-shots）： orbit 与 wikova-develop 都完整画下，且不再和 ☰ 共用一个 platter。
