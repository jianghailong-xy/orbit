Web 侧边栏 Workspace 行：⋯ / 右键菜单（Configure · Delete workspace…）

现在 web 上删除 workspace 只能走 Infrastructure → 机器 Details → Workspaces 行的 ⋯ 菜单，侧边栏和 workspace 页面都没有入口。方案是在侧边栏每个 workspace 行加一个 ⋯：鼠标悬停时出现在 Ctrl N 的位置，右键整行也打开同一个菜单。删除沿用机器页现有的确认框和文案，服务端（软删除，会话和任务保留）不变。
以下截图都是真实构建的 web 界面（方案代码 + 仓库 UI 测试数据），不是手绘。

①现在悬停 site 只有底色变化，没有任何操作入口
②悬停⋯ 出现在 Ctrl 2 的位置，移开就恢复
③点 ⋯Configure ／ 分隔线 ／ Delete workspace…（红色）
④右键行打开同一个菜单（这里右键的是 scratch）
⑤Delete workspace… → 确认和机器页 Delete 一样的标题、说明和按钮
⑥服务端拒绝时workspace 还是某个项目的 coordinator：错误显示在对话框里，对话框不关
⑦删除后行消失，计数 4→3，Ctrl N 顺延。删的是当前打开的 workspace 时回首页
⑧Configure跳到所属机器页，自动展开这个 workspace 的编辑器并滚到它（新增 ?workspace= 参数，打开后即去掉）
⑨手机抽屉（≤960px）没有悬停，⋯ 常显；和 Workspaces 的 Edit 同一规则
