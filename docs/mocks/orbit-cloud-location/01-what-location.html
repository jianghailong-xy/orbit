“Address / location” of Orbit Cloud — three different things

Orbit Cloud is a machine Orbit runs for you. Between it and Claude there are three places you could call its “location”. Values below are examples.

A · Host / data center

Where the machine physically runs

The server rack / cloud zone the Orbit Cloud container lives on.

e.g. “Tokyo · ap-northeast-1”

Orbit does not record this today.

→
B · Public IP address

The internet address it goes out from

The IP that websites (and Claude) see the traffic coming from.

e.g. 203.0.113.42

Deliberately never stored (privacy rule in the region contract).

→
C · Exit region

Country Claude thinks it's in

Looked up from that IP; decides whether Anthropic serves Claude there.

e.g. “Japan · checked 3 min ago”

Already recorded for every machine.

→

Claude (Anthropic)

Allows or blocks by country. If blocked, Orbit already shows a red note naming C.
