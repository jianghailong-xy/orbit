  1. Runs with 的编辑方式：推荐 Sheet（iOS 惯用，字段多、有子 Sheet）。另一种是像 web 一样原地展开——手机上会把 Activity 推到很远。
  2. 收件人切换：推荐输入框左侧 胶囊 + Menu（不占一行）。另一种是输入框上方的分段控件（和 web 一样，但多占 40pt）。
  3. ⋯ 里的 Mark done：iOS 今天有、web 没有（web 规则「浏览器不提供 Mark done」）。推荐保留（有 wiring 测试钉着，且手动收尾在手机上更常见）；也可以借这次去掉以与 web 一致。
  4. macOS：任务页与 iOS 是同一个 SwiftUI 视图，改了 iOS，Mac 也变成同样顺序。推荐一起改，Mac 上 Sheet 换成 popover/sheet 的 Mac 写法，实现时补一张 Mac 截图给你看，不再单出板子。Android 另出板。
