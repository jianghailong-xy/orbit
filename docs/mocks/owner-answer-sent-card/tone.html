答之前、答之后用颜色分开：答完变成中性灰框

今天，开着的提问卡（等你回答）和答完的 Answered 卡都是蓝色，只是答完的那张淡一点，扫一眼分不出哪张还在等你。建议答之前保持蓝色（等你回答），答之后换成中性灰框 + 绿勾（已经结束的记录）。下面是同一段对话答之前和答之后的真实页面截图（接着「合并成一张卡」的方案 M），数据是样例。

  • 答之前：蓝边框，蓝色标题栏，有选项和 Send answer，表示「等你回答」。这张不改。
  • 今天答完：还是蓝底蓝边，只是整体淡了一点（85% 不透明），和 ① 是同一个色系。
  • 方案 1：白底、灰边框、灰色图标，你选的答案前面是绿勾，View details 照旧是蓝色链接。蓝色只留给还在等你的卡。
  • 方案 2：整张卡变浅绿。分得开，但颜色更抢眼；对话里答过的问题一多，会是一片绿，还会和「完成、合并成功」这类绿色状态混在一起。
  • 为什么推荐灰色：Orbit 里已经有同样的规矩。证据评审卡被决定以后，就变成中性灰框 + 绿勾的回执；撤回的问题卡图标本来也是灰色。答完的问题和它们一样，都是「已经结束的记录」。
  • 排队中的样子不变（虚线 + Queued 那一行），只是底色跟着变成灰框。

深色主题方案 1 在深色下也分得开

  • 落地：只改颜色。Web 是给答完的卡加一个样式（边框、底色、图标颜色，用现成的 --border / --bg-raised / --success-solid）；iOS / macOS / Android 把答完那张卡的底色和边框换成同一组中性色。文字和结构都不变。
  • 撤回的问题（Withdrawn）也用这个灰框，图标本来就是灰色，正好一致。
