Project row — Pause / Resume, and the full action set

The project row in the session list, iPhone (iOS 26 circles). Swipe right holds the one state change the project can take right now (Pause, Resume or Complete) followed by Pin; swipe left stays Move. A full swipe fires nothing. Pause here is the project page's existing Pause project (POST /projects/:id/pause): it stops Orbit starting tasks and merging on its own. Runs already going finish.

Waiting on you

  2. One Resume for both kinds of pause? Drawn: yes. The row picks /resume or /fuse/:episode/resume. A limit resume never raises the limit; the toast says so and links to the project page.
  3. Pause takes the first slot; Complete only appears there once the project has finished. Drawn: yes.
  4. Undo on the Pause toast? Drawn: yes, as Resume. Resume gets no Undo: pausing again is one swipe.
