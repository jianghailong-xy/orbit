能不能搬：规则一览

情况结果原因
正在跑 / 有排队的消息 / 在等审批不能先停下。搬家要等原 runner 收尾提交。
正在结束 / 合并或提交进行中 / 合并修复没处理完 / 等自动重试暂时不能等它做完再试。
空闲，还没结束能，End and Move先结束（原 runner 必须在线），再搬。
已结束 / 已完成（Completed）能—
回收站 / 导入中 / 任务的执行会话 / 项目的协调会话不能回收站先恢复；任务和项目的会话归属由任务、项目决定。
派生出来的子会话能子会话本来就可以建在别的 Workspace。
Claude，同一台 runner能，对话原样接上runner 把对话记录搬到新目录。
Claude，换 runner能，对话重建用 Orbit 存的记录重建：最近约 10 万 token 原样，更早的是摘要。
Codex，同一台 runner能按 thread 接上。
Codex 换 runner；Kimi、OpenCode本期不能对话只存在原机器上 / 续接方式还没验证。
目标 runner 还没升级到支持搬家的版本不能不升级的话，同一台机器搬到另一个仓库时 agent 会继续改旧仓库。
代码改动留在原地留在原仓库这个会话的分支上；新 Workspace 从自己仓库的最新代码新建检出（分支名不变）。
同一台 runner、两个 Workspace 是同一个仓库代码也连着检出原样接上。
