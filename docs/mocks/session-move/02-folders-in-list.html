文件夹在会话列表里怎么呈现

文件夹属于某个 Workspace，排在列表最上面；一个会话最多在一个文件夹里。进了文件夹的会话不再出现在下面的时间分组里，所以文件夹行要替里面的会话报状态：有会话等你时显示琥珀色数字，有会话在跑时显示转圈，和抽屉里 Workspace 行的规则一样。点文件夹行进入单独的文件夹页（方案 B，已选）；方案 A 留作记录。

  • 长按文件夹行：Rename…、Delete Folder…。删文件夹只删“夹子”，里面的会话回到列表，不进回收站。
  • 新建文件夹的入口：Move 面板里的 New Folder…，和右上角 ≡ 菜单里的 New Folder…。
  • 文件夹按名字排序；同一个 Workspace 里不能重名。
  • 按标签筛选或 Group by Tag 时文件夹收起不显示，列表平铺，避免两套分组叠在一起。Trash 也平铺。
