定稿 · runner 满了时，会话列表这一行怎么显示

你选的是 C · 只写大白话：第二行写 Waiting for a free slot，不带时长。右上角的时间从排进队列那一刻开始算（lastTurnAt），所以它本身就是“已经等了多久”。 Web 和 macOS 鼠标悬停在这一行上，会出系统原生的提示框，里面是会话弹框的原话加等待时长；iOS 和 Android 没有悬停提示。Run full、Batch full 的写法完全一样。会话标题和消息都是示例。
