从「Anyone with the link」切回「Only you」就是撤销，会先弹这个确认。「Copy link」一直在，复制的是要登录的那个地址，和公开链接分开。

  • 1Access 下拉换掉「Create share link / Revoke link」两个按钮，开和关是同一个控件的两个值 借鉴 Google Docs「General access」。多账号部署以后可以加第三项「People signed in to this Orbit」，模型不用改。
  • 2Includes 按层勾选，每层都写数量。Overview 锁定不能取消。项目里的「Comments & files」和「Conversations」缩进在「Task pages」下面，关掉 Task pages 它们就一起置灰。
  • 3风险写在选项旁边，不另开警告框。Conversations 永远带一句「Can include command output and file contents.」；一旦勾上，这句变成琥珀色。
  • 4Updates：Live 或 Snapshot。项目和任务默认 Live（给人看进度）。会话也默认 Live，保持现在的行为，但会明说出来；选 Snapshot 就冻结在此刻，可以随时「Update snapshot」借鉴 ChatGPT / Claude。
  • 5Expires 可选 Never、1 day、7 days、30 days。到期自动撤销，清单里留一行「Expired」，可以一键「Share again」借鉴 Notion / Figma。
  • 6访问次数和 Preview。公开接口每次被打开都计一次数。「Preview ↗」用访客身份打开公开页，所有者发出去之前能先看一眼到底露出了什么。
