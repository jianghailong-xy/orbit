5改哪里：没有新界面

服务端改解析；客户端只改「从哪读」，看起来和今天一样。

P0服务端
· 项目任务、协调者、子会话改读锚点（§0 表）
· 「最新一条对话」只算人亲手开的会话（按创建入口打的来源标记，不靠标题）
· workspace 返回值在 lastEngine / lastProvider 旁加 lastModel
· 智能选模型的基线改为锚点
· 任务详情「Runs with」、orbit status 显示与实际开跑一致
规约测试：新开一条 Codex 对话后，项目任务 / 协调者 / 子会话的引擎都不变；你下次开会话预选 Codex + 那个模型。
P1客户端（web · iOS / macOS · Android）
· 新会话草稿的模型改读 lastModel
· 不再读、不再写账号级 defaultModels
· 任务详情「Runs with」读服务端给的锚点
旧版 App 照旧写 defaultModels，服务端照收不报错，只是没人再读。
不做记录在案
· workspace 显式默认、设置页「Default model」、草稿「也用于任务」—— 界面改动非必要
· 账号撞限额时按备选顺序换账号 —— 另立一期
· effort 的来源 —— 不在本次范围
· 遗留列 agent.default_*、workspace.model 的清理 —— 另行处理
