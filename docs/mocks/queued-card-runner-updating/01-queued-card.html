⑤多项排队（建议）：每一项排队都被同一次更新挡住，所以每一项都写 runner updating，包括你自己排队的消息。备选：只在最后一项上写，其余仍是 Queued Cancel。

待你确认的选择（每项都有建议）

  1. 说明放在哪：建议放在被挡住的排队项上（②）；没有任何排队项时，仍按今天的规则挂在最后一条已送达的消息下，或在空会话里显示居中说明页。
  2. 多项排队：建议每一项都写（⑤），不用判断“哪一条”，各端规则一致；备选是只写在最后一项上。
  3. Cancel：建议保留，位置照旧在最右；更新期间取消依然有效（被取消的通知以后会重新投递）。
  4. 弹层文字：建议沿用现有文字 “This message is sent right after.”，卡片上也一样，不为每种卡片另写一句。
适用于所有排队卡片（任务通知、Open item、Task start、后台唤醒、协调者通知、Session 消息等），Web / iOS / macOS / Android 一起改。
