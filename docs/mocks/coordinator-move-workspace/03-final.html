已定（11-11，全部按推荐）

问题定了什么
Move 的项目页入口coordinator 卡片 Workspace 行加 Move…，和会话的 Move 是同一个对话框
旧的、已换下的 coordinator就是普通会话，今天已经能搬，不用改
目标是另一个仓库不拦，确认框照常说改动留在原 Workspace 的分支上
新开的入口⌄ 菜单两项：原来那项不动 + Start a new coordinator in…
Move 搬不动时那一行给 Start new here…，直接到新开的确认
Rebind前端入口去掉，坏掉的卡片换成 Start a new coordinator in…；接口保留
项目的一次性判断会话照旧不能搬（它们是平台为一件事开的）
