1发起卡是通用 MCP 卡：名字 "orbit · bg_run"，摘要是 key=value 原文；bg_run 当场返回 running 回执，所以立刻绿 ✓ 且永远不变——job 后来失败了这里也是 ✓（和 SubAgent 修之前同一个 bug）。
2结束是另一行：画在 Agent 被叫醒的地方，离发起卡可能隔几屏；有新输出（wakeOnOutput）、变安静（wakeOnStall）也各画一行，一个 job 可以有好几行。
3底部托盘看不到 bg_run：Background processes 只列 Claude 自己的后台 shell。
a一张 Job 卡：标题用 description，命令收进展开里；转圈 → 退出码 / killed / quiet，原地变；折叠时露最新 1–2 行输出（失败红）。
b唤醒那一轮不画：结束、新输出、变安静都一样；Agent 读到的内容一字不改，协议不动。和 SubAgent 的决定（11-20）一致。
cbg_run 进托盘：和后台 shell 一个列表，失败红字计数，点一下滚到那张卡——卡在很上面时靠它。
定时唤醒（schedule_wakeup，没有 job）不在这次范围：没有在跑的东西可挂，那一行照旧。
