Documents · Mac app

The Mac app takes the iPhone's screens (01-ios.png) into a window: Documents in the sidebar under Wiki, a Finder-like list with an inspector, sheets for Move and Share link, and Trash and Storage as their own views. It behaves as the web page does (02-web.png); only what is Mac-specific is called out. Frame 4 adds the upload tray with an agent's directory sync (docs/drive-directory-sync-design.md). All names, sessions, sizes and dates are demo data.

What this frame decides

  1. Documents under Wiki in the sidebar, no count (SF Symbol folder; AppSection gets a .files case after .wiki).
  2. Toolbar: New Folder (⇧⌘N), Upload (⌘U), Share Link…, Move to Trash (⌘⌫). Rename is Return on a selected row, as in Finder; Move to… is in the row's context menu and by dragging rows onto a folder.
  3. "Last written by" in both forms (rule 6): with the session, which opens it, or plain "An agent on Orbit Cloud".
  4. Dragging from Finder uploads (files or folders, any size, D3, D12); a row shows its upload in place and resumes after sleep or a lost connection.

Downloading is the way out: the drive is not synced or mounted on the owner's own computer this round.

What this frame decides

  2. Earlier versions of overwritten files sit in their own group (D17). Each row's context menu: Restore, Restore as Copy, Delete Immediately…

The composer's drive picker and reply links on the Mac are the web's (02-web frame 8) in the Mac composer: a Documents button opens the picker as a popover.

What this frame decides

  1. The web's bottom-right tray becomes a toolbar button with a ring of progress while anything is going up, like Safari's downloads. It opens a popover; it goes away once everything is finished and cleared.
  2. An agent's sync is one row, marked Agent sync, with the same words as the web tray (documents-sync-tray board): files that need uploading, the file going up now, and the session that started it. No Pause: only the agent stops a sync.
  3. Details… opens a sheet with the failed paths and their reasons, and Open Datasets. No Retry (S1, one-shot).
  4. Files land in the folder as each one commits, the agent's session as the writer (rule 6). The list refreshes on drive.sync and drive.changed.

Uploads keep going while the window is closed and the app runs; quitting pauses them, and they resume from the parts already sent next launch.
