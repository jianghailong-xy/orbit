This board moves it onto the scale the session console and Tasks already use. It keeps the layout, data and actions as they are; only size, spacing, colour weight and column widths change.

What changes, by mark

  1. Header. No full-width rule; padding 24px like the session column. The title shows the path: “Drive”, or “Drive / Books” inside a folder, with the parent in grey. It replaces the 12px breadcrumb line above the table, so the page names its place once and not three times.
  2. Controls: only Search, New folder and Upload, 34px with 14px text. Upload is tinted like the session list’s New session button, not solid blue. Search is named “Search Drive” (it said “Search all of Files”, an old name).
  3. Tree rows are 34px and 14px, with the same outline folder icons as the app nav. The selected row looks like a selected nav item.
  4. Rows are 48px with 14px names. The table uses fixed column widths: Name takes the remaining space and the other columns stay together on the right, so a wide window no longer opens a gap of about 900px between “Last written by” and Size.
  5. Last written by is grey (text-2), with a small agent glyph in place of the words “Agent in”. The session title turns into a blue underlined link only when you hover the row. Blue is left for selection and actions, as in the session list. The “···” menu also shows only on hover.
  6. Tray uses 14px titles, 13px details and a 12px radius, like a session card. Rows that need attention (failed) come first; finished rows drop the blue session link.
  7. Trash is not a folder row or a button. It is the grey segment’s own legend line under the storage bar (“■ Trash › 3.1 GB”, 12.5px grey), so it appears once, that turns blue on hover and opens Trash. While you drag a file it becomes a drop target. Row menus keep “Move to Trash”, and the toast’s Undo is the usual way back.
  8. Storage meter sits at the foot of the tree and opens Storage. It reads GET /drive/usage, which the Storage page already calls. With no limit set (the default) the bar is the account’s total split into Drive, Trash and Other, with no grey track, so it does not read as “full”. Hover shows the numbers. States: frame 3.
  9. Frame 2: when a file is selected and the details pane opens, the table drops “Last written by” (the pane shows it as “By”), so names are not cut off.
