今天 Orbit 里没有帮助：没有 /help，账户菜单里也没有，用户卡住时只能去 GitHub 翻 docs/。
方案：两层。① 任何页面按 ? 打开右侧的帮助抽屉，先给“这一页”的文章，可搜索，可切到 Ask 直接问（Ask 见 02 板）；② 抽屉底部进入完整的 /help 帮助中心，用来浏览、搜索、读长文。
文章是一份英文 Markdown 文章库，随服务端版本发布，Web / macOS / iOS / Android 读同一份（内容模型见 03 板）。

A machine shows Offline

2 min read · Updated Nov 2, 2026

Orbit marks a machine Offline when its runner has not checked in for 90 seconds. Sessions on it pause and pick up where they stopped once it is back.

  1. Is the computer awake? A sleeping laptop is the most common cause. Wake it and wait a few seconds.
  2. Is the runner running? On the machine, run:
    orbit status
  3. Let it check itself if it says stopped:
    orbit doctor
  4. Still offline? Check the runner log.
    Open build-box ›1
A machine that is stopping for an update shows Draining, not Offline. It finishes its turns, then restarts on its own.

Evidence and confirmation

4 min read · Updated Nov 10, 2026 · Web, macOS, iPhone, Android

When an agent says a task is done, it attaches evidence: the commands it ran, test output, screenshots. Some tasks also need your confirmation before they count as done.

Where you see it

Tasks waiting for you appear in Waiting on you with an amber count. Open one to see each criterion and the evidence for it. Open Waiting on you ›

Confirm or send it back
  1. Confirm when the evidence shows what the criterion asks for.
  2. Return with a sentence saying what is missing. The agent gets it as its next message.
