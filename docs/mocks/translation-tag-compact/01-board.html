Composer：缩小 “Chinese → English” 标记

iPhone 393pt 宽，手绘（深色，照你截图的 composer）。现在 ComposerView 给标记永远预留 112pt 右侧空白（红色斜线），打字时每一行都少了这一截。下面三种改法，A 为推荐。界面 copy 都是英文。

现在

空白
Message...Chinese → English
+AutoOpus 5.5Default
打字中（长消息）
Please fix the login redirect so that it goes back to the page I was on
+AutoOpus 5.5Default
输入区只有 ~217pt 可用（361 − 32 − 112），长消息多折一倍行。

A · 缩成 “ZH → EN”，只在空白时出现推荐

空白
Message...ZH → EN
+AutoOpus 5.5Default
打字中（长消息）
Please fix the login redirect so that it goes back to the page I was on
+AutoOpus 5.5Default
标记跟 placeholder 一样：一打字就让位，输入区回到满宽 329pt。标记约 58pt（原 112pt）。点它仍跳 Settings › Translation。

B · 移进工具栏：一个翻译图标

空白 / 打字中都一样
Message...
+Auto文AOpus 5.5Default
Please fix the login redirect so that it goes back to the page I was on
+Auto文AOpus 5.5Default

输入区永远满宽，标记永远可见。代价：图标不说明方向（要长按/点开才知道是 Chinese → English），工具栏在 393pt 机型上本来就挤，模型名长时会被压。图标为 SF Symbol translate。

C · 只缩短，位置不变

空白
Message...ZH → EN
+AutoOpus 5.5Default
打字中（长消息）
Please fix the login redirect so that it goes back to the page I was on
+AutoOpus 5.5Default

改动最小，预留从 112pt 降到 ~60pt；打字时仍少一截。

待你定 ① 方案：A（推荐）/ B / C
待你定 ② 缩写写法：“ZH → EN”（推荐，按语言代码：JA → EN、KO → EN…）/ 保留全称 “Chinese → English” 只做“空白时才出现”
待你定 ③ 范围：iOS + macOS + Web + Android 一起改（推荐，四端 copy parity 测试 pin 着同一个 tag 写法）/ 只改 iOS
注：⑥ 当初定的 A 是 “Chinese → English” 纯英文 copy；②选 “ZH → EN” 会改这一条，仍是纯英文，copyLanguage.test 不受影响。
