长按（iOS）/ 右键（macOS）账号行 → Rename… → 系统改名对话框，和会话、文件夹改名同一个样式。改了名的 Default，副标题写成「~/.claude · Default」。
  • 1名字旁边一支铅笔，每个账号都有，Default 也有；双击名字也行，和会话标题一样。灰色、平时就在（触屏没有悬停），指上去变深。它不放进右边那一列：那一列是要机器去做的事——登录、删除——机器离线时禁用，而改名只改这一页的标签。账号行只在一台机器有两个以上账号时才列出来，铅笔跟着它。
  • 2Default 改了名，名字后面挂 DEFAULT 标记（和 NEXT 同一种 .re-chip），说明这是这台机器自己的登录 ~/.claude。没改名时仍只写「Default」，不重复挂。Default 依然没有 Remove，目录和 id 不动。
  • 3就地编辑，和会话标题同一个输入框（同字号的下划线输入框，宽度贴着文字）：进入即全选；Enter 或点别处保存，Esc 取消；首尾空格去掉，空的或没变就不改；最长 60 字。
  • 4名字存在控制面（按 runner、引擎、账号 id），不经过机器：保存即生效，runner 离线也能改，也不用升级 runner；账号被删掉时名字跟着删。
  • 5名字处处同一个：工作区的账号选择、composer 和新会话页的 Provider 菜单、会话里的「Switched to …」、删除确认里的「Workspaces set to this account run on …」、Runner 页的「Next: …」，读的都是它。已经写进会话记录的提示保留原文。
  • 6macOS / iOS 用长按 / 右键菜单里的 Rename…，打开系统改名对话框，规则同上。不放进左滑——左滑是直接执行的动作，改名要先打开编辑器（SessionRowActions.swift 里的现成规矩）。
