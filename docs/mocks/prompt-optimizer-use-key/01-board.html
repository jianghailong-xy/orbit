3. Rules and the alternatives considered

KeyMeaning when the card is openWhy / why not
Tab ✓Use. Fires only when the caret is in the composer box, with no modifiers, no @ / slash / # menu open (a menu gets Tab first, as it does today), and not during IME composition.Same key and same meaning as the reply suggestion. One key, no chord, and it cannot send anything by accident. When focus is on the card's buttons, Tab still moves focus.
⌘EnterUseToo close to Enter, which sends the original draft; one slip sends the wrong text. Many apps also use ⌘Enter to mean "send".
⌘⇧O againUse (optimize, then press again to accept)Today a second ⌘⇧O asks again. Pressing the same chord twice to retry would replace the draft instead.
EnterUseTakes away "send my own draft". Rejected.
Not given a key: Edit, then use (Tab already leaves the caret in the box) and Try again (⌘⇧O already asks again). Clients: web and Mac get Tab. iPhone and Android are touch-first and stay as they are.
