项目会话：点项目行不再“换掉列表”，而是在右侧单开一栏

今天在会话列表里点一个项目（协调者那一行），整栏会滑成项目会话页，原来的列表看不见了，要按 ‹ 才回得去。
方案：会话列表原样不动，项目的会话放进紧挨着它右边的一栏；右边的会话区打开协调者。每一帧都截自真实的 Web 控制台（当前 main，vite + 固定样例数据）；方案帧是把真实截图按栏拼起来的，项目栏的 ✕ 是画进页面的。红色虚线和数字是标注。

今天点了之后：整栏换成项目会话页
  • 项目占的是协调者那一行：进度 10/12，副行是协调者最近收到的消息。

方案点项目行：列表不动，右侧开项目栏，会话区打开协调者
  • 会话列表原样留着，项目那一行保持选中（蓝底）。在列表里上下翻、点别的会话都照常。
  • 新开的项目栏就是今天的项目会话页，内容一样（进度卡、Coordinator、按时间分组的成员、DONE 后的结算卡），宽度和会话栏一样，可拖。页头左边的 ‹ 返回换成 ✕ 关闭；Esc 也能关。
  • 页头右边的 ⊞ 照旧，打开项目页。
  • 协调者在栏顶，是选中态，因为右边打开的就是它。
  • 会话区打开协调者会话：点项目行最常要做的就是看协调者在说什么（这一行的副行本来就是协调者收到的消息）。
方案在项目栏里点一个成员（T7 回放对比）
  • 列表里项目那一行还是选中的（选中的会话属于这个项目）。
  • 项目栏里选中 T7。
  • 会话区打开 T7。在成员之间切换只动项目栏和会话区。
  • 在列表里点另一个项目：项目栏换成那个项目。点一个不属于任何项目的会话：项目栏自动关掉（它已经和右边的会话无关了）。再点一次已选中的项目行：也关掉。

待定 · 要你拍板

1. 项目栏放在哪

A列表和会话区之间推荐
B会话区最右边（像任务侧栏那样）
  • A：从左到右就是“工作区 → 项目 → 会话”，一层层往下，眼睛顺着走；项目栏和列表长得一样，读起来像一个整体。
  • B：会话区紧贴列表，项目栏像个附加面板；但会话标题右边已经有 ⋮ 和任务侧栏，三个东西挤在右边。

2. 点项目行时，会话区打开什么

  • A 协调者会话推荐：和上面的图一样。项目行代表的本来就是协调者，副行也是它的消息；点一下就能接着和它说话。
  • B 不动：会话区还是刚才那个会话，只多出项目栏，要再点一次协调者。少一次跳转，但“点项目 → 右边没变化”容易让人以为没点上。

3. 窗口不够宽、手机

  • 手机：一次只显示一栏，维持今天的样子（推进到项目会话页，‹ 返回）。iOS / Android 也不变。
  • 桌面窄窗口（四栏放不下，会话区会被挤到 < 480px）：A 先收起左侧导航推荐，再不够就退回今天的“换掉列表”；B 直接退回今天的样子。
