项目会话：点项目行打开协调者，项目的会话在会话区最右边一栏（第 2 版）

按 11-11 你定的三条改了：① 项目栏放在会话区最右边（B）；② 点项目行，会话区打开协调者会话；③ 项目栏可以收起：窗口放不下四栏时自动收起，协调者会话标题栏上的按钮 ⊞ 11 把它展开或收起；手机（Web、iOS、Android）上点同一个按钮，从底部弹出项目的会话列表。
每一帧都截自真实的 Web 控制台（当前 main，vite + 固定样例数据）。方案帧是把真实截图按栏拼起来的；标题栏里的 ⊞ 11 按钮、项目栏的 ✕ 和手机上的底部弹窗是画进去的。红色虚线和数字是标注。

今天点了之后：整栏换成项目会话页
  • 项目占的是协调者那一行：进度 10/12，副行是协调者最近收到的消息。
  • 点它，会话栏整栏滑成项目会话页（URL 加 ?project=）。原来的列表看不见了，要按 ‹ 才回去；在项目里看完一个成员，想回到别的会话，得先退出项目页。
  • 右边的会话区不变，还是刚才那个会话，跟项目没关系。
方案宽窗口：点项目行 → 会话区打开协调者，项目栏开在最右边
  • 会话列表原样留着，项目那一行保持选中。
  • 协调者会话的标题栏，⋮ 左边多一个按钮：项目图标 + 会话数（⊞ 11）。项目栏开着时按钮是蓝底（按下态）；点它收起，再点展开。悬停提示 Project sessions。
  • 项目栏就是今天的项目会话页（进度卡、Coordinator、按时间分组的成员、DONE 后的结算卡），贴在会话区右边，宽度和会话栏一样。页头左边的 ‹ 换成 ✕，作用和标题栏按钮一样：收起。
  • 协调者在栏顶，是选中态，因为会话区打开的就是它。
  • 标题栏上方那行“← 搜索服务迁移到新索引”（打开项目页）和项目栏页头的 ⊞（也是打开项目页）都保持不变。
方案在项目栏里点一个成员（T7 回放对比）
  • 列表里项目那一行还是选中的（会话区里的会话属于这个项目）。
  • 项目栏里选中 T7，栏不动。
  • 会话区换成 T7。成员之间切换只动会话区。T7 的标题栏也有 ⊞ 11（11-11 定：成员也放）。
  • 在列表里点另一个项目：会话区换成那个项目的协调者，项目栏也跟着换。点一个不属于任何项目的会话：项目栏关掉。
方案窗口放不下四栏：项目栏自动收起，用标题栏按钮展开
  • 项目栏收起时，按钮是普通灰色（不是按下态），点它展开项目栏。
  • 点项目行的效果不变：会话区打开协调者；只是项目栏先收着。
  • 什么时候算“放不下”：展开项目栏后会话区会窄于 480px（这张 1180px 宽的窗口就是：会话区只剩 260px）。窗口拉宽到放得下时，项目栏自己展开回来；用户在宽窗口里手动收起的，就一直收着，直到再点按钮。

方案点 ⊞ 11 → 底部弹出项目的会话列表
  • 手机上点会话列表里的项目行，不再推进到项目会话页，直接打开协调者会话。标题栏 ⋮ 左边同样是 ⊞ 11。
  • 点它，从底部弹出项目的会话列表，内容和桌面的项目栏一样。弹窗先停在中间高度，往上拖到全屏；点 ✕、点遮罩或往下拖就关掉。
  • 点一个成员：弹窗关掉，会话区换成那个成员；返回 ← 回到会话列表。
  • iOS：用系统 sheet（中/大两档 detent），列表就是现在的 SessionProjectPage 的内容；Android：用 ModalBottomSheet，列表复用现在的项目会话页。这两端图里没画，外观照各自现有的弹窗。

  • 点项目行，会话区打开协调者会话。
