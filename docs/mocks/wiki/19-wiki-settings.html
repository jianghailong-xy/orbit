  1. 1审阅模式：三档单选，每档一句话；默认 Tiered（标 default）。只有你能切（owner 门）。卡底一句安全底线：什么在任何模式下都问你。 Orbit 一致性Settings 页的 antd Card + 左边说明、右边控件 新词Manual / Tiered / Automatic 的三句说明 · Always asks you, in any mode
  2. 2抽检开关：挂在 Automatic 下面，默认关；开了之后每 200 条抽 1 条进 Review，且不占 30 条待审名额。没选 Automatic 时置灰（Tiered 自带每 10 抽 1，不用开关）。 新词Spot-check Automatic
  3. 3维护作业：默认关：一行说明 + 状态 Off + Set up…。首页状态行的 Set up 也到这里。
  4. 4Set up：Workspace（在哪台 runner 上跑）、Provider（默认 local-vllm，钉死不回退）、Daily limit（每天最多几次运行，默认 8）→ Turn on。弹窗与条目抽屉的 Edit / Retire 同一个 antd Modal。 新词Set up maintenance · Daily limit · runs a day
  5. 5开着的时候：状态（和首页状态行同一句）、在哪、用谁、额度用了多少、上次运行（View run 打开运行抽屉，图 17）；Edit / Turn off。 协调性状态句与首页状态行同一个
  6. 6自动退回：Automatic 的核实拒绝率超过 30%（最近 50 条）会自己退回 Tiered 并通知一次；设置页用琥珀提示说清什么时候、为什么，单选落在 Tiered。日期是预览 space 09-27 真实退回的那天（服务端记了 reviewModeChangedAt / By=verification）。 新词Automatic switched itself back to Tiered
