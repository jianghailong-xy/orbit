1产品概览与架构
1.1
产品定位与核心能力
Orbit 是自托管的 coding agent 控制台：agent 跑在你自己的机器上，计划、历史和控制都留在一个自托管的地方。
1.2
系统架构与数据流
Orbit 把协调和执行分开：服务器保存意图与历史，注册的 runner 在本来就有仓库、凭据和网络权限的机器上跑 agent 进程。

Session 运行与恢复

1中栏 = 目录：Home、Browse by category、A–Z index、Plan，然后各大类和篇——和 web 桌面左边的目录栏（图 29）同一张单子，也和手机 Contents sheet 同一套行。iOS 系统三栏的中栏本来就该是「可选的单子」，Projects、Tasks 都是这样。

2详情栏默认就是内容（Home 选中）：和手机首页同一份——内容状态、搜索、文档按大类、每篇两行导语。点中栏的篇，详情栏换成文档页。

3管理信息照样在 Activity：详情栏页头的按钮，数 = 抽屉的数；Activity、Review、设置都开在详情栏。

协调性这样 iPad 和 web 桌面是同一个结构（目录栏 + 内容），手机是它的单栏版（图 30 ③）。web 桌面今天的首页（图 29）同样改：主区放内容，Review、Plan、Recently changed、Agents used 进 Activity，见图 33。
