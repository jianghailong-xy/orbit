协调性两端同一顺序：标题 → 数量 → 按大类分段（段头 = 编号 + 名称 + 篇数，下一行是这一类回答什么）→ 每段里的篇（编号 + 标题 · 节数 · 待审 / 还没写，第二行是读者带着的问题）→ 展开后的节。

Orbit 一致性篇一行 = 图 16 的主题行：标题蓝色、点开是文档页；行尾 caret 展开它的节（web 行尾 caret，iOS 用 DisclosureGroup 的 chevron），点一节跳到文档里那一节。

借鉴桌面（图 27）把每篇的节两列铺开；手机上默认只展开你点的那一篇，否则一屏只看得到一篇。
