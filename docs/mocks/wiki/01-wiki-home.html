  • 1侧栏入口：Wiki 放在 Projects 下面，book 图标；右侧琥珀数字 3 = 等你审的提议数（悬停 tooltip「3 proposals to review」）。Orbit 一致性整行照抄 .tp-item，琥珀胶囊就是 workspace 行「等你回复」用的 .tp-count.needs-you；有琥珀数时不显示快捷键，和 workspace 行同一条规则。协调性同一个 3 出现在侧栏、状态行「3 to review」、右栏 Review 卡和 04 的副标题，口径都是「等你拍板的提议」。
  • 2页头：标题 + space 选择器 + New entry，下面整行搜索框，右侧提示 ⌘K（⌘K 全局面板里也搜得到 Wiki，见 05-d）。space 就是代码库：orbit 这一份同时服务 wikova 和 longdeMac-mini.local 上两个叫 orbit 的 workspace；另一份是 wikova（wikova-develop / -prod / -data 共用）。Orbit 一致性布局照 Projects 页的标题行 + 整行搜索（projects-title-row / projects-toolbar）。新词space、entry。
  • 3状态行：条目数 · 待审数 · 锚点最近一次在哪个提交上复验、多久前 · 维护任务最近一次运行。Orbit 一致性直接用项目详情页集成线那一行（.project-integration-row），灰底一行、数字加粗、需要你的数字用琥珀。新词Anchors verified、Maintenance。
  • 4Principles 置顶：owner 写的 4 条，每行标题 + 一行说明 + 深色 Owner 标签；第 4 条是昨天新加的（蓝点 = 你上次来之后新增）。借鉴Notion verified pages：谁核验过就挂在条目上。Orbit 一致性卡片框 = 项目页 Open items 卡（.project-open-items），行 = 列表两行式（标题 + 摘要）。新词Principle；信任标签 Owner / Confirmed / Proposed（深 / 蓝 / 灰），在 02–05 各处同一套。
  • 5Topics：6 个主题（2 列 × 3 行），数字是条目数，六个加起来 = 96；底下一行是这个主题最近一次变化。借鉴Confluence / Notion 的 space home。协调性动词和右栏 Recently changed 同一套：Added / Confirmed / Amended / Retired。新词Topic。
  • 6Recent decisions：决策日志，日期 · 标题 · 状态。被取代的决策不删，在取代它的那条下面划线显示并标 Superseded。为了让 Active / Superseded 两种状态都看得见，这里放了 4 行（规格写 3 条）。借鉴ADR 的状态字段、Oxide RFD 的状态标签。Orbit 一致性Superseded 是任务结局里已有的词（lib/taskOutcome.ts）；标签用任务详情的 .tdp-badge。
  • 7Review 卡：琥珀点 + 同一个 3，列出 3 条提议（ADD / RETIRE / AMEND，顺序和写法都与 04 的三张卡一致），按钮进 04。Orbit 一致性琥珀 = 等你处理，和侧栏、项目页 Needs you 同一规则；按钮是主色，不是琥珀。
  • 8Recently changed：最近 5 次变化。圆点颜色 = 变化后的信任状态：深 = Owner，蓝 = Confirmed，灰 = 已退役（退役的标题划线，并说明原因和替代条目）。借鉴Linear Pulse 的时间线。
