协调性两端同一顺序：space → Review mode（Manual · Tiered · Automatic，每档一句）→ Automatic 的抽检开关 → 安全底线一句 → Maintenance（Off · Set up…）。

Orbit 一致性web 就是 app 的 Settings 页（图 19 的手机宽度）：antd Card、左说明右控件；三档是竖排单选，抽检开关缩进挂在 Automatic 下。

iOS 系统iOS：Wiki 首页右上的齿轮 push 进来，insetGrouped 表单（同 app 设置）。三档是带说明的勾选行（系统单选列表的习惯，勾在右侧），抽检是同一段里的 Toggle，不选 Automatic 时置灰；安全底线写在段脚注。

已定维护默认关、provider 默认 local-vllm、Automatic 的抽检默认关（每 200 抽 1）——都是判据 7 与项目说明里定的。

协调性Set up 的三项同一顺序：Workspace（跑在哪台 runner 上）→ Provider（钉死，不回退）→ Daily limit（每天最多几次运行）→ Turn on。

iOS 系统iOS 用 sheet 表单：左 Cancel、右 Turn on（确认在右上，系统表单的习惯）；选项用 Picker(.menu)，次数用 Stepper。web 是 antd Modal，按钮在底部右侧。

要你拍板每日上限的单位：图上按「每天最多几次运行」画（默认 8，一次运行最多读 20 个会话、写 30 条）。也可以按 token 或按条数限，你定。
