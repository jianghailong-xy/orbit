Secret redaction lets ENV_VAR=value secrets through
TriggerA watch delivery fails with an error that quotes an environment assignment such as POSTGRES_PASSWORD=… SymptomThe value is stored in the delivery's lastError and shown on the watch and the dead-letter list unredacted. CauseThe key pattern starts with \b, and _ is a word character, so \bpassword never matches inside POSTGRES_PASSWORD. FixLet the key follow _ as well as a word boundary, and add POSTGRES_PASSWORD=hunter2 to the redaction spec. Sources
