Summary· generated from 17 entries at 4db4f9fRegenerate

Work starts only from a committed fact — evidence revised, a receipt written, a turn ended; a clock can only hand an open item to a person.[1] A task is done when its declared criterion says so, and an EXECUTABLE criterion judges by the exit code alone.[2][3] Order is a field on the task: the dispatcher reads priority, then age, and no scheduler session moves tasks between lists.[4] Wakeups are held by the server, so a recycled engine no longer loses them.[5]
