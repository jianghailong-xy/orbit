4待你定 · 两个问题，各有推荐

Q1 · 点了 ✕ 以后，「收起」记多久？

A · 一直记住，直到你再点圆按钮 推荐
存在本机（localStorage），按 space 记；新标签、重启 app 都还是收起。和 VS Code 按 workspace 记一样。你关它是有原因的，不该每次打开又弹出来。
B · 只记到这个标签页关掉
存在 sessionStorage，和今天记「开着哪一场」一样；新标签又默认展开。好处是不会「关了一次就永远看不到」；坏处是不想要它的人每次都得再关一遍。

Q2 · 收起以后长什么样？

A · 照旧：右下角圆按钮 推荐
图 42 已定，带四种状态（Working、needs you…）。不改，零成本。
B · 缩成右边一条窄条（NotebookLM 的 rail）
收起后右边留 40 宽的一条，放展开键和状态。更像「面板一直在」，但要重画状态、和条目抽屉的关系也要重想。
