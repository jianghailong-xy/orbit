Q3 · 历史列表放在哪？

A · 整个面板换成列表（图 ②） 推荐
放得下搜索、分组、⋯ 菜单；Cursor 也是这样。代价是看列表时看不到当前对话，选一场或按 Esc 就回来。
B · 保留下拉条，只加状态和时间
改动最小，边看对话边选。但只有 40% 高，放不下搜索和分组，管理动作只能再塞一个菜单。

Q4 · 列表怎么分组？

A · Open / Completed，跟 session 列表一样 推荐
先看要处理的；「完成」同时管「不再自动接上」。
B · 按时间：Today / Yesterday / Previous 7 days
ChatGPT 的做法，找「前天那场」快；但等你处理的会埋在中间，完成与否也看不出。
