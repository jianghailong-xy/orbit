新词维护状态四种样子（判据 5），手机和桌面同一句话：

① 关：Maintenance off · Set up，Set up 进 Wiki 设置的 Maintenance（图 20）。
② 正常：Maintained 2h ago ✓ · 6 to catch up = 上次成功时间 + 还没消化的事实数（会话结算、任务终态、审批回答、receipt、判据修订，各算一条）；正在跑时换成 Maintaining now · started 4m ago。
③ 滞后（琥珀）：最老的一条超过 24h 还没处理，后面跟原因（daily limit reached / runner offline）。
④ 连续失败（红）：次数 + 上次成功 + View run（打开失败那次运行的会话）；到 3 次推一次通知，恢复后清零（判据 5）。

协调性“to catch up” 和旁边的 “12 to review” 同一个句式；颜色规则照会话列表的状态点：琥珀 = 停着等，红 = 坏了。
