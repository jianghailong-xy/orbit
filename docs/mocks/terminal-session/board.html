终端凭据（credential_kind = TERMINAL）：在终端里批审批，权限收窄到这台机器

限制防的是什么
只能由 owner 在 App 里点 Approve 签发（owner 渠道），令牌和 runner 都发不了agent 给自己签一个
只绑定这台机器（它的 runner）和这台机器上的会话，别处的会话一律拒绝凭据被拷走后拿去批别处的会话
存系统钥匙串（没有钥匙串时存 0600 文件），不进环境变量从 env 或公开可读的文件里读到
30 天过期；App 设置 → Terminals 里列出来，可以撤销泄露了也没人发现、一直能用
只放开：建 / 开会话、发消息、打断、读事件、批审批卡。证据裁决、验收标准、启动 / 完成项目等仍然拒绝终端权限扩大成 owner 的全部权限
每次回答都记 credential_kind = TERMINAL + 机器名事后查不到是谁批的
你接受的风险（D7 = B）：和终端同一个系统用户的 agent，能读到存下来的凭据，直接调用审批路由批准它自己在这台机器上的请求。activity 里看得到，也可以撤销。runner 用独立用户安装（hostd）时，agent 碰不到你的钥匙串和家目录。
human-only-authority.md 加一行 TERMINAL：只放开审批卡，证据裁决、验收标准、启动 / 完成项目等仍然拒绝。
