终端凭据（credential_kind = TERMINAL）：在终端里批审批，但不给同机 agent 留口子

限制防的是什么
只能由 owner 在 App 里点 Approve 签发（owner 渠道），令牌和 runner 都发不了agent 给自己签一个
只放在 TUI 进程内存里，不写磁盘、不进环境变量agent 从文件或 env 里读到
进程退出就作废，最长 12 小时泄露出去的副本一直能用
只管这个终端开过的会话拿它去批别的会话的请求
批审批必须在这个 TUI 自己的 TTY 上按键脚本替人点
每次回答都记 credential_kind = TERMINAL + 机器名事后查不到是谁批的
剩下的风险：和 TUI 同一个系统用户的 agent，理论上能用 ptrace 读它的内存。Linux 的 ptrace_scope ≥ 1 和 macOS 默认都会拒绝非父进程这样做。runner 用独立用户安装（hostd）时，这个风险就没有了。agent 也不能自己另起一个 orbit：每次启动都要手机上点一下，你会看到。
human-only-authority.md 加一行 TERMINAL：只放开审批卡，证据裁决、验收标准、启动 / 完成项目等仍然拒绝。
