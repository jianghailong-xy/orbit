iOS 项目会话页重做：从「按时间排的会话」改成「这个项目现在怎样了」

这一页是从会话列表里点项目的进度小标签进来的。进来的人想知道三件事：有没有事等我、现在谁在干活、哪个任务做到哪了。现在的页面把 24 个会话按时间平铺，前缀占掉了标题，同一个任务的两次运行长得一模一样，coordinator 被标了三遍，最上面还空着一大块。

改后：顶部一张卡，放项目整体情况（进度、coordinator、判断会话）；下面按状态分组（Needs You / In Progress / Finished / Not Started），每个任务只占一行。图里的数据都取自这个项目当前的真实状态。

改了什么、数据从哪来

项规则数据 / 实现
行标题任务会话显示任务名，去掉「执行任务：」。@ 任务发起的对话（CONTEXT）和子会话（CHILD）挂在它们的任务下面，跟「↳ Run 1」一样单独一行小字，前面加 Chat / Subagent 小标签。会话已经带 taskId；任务名可以在 projectMembership 里加一个 taskTitle（服务端一行 SQL），不建议客户端去剥前缀字符串。
一个任务一行同一个 taskId 的会话合成一行，用最新那次运行代表；更早的运行在任务还在跑时挂在下面，任务结束后收成「N runs」。纯客户端分组，加在 OrbitKit 的 SessionProjectGrouping 里，带单测。
状态分节Needs You（行状态是等你）→ In Progress（在跑 / 排队 / 有 watch 在等）→ Finished（任务 DONE，或会话已结束）→ Not Started。节内按最近活动时间排。前三节用现成的 SessionStatusGlyph 判断；Not Started 需要项目的任务列表（项目页已经在拉）。
顶部卡进度行写 done / running / not started，整行点进项目页；Coordinator 行；Judgments 行写条数。原来的 progressCard 和 Coordinator 节合成一个 Section，原来那块空白就没了。⋯ 菜单不变。
没动的导航栏、⋯ 菜单、会话行本身的样式、左右滑、长按、每 4 秒刷新、iPad 在中间栏原地换页。—
