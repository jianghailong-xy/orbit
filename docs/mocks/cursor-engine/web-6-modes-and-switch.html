Web 6 · 权限模式：Cursor 能做的可选、做不全的带一句说明、做不到的不可选；换账号：开始说话以后先不能换

Cursor 在 ACP 下写工作区文件从不发权限请求，也没有开关能让它问（契约 §5.4）——所以「编辑前要问」的 Default 做不到。其余模式按 P1 的协调说明映射：Accept Edits = 默认白名单（写文件不问，命令 / MCP / web fetch 走审批卡）；Plan = Cursor 的 plan 模式挡写文件 + Orbit 拒绝其余请求；Auto = Orbit 自己的请求级分类器（写文件不受控）；Don’t Ask = Orbit 一律拒绝（写文件仍会发生）；Bypass = --force。Cursor 自己的 ask 模式不用。下拉框沿用今天的「模式 — 短说明」写法（今天 DeepSeek Harness、Codex、OpenCode 已经这样）。换账号：跨账号续聊还没验证（D5），说过话的会话先不能换，没说过话的照常换。灰色字母标现在的问题，橙色数字标改动。
