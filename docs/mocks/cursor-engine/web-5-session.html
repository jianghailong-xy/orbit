Web 5 · Cursor 会话：模型 + 变体；轮中发的消息排到下一轮并说明原因；上下文读数写「Unavailable」；额度用尽显示成额度卡

模型目录来自 Cursor 的参数化选择器（契约 §10，_meta.parameterizedModelPicker）：先选模型，再选这个模型自己的参数——effort、context、fast，Auto 没有参数。Cursor 轮中再发一条 prompt 会取消正在跑的一轮（契约 §3.2），所以 Orbit 只排队、不插话，托盘上写明为什么。ACP 从不发 usage_update，上下文读数永远没有，和「还没报上来」不同，要写成「Unavailable」。额度用尽时 Cursor 只回一句文本 "Upgrade your plan to continue" 加 end_turn（契约 §12），P5b 把它归成额度错误，界面显示成额度卡而不是一条普通回复。示例：hpc 上的 orbit 工作区，会话「Fix the flaky export test」跑在 Cursor CLI 的 Default 账号上。灰色字母标现在的问题，橙色数字标改动。
