  • 1每个账号都写明谁的会话能落在它上面。ChatGPT 账号标「Only you」，API key 标「Everyone here」。这是规则，不是开关：没有把 ChatGPT 账号改成 Everyone 的选项。
  • 2「Who can use it」有两档：Just me 和 Me and people I add，按 Orbit 账号邮箱加人。每人一行，写清能用哪些账号（全部 / 只有 API key），以及 API key 本月用量里的份额。份额公开沿用共享池的 D6，只算 API key，不算你的 ChatGPT 用量。「They can add their own API keys」就是现在的 Members can add keys。
  • 3被加进来的人看不到你的 ChatGPT 账号。只有一行锁住的说明，不显示邮箱、套餐和额度，因为那是你个人订阅的信息。也可以连这一行都不显示。
  • 4加了人，但池里还没有 API key：卡片直接写明他们开不了会话，并给出「Add an API key」。他们的会话选择器里，这个池显示为灰色，写「No key you can run on」。
  • 5选号：你的会话先用 ChatGPT 账号（订阅额度，不额外花钱），都用完再落到 API key（按量计费）。别人的会话只在 API key 之间选，own key first 照旧。网关也照旧：登录令牌只发给池主（0324 的外键），其他人只拿得到 API key 的令牌。
  • 6方案 B 改动最小：两种池不合并。ChatGPT 池只能加账号，「Who can use it」固定为 Just me，并指向「New shared pool」；要分享，就用现有的 API key 共享池和它的 Members 卡。代价是在这个页面上做不到「配置可见人」。
