上两张是池主看到的（Just me / 分享后）；最后一张是 Zhang Min 看到的同一个池。

  • 1「Add account」先问加哪种账号。两种账号谁能用不一样，所以把差别写在选项上，而不是等加完才发现。选 ChatGPT 进入现有的设备码登录，选 API key 进入现有的 AddKeyModal（说明 → 名字 / key / 每月上限 → 完成）。池里没人分享时，API key 也可以加，作为你自己的按量兜底。
  • 2第二个账号的说明页只改三句话。「Only you can use it」补上「即使池分享出去也一样」；「Sign out any time」改成「池继续跑其他账号」；开头一句说明池里现在有几个账号。
  • 3风险提示改成「只能是你自己的账号」。拿别人的 ChatGPT 账号走设备码登录，页面拦不住，但这正是 09-27 被否掉的那种共享，所以要在这里写明。
  • 4完成页说明加进来以后会发生什么。「taken」那一步（池已经跑在另一个账号上）没有了；同一个账号再登一次仍然拒绝，文案改成「adds no quota」。
  • 5分享的确认页把边界说在点「Share」之前：他们只能跑 API key，看不到你的 ChatGPT 账号是哪几个。
  • 6池里还没有 API key 时，主按钮是先加 key，也可以照样分享。分享以后卡片上会一直挂着图 02 里那条黄色提示。
  • 7切回 Just me 等于一次移除所有人，沿用现在「成员离开，key 跟着走」的规则（复合外键级联），他们的网关令牌也随之失效，所以要二次确认。
  • 8Providers 页的池卡只自己用时写「Just me · 2 of 2 accounts available」，分享后加 SHARED 和头像。读数同图 01 的 B，取最紧的窗口。被加进来的人看到的是「jianghailong's · 2 keys you can run on」。
