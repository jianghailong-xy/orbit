Commits first on iOS and Android

The web bar now counts a session's work in commits (board 01, live since 11-19). This brings the same model to the native apps, keeping each platform's existing shape: the bar above the composer, and the full-screen "Worktree changes" view it opens (iOS sheet, Android full-screen dialog). The change is a Commits / All changes switch at the top of that view, a commit screen between the list and a file's diff, and the bar's count. iOS is the reference; Android follows it with Material parts. Hand-drawn draft; nothing is built. macOS shares the iOS code (OrbitKit + WorktreeBar.swift) and gets the same, in its own sizes.
