1 · An ended session's icon

The Idle circle. Released is not an activity: a released session is always phase IDLE. The grey Ended mark beside it says it ended (green Finished if its work finished, red Failed if the release was a failure). Today's grey check, which reads as success, goes.

2 · A failure stays noticeable

By the red Failed mark, the only red left on a row, and by its place: a failure nobody is retrying sits in Needs you at the top, as today. The red moves from the icon to the mark; the icon is Idle. A failure being retried wears grey Retrying and stays in Working.

3 · Needs you and Working keep their members

The group rules are not touched and read the same facts: the Group column is before = after on every row. Needs you = a Needs you mark or a red Failed mark, on every client. Working on web = Queued or Running, or Retrying. Mac, iPhone and Android read Working from the legacy status, so rows 15, 27 and 29 draw Running but stay out of Working, exactly as today.

4 · What colour means

blue running (the spinner on web and Mac; phones keep it muted, as today) · amber you have to act · red a failure nobody is retrying · green the work finished. Everything else is grey: a grey row needs nobody.

Session list iPhone row: SessionLiveIndicator sits on the first line before the time (AgentsView.swift:1841-1850, 1935-1977). After: the state icon keeps that slot; marks go to the right end of the second line.
