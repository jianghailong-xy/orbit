iOS 标题区 — 大标题到底占了多少

同一条 needs-you 条、同一个工具栏，只换标题这一块（三格都是 393pt 宽、按你截图量出来的带高：状态栏 59 / 导航栏 44 / 大标题块 62 / 搜索 44+12 / 条 36）。 蓝框 = 标题块，红虚线 = 列表首行的起点。

量出来的账：常驻成本（不滚也在）＝ 状态栏 59 + 导航 44 + 搜索 56 + 条 36 ＝ 195pt； 大标题那 62pt 是滚动即收起的，所以「占太大」的账主要记在搜索框（displayMode: .always，44+12pt） 和这三带叠加，而不是标题的字号上。
我的建议：标题这一块先别动字号——想收回空间按性价比是 B（明确、可逆、和 iPad 同口径）； 想留住「我在哪」就选 A 保持现状，或 C 把那 62pt 花成信息。三格里只有一处是真的浪费：A 的 62pt 只印了一个你刚刚亲手选过的名字。
