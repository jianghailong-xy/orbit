① 项目 DONE：谁来确认

项目进 DONE 有两条路。推导（project-done-derived.ts）：判据全部满足、全部落到 main，再加上你早先确认过这版判据，Orbit 就自己把它写成 DONE，这一刻不问你。记录（POST /projects/:id/done）：只在事实证明不了时才走，coordinator 提请求，你在「Is this project done?」卡上按。下面画的是正常落地的项目在推导这一刻你看到的东西：现在、方案 A、方案 B。

待你定：A 还是 B？A 保持 2026-09-08 的决定（确认判据 = 同意），只补通知和 Reopen 入口，改动小。B 推翻那个决定：Orbit 永远不自己写 DONE，done_by='DERIVED' 不再出现，「recorded by Orbit」文案和 docs/project-done-gate.md 都要改；推导出的 DONE 后续被事实收回的规则也随之消失（你的记录只在判据变或服务任务 reopen 时收回）。
