  • 1只在 iPhone（compact 宽度）上合并，两个读数都保留。用量条（24×5，比现在的 20×4 稍大，更好看清）和圆环（16pt）并排放在一个按钮里，整块 62×32 都能点，按下时整块显示按下效果。iPad（regular）和 macOS 仍是两个带数字的控件。
  • 2颜色规则不变：用量条按套餐用量（≥90% 橙色，用完红色），圆环按上下文用量（≥75% 橙色，≥90% 红色），一眼就能分别看到两项。没有套餐数据时只剩圆环，点击区域不小于 32×32。无障碍标签同时读出两项："Plan usage 94%, context 41%"。
  • 3合并面板的标题用 "Context and plan usage"，和 Android 一样。分组顺序：Context → Plan usage（Account、各时间窗口、重置时间，以及 Codex 的重置额度卡片）→ 操作。操作的显示条件和 coordinator-context-actions 的 03 一样。没有套餐数据时，不显示 Plan usage 这一组。
  • 4关掉面板后，底栏照常显示两个读数（这里用量条是橙色的 94%），不用打开面板就能看到。
