03 · 不加填色，怎么让用量条和圆环看起来是一个控件

02 的灰色胶囊太突兀：底栏里 + 、Bypass、模型名都没有底色，只有它有。下面四种更轻的做法（左：2 倍放大；右：实际大小，深色 / 浅色）。读数都一样：套餐 94%（橙），上下文 41%。

  • 1推荐 D（双圆环）。它本来就是一个图形，不需要再靠底色或边框去"框"在一起；两个读数都还在，颜色规则也不变（外圈按上下文，内圈按套餐）；而且比现在更窄，模型名不容易被截断。
  • 2如果想保留横条，选 B：只把间距缩小，最不显眼。C 介于 B 和 02 的胶囊之间。
  • 3所有方案的点击区域都不小于 32×32（看不见），按下时整块一起变暗。iPad 和 macOS 不变。
