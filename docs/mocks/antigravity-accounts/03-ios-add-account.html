Antigravity 账号 · Add Account：再加一个 Google 账号，走 Claude Code 加账号的同一套流程

点 Add Account 的那一下就开始登录，名字先用 Account 3 占着、随时可改；登录还是今天 Antigravity 的 Google 登录（打开 Google 页 → 同意 → 把授权码贴回来）。登录成功、runner 报上新账号、名字存好之后卡片自己收起，留下新账号那一行——和 Claude Code / Codex 加账号的规则完全一样。新账号的登录放在自己的目录里，Default 和其他账号都不动。

1点 Add Account

① 名字先填好：Default、Work 之后就是 Account 3（被占用就往后数）。点下的同时 runner 开始一个新的 Google 登录，几秒后出现登录页链接。

2去 Google 同意，贴回授权码

② Open the sign-in page 在 Safari 打开 Google，选要加的账号、同意，页面给一串授权码，复制回来贴进来 Submit。③ 登录中随时可以改名，回车或点别处就存。

3登录成功

④ runner 验过新令牌能读到额度才算登录成功（今天的 Google 登录就是这么做的）。成功后这张卡不用点 Close，账号一出现在列表里就自己收起。

结果卡片收起，多了一行

⑤ 新账号 Personal 带着自己的四条额度出现在列表里，Add Account 回到原样，再点就是再加一个。运行器页那一行变成 3 accounts signed in。

  • 1失败或取消：卡片留着，橙字写原因，按钮变成 Try signing in to Antigravity again——和今天一样，也和 Claude Code 一样。原来的账号不受影响。
  • 2同一个 Google 账号登了两次：新行下面写 This is the same account as Default — signing in twice does not double the quota，旁边一个 Remove（Claude Code / Codex 已有的提示，web 上显示）。
  • 3条款：Google 条款一直在 Accounts 区下面（图 2 ⑥），这一页里每个登录按钮都在它上面。
