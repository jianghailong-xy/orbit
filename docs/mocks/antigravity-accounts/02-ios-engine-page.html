Antigravity 账号 · 引擎页：Google 账号一个一个列出来，和 Claude Code / Codex 一样

从运行器页点 Antigravity 进来的页面。现在只有一个「Sign-In」区：一行 Google account、四条额度、一个 Re-sign in 按钮，换账号只能把唯一的账号顶掉。改后换成 Claude Code / Codex 的 Accounts 区：每个 Google 账号一行，自己的登录状态、自己的额度、自己的 Sign In Again / Pause…，最下面 Add Account 加新账号。

现在引擎页（按现有代码画）

A 区名是 Sign-In，只容得下一个账号。B 「Re-sign in · change Google account」：想换账号只能把现在这个顶掉，不能同时留两个。

改后两个 Google 账号（整页长截图）
改后说明
  • 1区名 Accounts，和 Claude Code / Codex 的引擎页同一个区。Default 是这台机器原来那个 Google 登录（~/.orbit/antigravity/google），升级后原样保留，不用重新登录。
  • 2每个账号一行：名字、登录存放的位置、Signed in；下面是这个账号自己的四条额度——每个 Google 账号的额度各算各的。
  • 3Sign In Again / Pause…：和 Claude Code / Codex 账号同一组按钮。Sign In Again 只重登这一个账号；Pause… 让新会话暂时跳过它。原来的「Re-sign in · change Google account」不要了。
  • 4Work 是加出来的第二个账号，登录放在自己的目录（~/.orbit/antigravity-accounts/<id>），和 Default 互不影响。它的 gemini-5h 只剩 4%，条变橙——和别的引擎快到上限时一样。
  • 5Add Account：点下就开始一个新的 Google 登录（流程见图 3）。
  • 6Google 条款挪到 Accounts 区下面的说明里：这一页是所有 Google 登录发生的地方，条款一直在按钮下面看得到。运行器页的行上不再重复。
  • 7改名（长按 → Rename…）、移除（左滑 → Remove，先确认）和 Claude Code 的账号完全一样，Default 不能移除。
