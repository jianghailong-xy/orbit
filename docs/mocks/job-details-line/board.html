后台作业行：「Job details」挪出最右侧

你截图里那行（BackgroundWakeCard — 会话流里 agent 的一行事件）。现在 Job details › 被 margin-left:auto 顶到整行最右侧：内容在 just now 就结束了，跟着是一千多像素的空档，读起来像另一列按钮。 iOS / Android / macOS 的同一行不是这样的——它们的 HStack 里没有 Spacer，Job details 紧跟时间； 只有 web 把它推到了最右。方案 A 就是把 web 改回其他两端已有的样子；方案 B 是更进一步的 web 内部统一（和工具行、思考行一样，行首一个箭头、去掉字样）。

① 改动前宽窗口下 Job details 孤零零挂在最右

session · 窗宽 2000px（示意一个宽窗口）真实 markup 与 CSS

橙色虚线是量出来的空档：内容在 just now 结束，之后一路空到行尾才出现 Job details。窗口越宽，这个空档越大——它不随内容走。

② 已采用：方案 A字样留着，贴住内容：改回 iOS / Android 的写法

session · 窗宽 920px · 收起

悬停时字样提亮一档（下面第二行就是悬停的样子）。

③ 方案 B行首箭头：与 web 的「工具行 / 思考行」同一套折叠语法

session · 窗宽 2000px · 四种状态
收起

展开
失败（标题转红，输出尾巴仍然露在外面）

Job details 四个字不再需要——箭头本身就是「点开有东西」，和工具行一模一样：点整行展开，箭头朝下。折里的一切（job id、命令、输出、agent 收到的原文）不变。

语法对照：三行共用一个箭头列（虚线为箭头列）

箭头列对齐后，唤醒行和工具行、思考行读成同一种行：箭头 · 记号 · 文字。
代价：web 会与 iOS / Android 分家——那两端的行里仍写着 Job details，web 只剩一个箭头；要么三端一起换，要么接受不一致。
