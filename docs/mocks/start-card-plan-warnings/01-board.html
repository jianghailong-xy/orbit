Start 卡片：Plan 里的黄字

这些黄字是“启动前检查”留下的提醒。协调者请求启动时，服务端会先检查计划：如果某条验收标准只靠“看起来不写代码”的任务完成（OWNER_CONFIRMED，或 EVIDENCE_JUDGMENT 但没有验收命令），而这些任务都没声明 codeless，就记一条提醒。它防的是：这种任务结束时如果没有提交，那条标准可能一直算不上“已落地”，项目也就到不了 done（10-01 有个上线任务就这样卡住过项目）。

问题出在显示上：每条标准一段，句子是写给协调者看的，满是内部词，而且整段橙色。这个项目 7 条标准里有 6 条命中，6 段加起来约 pt。这次还是误判：11 个任务都会写代码，只是验收要看证据，写不成一条命令。

方案：同一种提醒合成一行，换成 owner 的说法，默认收起，点开再看原因和涉及的任务（②③，只改 iOS 和 Web）。可选：让协调者能对提醒附一句说明，卡片直接引用，不再用琥珀色（④，要改服务端）。数据取自截图里的项目「Wiki 服务端执行与 System model」。
