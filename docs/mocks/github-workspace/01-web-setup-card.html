从 GitHub 建 workspace · 01 Web：设置卡的 Folder 步骤和会话第一行

今天要在机器上用 GitHub 的代码，只能选「A new folder」，然后在第一条消息里让 agent 去 clone（卡上原话就是 Ask for a clone … in your first message）。在托管 runner 上，私有仓库这样 clone 不下来，因为机器上没有凭据。 方案是在 Folder 步骤里加第四个选项 From GitHub：挑仓库 → 发送 → Orbit 先 clone，clone 好了会话才开始。 界面文案全部是英文；红色编号对应下面的说明。帧用的是 app 自己的样式表（index.css、ui/*.css、MachineSetupCard.css），DOM 是手写的。
① 今天机器 orbit@austin 上没有 workspace，打开它的新会话页。
② 方案Folder 步骤加第四个选项 From GitHub。部署没配 GitHub App 时不显示这个选项，其余三个和今天一样。
