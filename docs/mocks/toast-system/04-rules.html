2同时来了好几条

钉住的 ③临时位（1 条）
  • iPhone 同一时刻：顶部钉住的 ③（多条叠成一个，带 +N）＋ 下面 1 条临时的。新的临时 toast 直接替换旧的临时 toast。
  • 大屏：右上角最多 3 张，③ 在最上，临时的往下排，旧的先走。
  • ③ 不会被替换：只有 ✕、处理掉、或在别处解决掉才消失。
  • 同一个操作同一个 key：进行中 → 结果原地更新，不重新入场。
  • 2 秒内的重复合并：连点两次 Copy 只弹一次。
  • 不跟页面走：toast 挂在根视图上，切页面不清空（今天就是这样）。

4怎么写界面文案是英文，示例取自现有调用

成功：结果 + 对象

泛指的对象写进标题：Link copied、Schedule saved。具体的名字（条目、会话、任务标题）放第二行。

进行中：-ing + 对象 + …

Merging into main…、Committing 2 files…。完成后同一个 toast 改成过去式。

失败：Couldn't + 动作 + 对象

标题说哪一步失败，服务器原话放原因块，不当标题。统一用 Couldn't，不用 Could not / Failed to / … failed。

不写空话

Decided、Done、Success、Error、Failed 单独出现都不行：读的人不知道是什么事。

5动效 · 触感 · 读屏

动效

  • 进场：从上方 12pt 滑入 + 淡入 + 0.96→1，弹簧 0.35s
  • 离场：向上淡出 0.25s
  • 进行中 → 结果：图标交叉淡化（SF Symbol .replace），宽度弹性过渡，不重新进场
  • ③ 缩起：卡片收成胶囊，停在原位（matched geometry）
  • 减弱动态效果打开时：只淡入淡出

触感（iPhone）

  • ③ 到达：.error / 等你批准 .warning
  • 进行中完成：.success（你可能已经不在看了）
  • ① ②：不震——按钮本身已经给过反馈
  • 静音、低电量模式下照系统设置

读屏（VoiceOver）

  • ① ② 进行中：礼貌播报，读标题 + 第二行
  • ③：立即播报，连原因一起读
  • 缩起的胶囊读作「1 issue: Couldn't merge into main. Double-tap to expand.」
  • 动态字体放大时胶囊自动换成卡片，不截断标题
