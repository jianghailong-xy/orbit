What this frame decides

  1. An agent's sync is one row in the owner's upload tray, marked Agent sync. It reads local folder → destination. Only the folder's last name is shown, never the runner's full local path. It has no Pause or Resume: the owner doesn't stop a sync from here.
  2. The bar counts only the files that need uploading (new or changed). Files already the same in Documents are skipped and not counted. Rate and time left read like an owner upload.
  3. Under the bar: the file going up now, and the session that started the sync. The session name links to it.
  4. Files land in the folder as each one commits, with the session as the writer (rule 6). The list refreshes on drive.changed as it does today.

The header counts syncs and uploads together ("2 of 3") and sums their bytes. Clear finished clears finished syncs too.

What this frame decides

  1. Checking: Orbit is listing what Documents already holds and walking the folder, so the total isn't known yet. The bar moves without a percentage, and the count of files looked at so far goes up.
  2. Finished gives the count and size uploaded. A sync that found nothing new says Already up to date (d), so a repeat run doesn't look like it did nothing by mistake.
  3. Some files failed: the other files still went up. A warning mark and Details list what failed (frame 3). With --delete (S3) the line also says how many files went to Trash (f).
  4. Stopped: the agent stopped it, its session ended, or the runner sent nothing for 2 minutes. The grey bar keeps what got through. Files already uploaded stay in Documents.

Selecting a finished or stopped row opens its destination folder. Finished rows stay until Clear finished, for at most 24 hours.

What this frame decides

  1. Details opens a dialog: what was synced, from which session, and each failed path with its reason in plain words. Up to 100 paths are listed, then "and N more". Open Datasets goes to the destination. There is no Retry: only the agent can run the sync again (S1, one-shot).
  2. Selecting the row anywhere outside Details and the session link opens the destination folder, which is what the page behind the dialog shows.

Errors the owner might see: "Changed while uploading", "Documents has a folder with this name", "Couldn't reach Orbit after 3 tries". None names the runner's local path.
