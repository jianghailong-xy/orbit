          侧栏里没有哪一行亮着——和今天停在 Settings、Profile 页时一样，页面标题 Users 说明你在哪。Users 页本身一行不改。
          • 1顶部导航只留产品入口：Projects · Tasks · Wiki · Runners · Providers，管理员和成员看到的一样。
          • 2Admin 放进账号菜单，在 Settings 正下方、同一组：两行都是「打开一个设置页」——Settings 管你自己，Admin 管这台 Orbit 上的账号。只对 role = ADMIN 显示；点了去 /admin，地址不变，书签照用。不为它单开一组：为一行再加一条分隔线，菜单更重；「Admin」这个词已经说清它管的是谁。iOS 也是这么放的：Settings › Account 的最后一行就是 Admin。
          • 3折叠侧栏也能进 Admin：今天的图标栏只画前 5 个入口（topItems），Admin 根本不在里面；挪进菜单后，折叠、展开和窄屏抽屉用的都是左下角同一个菜单。
          • 4在 Users 页时侧栏不亮任何一行，和今天停在 Settings 页时一样，也不给头像加选中态。
          • 不做菜单头部不挂 ADMIN 标记；不加「Admin 搬家了」的一次性提示；macOS 侧栏里的 Admin 这次不动——只改 Web。
