Watching 里的会话并入 Tasks 停车条（web · 会话页）

你截图里 Watching 等的会话「Task: Android: …」，是 Tasks 里那条 Running 任务的执行会话（会话的 task_id 就指向它）； Tasks 头上的 👁 1 是 agent 对同一条任务的另一次等待。也就是说 agent 把一件事等了两次—— task_await（任务失败）+ session_await（执行会话结束或要人批准）——停车条就把它画了两行。

建议：被等的会话如果在执行某条任务，就当成在等那条任务，👁 落在那条任务的行上，Watching 行不再出现。 近 30 天本机 transcript 里，agent 等过的 110 个会话中 81 个（74%）都是这种「任务的执行会话」。 标题换成了示例文字（仓库公开）；停车条用仓库里的 index.css 画，就是线上的样子。虚线框 = 有变化。

③ 展开态，和另外三种情况

展开后还是一行一个任务；被等两次的任务也只有一行、一个 👁。右边三种是同一条规则落在别处的样子。

a执行会话属于别处建的任务

今天
Watching Task: iOS: share sheet saves the image to Photos Running
建议（展开）
Tasks 1 1 running · 1/2 done
Running iOS: share sheet saves the image to Photos elsewhere› Done Android: unread-reply badge on the session list 10h ago›
进卡时用任务自己的标题和胶囊（不是会话标题「Task: …」），年龄那一列写 elsewhere——和 10-07 时「别处建的、这里只是在等」的任务一样；等待结束后这行随之消失。

b这条等待很久没人检查

Tasks 1 1 running · 1/2 done
Not checked for 12m — the resume may be late.
Running Android: tapping a notification opens the session it names 25m ago› Done Android: unread-reply badge on the session list 10h ago›
原来挂在 Watching 展开里的那句提醒，原样搬到 Tasks 列表顶部（任务的等待今天就是这么显示的）；那一行和卡头的 👁 变橙。

被等的会话没在跑任务时（session_create 出来的子会话）

剩下的是没有 task_id 的会话：部署、只读核查、探针这类子会话，没有任务可以挂。 近 30 天本机：被等的 110 个会话里 27 个是这种（25%），几乎都出自运维 / 协调类会话（P10 中继、发版、探针）。

推荐 A。你截图这种（会话在跑任务）占 74%，A 已经让它从停车条消失；剩下的子会话本来就不是任务，留在 Watching 名副其实，而且只出现在开子会话的会话里。 如果你更想要「停车条永远不超过 3 条」，选 B：工作量中等，多一种行类型和一个词 session。

规则，和落地（按代价排）

规则

  • 被等的会话在执行一条任务（sessions.task_id）→ 等同于在等那条任务，画在那条任务的行上。
  • 同一条任务被 task_await 和 session_await 同时等：一行、一个 👁；其中任一条没人检查 → 橙色。
  • 那条任务不是这里建的：作为 elsewhere 行进卡，用任务自己的标题和胶囊。
  • 计数句只数任务；👁 N 数带眼睛的行。
  • 会话列表那一行、头部状态词：任务和它的执行会话算一个目标。
  • 服务端还没带新字段时：照旧画 Watching 行，什么都不丢。
  • 会话没在跑任务：见待定（A 保留 Watching / B 也并进来）。

落地（按代价排）

  1. 服务端（小）：WatchesService.named() 读会话时多带 task_id，把那条任务的标题和状态一起读出（和 TASK 目标同一套 running / queued）；SESSION 目标多一个可选字段 targetTask。不加表、不加迁移，watch-api pg spec 加一例。
  2. 三端客户端（中）：watchedTasks 把带 targetTask 的会话目标映射成那条任务；waitsBeyondTasks 不再算它；stripLine / watchingWord 先折叠再数。web lib/watches.ts，OrbitKit SessionTaskCard.swift + WatchProjection.swift，Android SessionTaskCard.kt + WatchProjection.kt。iPhone 折叠条（10-16）的 👁 标记跟着 beyondTasks 走，自动少一个。
  3. 夹具 + parity：session-created-tasks.fixture.json、watch-strip.fixture.json 各加三例（这里建的任务的执行会话 / 别处任务的执行会话 / 同一任务两次等待），三端 parity 测试读同一份。
  4. 只在选 B 时：卡片行加会话一类（会话胶囊、行尾 session、点开进会话），删 SessionWatchStrip / WatchingCard / WatchingStrip 和它们的 parity 用例。

文案

  • A：没有新文案，Watching / Tasks / elsewhere / Not checked for… 都是现成的英文。
  • B：多一个词 session（行尾）。

不变的
