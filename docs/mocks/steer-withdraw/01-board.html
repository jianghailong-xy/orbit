规则什么时候显示 Withdraw
消息下面写的这时消息在哪Withdraw
Sending…Orbit 收下了，还没交给引擎显示。服务器直接删，任何引擎都行
Waiting to be read（Claude）在 Claude 的队列里，模型还没读显示。以 Claude 的回答为准
Waiting to be read（Codex）Codex 收下了不显示：收不回
Read in this turn模型读到了不显示
Not delivered没送到不变：Put back in the composer
Queued for next turn排队等自己的回合不变：Cancel
  • 旧 runner、旧 Claude CLI、后台任务和 Watch 的唤醒：不显示。
  • 撤回失败（runner 15 秒内没回话、会话结束了）：提示 Couldn't withdraw the message 和原因，消息保持原状态；没送出去的撤回请求会被收回，不会事后生效。
怎么做
  1. 客户端发 DELETE /sessions/:id/turns/:turnId（和排队消息的 Cancel 同一个接口）。
  2. 服务器：还没交给 runner → 直接删。已在 Claude runner 手里、runner 声明了 session-claude-steer-withdraw-v1 → 排一个 withdraw 控制 turn、唤醒 runner、等结果。Codex 或旧 runner → 409。
  3. runner 对 claude 发 cancel_async_message，按 steer 帧上的 uuid（就是 turn id）指名；Claude 回答 cancelled: true 才删行，false 就是已读。
实测：Claude CLI 2.1.296 和 2.1.300（本机，Haiku），回合里跑 sleep 20，中途发两条，撤一条：
  • 撤回请求 < 10 ms 得到 cancelled: true，比工具结束早 16 秒；撤掉的那条没有回显、没进模型的回答，会话记录文件里也没有原文。
  • 没撤的那条照常送达，回显带着我们给的 uuid；已读的再撤 → cancelled: false。
