① 项目结束卡：画进项目 sessions 页

项目被记为 DONE 之后，项目 sessions 页顶部只有一张灰卡写一个「Done」：哪几条判据落了地、是谁记的，这一页都看不到。而这张卡三端其实都已经有了——「This project is done · recorded by Orbit · 6 criteria · 5 on main · 1 no code to land」——只是画在协调会话的对话里。要做的只是把它也画到这一页上：卡片本身不动，只挑一个位置。

三端一起改：Web 的同一个页（.session-project-page）、iOS、Android 都画同一张卡、同一个位置（macOS 没有这一页，不动）。卡片上的字和计数都是现成的：判据清单读项目详情里已有的 derivedDone，记录人读 doneBy，不加服务端字段。卡片不带按钮——回执、Reopen 都在项目页（页头 ⊞）。
