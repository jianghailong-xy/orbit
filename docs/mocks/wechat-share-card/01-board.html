怎么做到

微信抓取 /s/<token>
→
web 的 nginx：location /s/ 打开 SSI
→
子请求 GET /api/shared/<token>/card
→
回一段 head：title / description / og:*
点做法
浏览次数新接口不调用 recordView：微信抓一次不算「Viewed」。只有页面里的 JS 请求才计数，跟今天一样。
失效链接接口 404 → SSI 用 stub，输出原来的 <title>Orbit</title>。
其他页面location / 不开 SSI，那行注释原样留在 HTML 里，无影响。
安全标题本来就是拿着链接的人能看到的内容；HTML 转义；Wiki 关掉的账户照旧 404。图片地址用请求的 Host 拼成绝对地址。
