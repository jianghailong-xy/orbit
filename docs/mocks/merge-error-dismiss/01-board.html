Closing clears the failure, not just the strip: the red Retry button goes back to a plain Merge to main, or to ✓ In main when the commits already reached main another way (as this branch's did). Stored on the server with the session's merge state, so it stays closed after a reload and on the Mac, iPhone and Android apps. A new failure shows again: the next merge that fails brings back a fresh strip.
