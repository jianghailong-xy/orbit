① 合入 main：从协调会话挪到项目 sessions 页

现在，合入 main 的请求卡和回执都画在协调会话的对话里（左边三屏）。你在会话列表点项目，进的是项目 sessions 页，可这一页只有进度条。要合入，得先进协调会话，在对话里找到那张卡，再打开详情才能按；合完之后，回执又夹在聊天中间。
方案：把合入当成项目的一件事，不当成对话里的一条消息。请求、合入中、受阻，都是项目 sessions 页顶部同一张合入卡的不同状态；合完卡片收起，时间线里留一行；协调会话里每个时刻只留一行事件（右边两屏）。数据不变，仍然读 promotions/current 和 promotions/merged，变的只是画的位置。
