Idle icon: the original speech bubble vs the one live now

Left: the bubble idle rows wore before 11/25 on web, antd MessageOutlined, drawn from its own path in @ant-design/icons-svg. Right: the rectangle production draws since today (ccd43103ea). Same rows, same 16 px icon size, same grey (--text-3). Mac and iOS draw Apple's SF Symbol message (a round bubble, no dots), which can't be rendered on this Linux box.

The icon alone, at row size and enlarged

Original: round bubble with three dots
  • The real shape the product shipped for months; people who used it before 11/25 know it.
  • Close to Apple's round message, so web, Mac and iOS read as one icon.
  • The three dots read as "typing…" / "someone is writing", a hint of activity on a row that is idle.
  • Busier at 16 px: four shapes in one glyph, heavier than the clock and the spinner.
Live now: rectangular outline
  • Quietest of the two: one thin outline, the same weight as the Queued clock beside it.
  • No dots, so it says "a conversation", not "someone is typing".
  • New: it was drawn for the board, not taken from the early product.
  • Differs from Apple's round message; Mac and iOS would need a custom glyph to match.
