待定 · 落地要你拍板的三件事
待定 A · @ 里除了你开的会话，还列谁
建议 A1 你开的会话 + 项目协调会话；任务运行、落地会话不列。人引用会话的 494 次里，协调会话 89 次，值得留；任务运行 134 次，多是从卡片或通知里点进去后粘贴的，粘贴照样认。
A2 只列你开的会话，协调会话也不列：更干净，但「你为什么没跟进」这类问协调会话的话要靠粘贴。
待定 B · 退格删整个，要不要先「选中」一下
建议 B1 一次就删整个（Slack、Notion 都这样），⌘Z 撤回。
B2 第一次退格只把 chip 选中（变深），第二次才删：不会误删，但每次都多按一下。
待定 C · 弹框放哪
建议 C1 跟着光标、宽 480：短句里一眼就看到。
C2 仍贴在输入框左上角、宽 480：位置固定，长草稿里离光标远。
落地（按代价排）
  1. @ 不列任务运行和落地会话（客户端过滤，taskId / 会话类型；一行代码）。
  2. 退格 / Delete 删整个 chip，⌘Z 可撤回（用浏览器自己的撤回栈：一次 insertText 式替换）。
