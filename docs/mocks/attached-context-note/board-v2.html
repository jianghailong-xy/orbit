不带（推荐）：这行说的是「Orbit 加了什么」，不是「结果怎样」。结果回复里会说（这一条就是：哪个分区失败了、要不要重跑）。悬停能看到数字，点开能看到每一个。
带，灰色：不点开就知道有没有失败；代价是这行长一倍，带了两块时更长。不上色，所以不抢你的话。改动只有一行。
