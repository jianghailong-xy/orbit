SCHEDULED RUN GRANTS / 08

安全：授权承诺到哪里

§10 · 紧凑边界表；风险不藏在“已授权”三个字后面。

边界规则读图结论 / 例外
授权不是沙箱前缀不约束参数；仓库可编辑，测试可执行刚改过的代码。git fetch 可带 --upload-pack；仓库代码标签必须显示。
级别禁令优先CHECK_ONLY 禁写，只存 EXACT；OPEN_PR 不可 merge / release / deploy。Orbit 工具由级别控制；门口在所有引擎检查命令 deny list。
拒绝列表不存 shell / 裸解释器 / env / xargs / sudo / eval / exec / nohup / timeout / time / nice 前缀。不存工具通配符或 mcp__orbit__*；不可读语法拒绝。
凭据与网络网络条目直达 runner 可达地址，含内网；v1 只标注，不阻断。字面密钥拒绝存储；环境变量引用可用。主机凭据仍是实际边界。
LAND 路径墙必填路径；** 要明说全部路径。重命名检查新旧两端。.github/**、.claude/**、.orbit/**、CLAUDE.md、AGENTS.md、submodule 必须点名。
引擎边界只管引擎送到门口的请求；引擎认定安全的操作可能不经过门口。DeepSeek 不写文件的命令（含网络）绕过列表，卡上明说；OpenCode 编辑级别拒绝。
作用域与自扩权只读本次快照；workspace rule 和 settings 不应扩入授权。运行只能提议；DECLINED 不反复问；P4 再加引擎沙箱。
