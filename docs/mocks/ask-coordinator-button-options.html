Escalated 卡上的「Ask the coordinator again」：今天 / A / B

这颗键画不画完全由服务端定：卡片只画服务器列出的门（原生 row.actions.contains(.askCoordinatorAgain)， web 同一份 openItemActions），而 askable 今天 = coordinatorEnabled && 绑定 && 会话未结束， FineWeb 这个项目开关是关的 —— 所以卡上没有它（①）。② 是 A：判据跟绑定走（跟 badge 同一条），按下去把这一条 turn 投给那个会话； ③④ 是 B：不动权限语义，把「为什么没有」说出来，并把 Automatic 开关补到手机的项目页。 两颗键的顺序/权重不是这里定的：ExceptionCards.presses 让领头的两颗当主键与次键，其余降成链接，卡自己的 Chat about this 排在服务器那几颗之后、Mark as handled 最末。

我的建议是 A，但它有一个前提值得你先点头：它把「开关」的意思收窄成 「别自行动手」——自动投递、四个 wake producer 一律照旧不动，只有你自己按的这一颗键能把一条 item 送到那条会话面前。 如果你要的是「协调者关着的时候，任何东西都不该进那个会话」，那就选 B，并把 ④ 那颗开关当成真正的出口。
