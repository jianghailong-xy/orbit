  1. 1今天：Mac 列表是一个平铺 ForEach，没有分组、没有文件夹，置顶只是行左边一条蓝线。
  2. 2文件夹行：和 web / iPad 同一行：文件夹图标、名字、里面会话的状态（等你=橙色数字，运行中=转圈）、会话数、›。只在 Open 和 Completed 出现；Trash 里没有。
  3. 3Pinned 标题：整条是按钮，› 展开时朝下、收起时朝右；收起状态记在本机（和 iPad 同一个键），换 workspace、重启都保持。文件夹页里的 Pinned 共用这一个开关。
  4. 4文件夹页：占会话列，顶栏 ‹ 返回、标题是文件夹名+workspace 名、⋯（改名/删除）、✎（新会话直接建在这个文件夹里）。右边详情不动。再点侧栏里当前 workspace 也会回到列表。每个 workspace 记得自己停在哪个文件夹。
  5. 5右键：Rename… / Delete Folder…，和 iPad 长按、文件夹页 ⋯ 是同一套对话框和文案。删除文件夹不删会话，会话回到列表。
  6. 6会话右键 Move…：和 iOS 长按菜单同一位置（Complete 之后、Delete 之前）；项目行的右键也有 Move（搬的是 coordinator）。Trash 里没有。
  7. 7Move 面板：就是 iOS 的那个：本 workspace 的文件夹（当前的打勾、New Folder…），下面是搬到其他 Workspace（点进去选那边的文件夹并确认）。Mac 上是窗口 sheet，Done 在右上。
  8. 8New Folder…：iPhone 在 ≡ 菜单里，Mac 放在工具栏设置齿轮旁边；Trash 视图里置灰（那里不画文件夹行）。
