Read 一张 .png：图片到达之前，卡片里是什么

iOS 会话窗口 · 同一张卡片的四种样子。左上是你截图那一帧（现在），其余三种是改法。

卡片是「自动展开」的：结果里带 image 块它就展开（web 同款）。超过 64KB 的图， 服务端只留下 image 块、剥掉里面的字节（这两张 mock 图 443KB / 447KB，都被剥）； 字节要等客户端回取那次 ~400KB 的 refetch 才到。中间这一段，卡片就是空的。

现在展开的卡片是空的 箭头朝下、有边框、有左侧蓝条，里面却没有一行东西 —— 读者以为图挂了，或者以为这张卡坏了。

推荐 A按图片上限尺寸占位 + 转圈 占位块正是图片将要出现的位置（iOS 上图片上限 300×360），落位时几乎不跳；转圈说明「正在取」。

备选 B小灰块，静默（120×90） 和「已发图片」缩略图等待时那块一模一样，改动最小、最轻；代价是图片落位时会把下面的内容顶一下。

备选 C只写一行字，不占位 最省地方，也最不像一张图；落位时顶得最多。要加文案，还得定用哪种语言。
