翻译失败的消息：加「Cancel」（Web / macOS·iOS / Android 同一改法）

今天翻译失败、没发出去的消息只有 Retry 和 Send as written 两条出路：不想发了就没法撤，消息一直挂在对话里。
产品上它本来就是“还没交给 Agent 的、我自己的话”，和排队中的消息、刚发还没被 runner 取走的消息是一回事——那两处已经有 Cancel，按了以后话回到输入框，可以改了再发。所以这里用同一个词、同一个行为，不发明新概念。界面文字英文，标注中文；手绘，颜色取自 .chat-translate-foot.is-error。
