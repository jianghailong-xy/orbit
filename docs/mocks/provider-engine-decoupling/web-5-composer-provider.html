5 · 会话里切换 Provider（Web）：只列会话 engine 能用的凭据；菜单标题取自会话自己的 engine

点 composer 里的模型（如「DeepSeek V4 Pro Default」）打开的菜单，main 上的结构未变。今天菜单标题和可切换的 provider 都是从会话当前那把 key 的 runtime 推出来的：key 被删或停用时推不出来，就当成 Claude；切到另一个 runtime 的 provider 时标题写成「Claude Code → Codex」。改后会话自己记着 engine（项目验收第 2 条），标题直接读它，Provider 子菜单只列这个 engine 兼容的登录、账号池和 key；engine 换不了，要换就开新会话。数据同板 1、板 4。灰色字母标现在的问题，橙色数字标改动。
