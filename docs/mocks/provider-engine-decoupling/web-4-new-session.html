4 · 新会话（Web）：先选 engine，再在 Provider 菜单里选这个 engine 能用的凭据

今天的新会话已经是「中间选 engine、composer 的模型菜单里选 Provider」两步，但 Provider 菜单只列「跑在同一个 CLI 上」的 key：DeepSeek key 只出现在 Claude 下面，DeepSeek Harness 只有自己那把 Harness key，OpenCode 下的 key 是用模型名 orbit-<slug>/<model> 编码出来的。改后 Provider 菜单按兼容表列：凭据来源分三组（这台 runner 上的登录、账号池、你的 key），同一把 DeepSeek key 出现在 Claude Code、DeepSeek Harness、OpenCode 三处，DeepSeek Harness 下可以在两把 DeepSeek key 之间选。示例：工作区 orbit 在 hpc 上；hpc 上 Claude Code 登了两个账号（Default、Work），有账号池 Claude accounts；key 和板 1 一样。engine 名按待定项 A（板 1 ③-2）。灰色字母标现在的问题，橙色数字标改动。
