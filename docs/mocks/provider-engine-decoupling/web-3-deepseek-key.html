3 · DeepSeek key 的页面（Web）：余额照旧；写出这把 key 能用的 engine；停用、删除影响它在所有 engine 上的会话

在 Infrastructure 的 API keys 里点一把 DeepSeek key 的 Edit 进来。今天这页说「Runs on Claude Code」；停用就是关掉开关再 Save，没有确认；删除只问一句「Delete DeepSeek?」。合并以后一把 key 同时挂在三个 engine 上。按契约 §3.6，停用或删除会让它在所有 engine 上的会话都停下：会话保留原 engine，重新启用、或在 Provider 菜单换一把兼容的凭据后，从原处继续，不会落回 runner 自己的登录。改 endpoint 或协议时，如果有未结束的会话或任务 pin 在用新协议跑不了的 engine，就拒绝保存。拒绝的文案用契约 §3.7 的 PROVIDER_DIALECT_IN_USE。要不要在停用、删除前先弹窗说明影响，是待定项，见 ②。灰色字母标现在的问题，橙色数字标改动。
