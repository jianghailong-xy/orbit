iOS 5 · 会话里切换 Provider：只列会话 engine 能用的凭据；菜单标题来自会话自己的 engine

会话页点 composer 里的模型打开的菜单，和新会话（iOS 4）是同一个菜单。今天的标题和可选 provider 都从当前 key 推出 runtime（executingRuntime）：Harness key 只能换 Harness key；key 被删时推不出来就当成 Claude；已结束的会话挑了别的 runtime 的 provider，标题会写「Claude Code → Codex」。改后标题读会话的 engine，Provider 只列这个 engine 兼容的凭据，engine 换不了。数据同 Web 板 5。灰色字母标现在的问题，橙色数字标改动。
