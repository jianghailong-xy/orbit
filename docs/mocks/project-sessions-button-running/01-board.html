项目会话按钮（⊞ N）显示“有东西在跑”

所有者 2026-11-17：协调者会话标题栏上打开项目会话弹窗的按钮，看不出会话和落地正在运行。弹窗里写着 6/7 done · 1 running、Landing 卡在 checking，按钮上只有 ⊞ 7。下面四个画法，每个都画在三种状态上。手机是画的（深色，同截图），不是截图；英文是上线文案，中文是说明。分支上已按 A 写了代码（3552495d5），选别的就改。

1 · 四个画法

“按钮”是 ⋯ 左边那一格；返回键和 ⋯ 不变。

2 · 什么时候亮

亮：与弹窗里的“在跑”一一对应

项目里的弹窗里怎么画按钮
成员会话在跑（含协调者自己、它的 Agent 在跑）行首转圈；进度行 · 1 running亮
落地会话在跑Landings 行蓝色环亮
落地作业在途（integrating / RUNNING）Landing 卡，checking · output 235s ago亮
合入 main 在检查、已确认在合、重查合入卡 Checking / Merging亮

不亮

项目里的为什么按钮
只有排队的作业（queued）还没开始；弹窗也不画转圈不亮
停着、只开着后台进程的会话弹窗画“呼吸”，不是转圈：说的是“有作业”，不是“在干活”不亮
等你决定（审批、卡片）已经由左上角 ☰ 的橙色数字和会话自己的橙点说不亮
合入被挡住（Can’t merge into main yet）在等决定，不是在跑不亮

怎么保持新

弹窗关着时，会话页按弹窗本来的节奏读：成员每 4 秒对一次本地列表；落地和合入有东西在跑时每 4 秒、否则 15 秒或有提示时读。App 在后台时都停。弹窗开着时这三项会读两遍（会话页一遍、弹窗一遍）——可以改成弹窗开着时会话页这边停。
