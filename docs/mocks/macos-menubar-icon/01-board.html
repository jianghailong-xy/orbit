方案 A · 轨道建议

倾斜的轨道环、中间一颗行星、环上一颗卫星，取自 App 图标的外圈（终端块换成行星）。16 px 下依然清楚，轮廓和系统图标、其它应用的图标都不撞，和 Dock 里的 Orbit 也能对上。

方案 B · 完整标志

和 App 图标几乎一样，在 Retina 屏上辨识度最高；但中间的 >_ 在 1x 外接屏上会糊，整体也比旁边的图标“重”。

状态：卫星有或无

没事时只有环和行星，有会话在跑时卫星出现，要你处理时再加数字。比空心/实心好认，但实际大小下仍然偏细微，要盯着看才发现。

状态：只看数字建议

和今天一样，只有要你处理时才变化。菜单栏里真正需要一眼看到的只有“要你处理”，数字已经足够。

落地（按代价排）

  1. 把选中的图标导出成矢量 PDF 模板图，放进 src/macos/Assets.xcassets，勾选 Template（一份文件同时适配浅色和深色）。
  2. OrbitApp.swift 里的 MenuBarExtra label 从 systemImage: "circle.hexagongrid" 改为 Image("MenuBarIcon")，数字仍用 Label。
  3. （仅当选“卫星有或无”）多导出一张不带卫星的变体，按 menuSummary.running > 0 切换。
