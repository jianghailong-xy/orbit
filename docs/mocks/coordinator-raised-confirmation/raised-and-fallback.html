这张卡和今天的不同

  1. 开头块在最前面：协调者的结论（judgment 原文），接着是它要你决定的点（needsYou），带选项和推荐项。
  2. 框上写明作者 Coordinator，这是它的话，不是 Orbit 的话。
  3. 执行会话的证据折叠着：What counts as done、What the agent said，仍由 Orbit 从行里取，点开就看。
  4. 按钮不变：只有你能按，不预选，不禁用。
  5. 呈上时手机响一次（§13 A6），正文只有 Orbit 的话，不带协调者写的字。
  6. 没有要决定的点时，开头块写 Nothing else needs your decision.

兜底卡

  1. 标签 Not reviewed by the coordinator 用琥珀色，比普通信息醒目。下一行写原因，全部是 Orbit 的话：
    • No answer within 2 h.
    • The coordinator’s session ended before it answered.
    • The coordinator stopped without answering.
    • This project has no coordinator conversation.
    • Automatic was switched off for this project.
    • This project’s coordinator is paused.
    • The coordinator could not be reached.
  2. 这张卡沿用原有的顺序：执行会话的证据在前，因为没有协调者的判断可看。
  3. 兜底的确认卡不响手机，出现在 needs-you 里（§5 N6）。
  4. 之后协调者补交了记录，这张卡就地变成上面那张（§13 A7），不再响。

持有和兜底怎么读出来

  • 工具权限审批不走这里，照旧直接到你面前（§18 U1）。
  • 持有中的问题不亮、不响、没有飞书卡；协调者用 session_reply 回答，答案直接回到 run 卡着的那次工具调用。
  • 协调者答不了时用 ask_owner 带上推荐项问你，你看到的是协调者的问题卡，不是这张。
  • notify 没有卡片；兜底时推送正文开头是 Not reviewed by the coordinator · 。
  • 持有和兜底都在读的时候算（§16 F1），没有新的定时任务。
