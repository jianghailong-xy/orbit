Dialog — a task that simply stopped
Reopen this task?

Reopening puts this task back to Open and changes nothing else: its history, its evidence, its dependencies and the project it is filed under stay as they are. It is how an attempt that stopped is picked up again as this task, rather than as a new one filed beside it.

If this task serves one of its project's acceptance criteria, the project stops reading as done while it is open again.

Reopen this task?

Reopening puts this task back to Open and changes nothing else: its history, its evidence, its dependencies and the project it is filed under stay as they are. It is how an attempt that stopped is picked up again as this task, rather than as a new one filed beside it.

This attempt is recorded as superseded or dropped, and reopening clears that record — a replaced attempt cannot be run again until it is gone.
