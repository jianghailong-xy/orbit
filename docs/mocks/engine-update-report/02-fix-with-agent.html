要你定的四件事（每项给了建议）

1. 点了之后：直接开工（建议）：建好 session 并把上面这段作为第一条消息发出去，页面跳到会话里。另一种：只把这段填进新 session 的输入框，你看过再发。Agent first 的意思就是不用你再按一次。
2. 在哪个 workspace：这台机器上你最近用过的 workspace，不建 worktree（建议）：修的是机器上的引擎，不是仓库代码，不需要隔离的 checkout。机器上一个 workspace 都没有时不显示这个入口（这种机器一般连更新都还没跑过）。
3. 用哪个引擎：这个 workspace 的默认引擎；坏的正好是它（比如 Claude Code 跑不起来）时，换这台机器上另一个已登录的引擎（建议）。一个可用的都没有就不显示入口。
4. 第一条消息谁来拼：服务器（建议）：用 runner 记下的完整失败细节（版本、命令、跑了多久、最后输出、二进制路径），比卡片上那一行字多得多；网页、macOS/iOS、Android 都只调同一个接口，说法不会分叉。

范围

出现入口的只有失败（红色那几种）；“owned by another user” 这种需要安装者本人处理的，agent 没权限修，不放入口。网页、macOS/iOS、Android 同时做。
