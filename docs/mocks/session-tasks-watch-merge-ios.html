Watching iOS 构建会话 Working

Watching 卡只在有非任务目标（会话等）时出现，只列那些目标；任务一律归 Tasks 卡。这种情况少见，单独一行比硬塞进 “Tasks” 更诚实。

规则

  • 卡内任务 = 本会话创建的 ∪ 本会话 watch 的任务目标，按 task id 去重。
  • 被观察的行：胶囊后一列 👁（tint）；stale 时橙色。
  • 排序：被观察的在前，其余保持服务端顺序（replaced 折叠规则不变）。
  • 卡头：Tasks + 👁 N（N>0 才显示）+ 原计数句；单任务时仍是“名字 + 胶囊”，被观察就在胶囊前加 👁。
