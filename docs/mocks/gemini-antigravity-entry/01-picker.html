新建会话的选择器：用 Gemini 只有一个入口

内置项代表 CLI 自己的登录（订阅额度），provider 代表 API key。Antigravity 在 Orbit 里没有自己的登录方式，只认 Gemini API key，所以默认不单独列出：Gemini provider 就是在 Antigravity CLI 上跑 Gemini 的入口。只有环境里已经放了 GEMINI_API_KEY，内置 Antigravity 才出现。runner 跑不了时，在选择器里就直接说明原因。
