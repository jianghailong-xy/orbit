实现要点

位置改什么
apiserverprovider 列表和 runner 数据里带上每台 runner 对 Antigravity 的就绪状态（是否声明支持、agy 是否安装、版本）；按「runner 环境或 workspace 环境变量里有 GEMINI_API_KEY」算出内置 Antigravity 是否可选，web 和 macOS/iOS 共用这一个结果
web选择器（sessionProviderChoices.ts）按上面的结果显示或隐藏内置项，补「Update runner」状态和默认模型文案；Providers 页 runner 卡片加 Antigravity CLI 一行（RunnerEngines.tsx），Gemini 一行补状态说明；会话提示（Transcript.tsx）换文案和按钮
macOS / iOSSessionProviderChoices.swift、EngineAuth.swift 同步；OrbitKit 的对照测试会读 web 源码，两边要一起改
runner不用改：doctor 已经按环境里有没有 GEMINI_API_KEY 上报 Antigravity 的 auth，也已经会安装 agy
