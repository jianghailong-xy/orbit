落地（按代价排）

  1. iOS / macOS 的行：ProjectDoneCards.swift 的 criterionRow——状态挪到正文下方、3 行折叠、点击展开。文案、计数不动。
  2. iOS / macOS 的小卡片 + 弹窗：ApprovalCards.swift 删掉一行强制整张显示的代码，卡片走已有的“预览 → 弹窗”路径；ConsoleView.swift 让 “1 open question” 打开弹窗；两个接线测试跟着改。OrbitKit 全套 5528 个测试在 Linux 通过；SwiftUI 本身在 Linux 编不了，没在真机上看过（可推分支跑 macOS/iOS 构建，约 25 分钟）。
  3. Android（与 iOS 一致）：DoneCriterionRow 状态挪到正文下方、3 行折叠、点击展开；会话里 CoordinatorDoneCard 用已有的预览卡（CardPreviewView），点开是底部弹窗，按钮钉在底部；顶栏 “open question” 打开同一个弹窗。
  4. Web：桌面宽度下右栏状态不挤，暂不动。
