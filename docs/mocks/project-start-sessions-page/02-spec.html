② 启动行：结构、状态与文案

启动行长在进度卡里，状态行下面。它只做一件事：把你带到起始卡。真正的启动仍然只有起始卡上的 Start the project 一个入口。

结构

两种状态用同一副骨架：状态行 → 请求行 → 按钮。已请求时多一行建议（③）。卡片底色不变，靠点的颜色和按钮的实心/浅色区分轻重。

什么时候画、点了去哪

判断只用一个函数：StartProject.pageRow(status:started:openItems:)。项目页 Open items 里的 Start 行用的也是它，所以两处的说法不会对不上。

新的画法

规则

  • 不算 Needs you。客户端和服务器本来就不把启动请求算进角标、抽屉计数和推送（SessionGrouping.countsOnlyAStart），因为启动不卡住任何事。这里也不加徽标，卡片不变色，只用橙点。
  • 已请求时，就在这一页打开起始卡，不跳进协调会话去找。这和今天把合入卡搬到这一页是同一个思路：需要你处理的事，在这一页就能做完。Chat about this 只留在会话里那张卡上；sheet 下面就是协调者那一行，想先改再启动就点它。项目页 Open items 里的 Review 现在还是跳会话，以后可以统一。
  • 不会和合入卡同时出现。没启动的项目没有东西可合。位置上也不冲突：启动行在进度卡里面，合入卡在进度卡下面。
  • 数据。/projects/sidebar 多带一列 startedAt（null 就是没人启动过）；页面只在项目没启动时读 open items，随页面每 4 秒轮询一次；启动以后就不再读。
  • iPad 上这一页会替换会话栏，起始卡用 form sheet 弹出。Web 的项目 sessions 视图，在进度条（.session-project-page-progress）下面同样的位置，按同样的规则画，点按打开现有的 StartProjectCard 弹窗。
  • 辅助功能：②③ 合成一个元素读出来。按钮的 hint 是 “Opens the start card: the criteria, the plan and how it runs.” 字号调大以后，③ 允许换行，不截断。
