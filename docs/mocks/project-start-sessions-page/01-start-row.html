① 未启动的项目：进度卡下面放启动按钮

现在，还没启动的项目在 sessions 页上写的是 “0/5 done · 0 running”，配一条空进度条，看不出它在等你启动，这一页也没有启动入口（左一）。
方案：项目没启动时，进度卡先写明 “Not started”，下面加一行启动。协调者已经请求启动时，这一行用实心蓝 Review and start；还没请求时，用浅蓝 Start…。两个按钮都打开现有的起始卡（sheet），在那里看判据、计划和跑法，按 Start the project 才真正启动。启动以后这一行收起。
数据取自截图里这个项目的真实状态：5 个任务、5 条判据，协调者还没发启动请求（它在对话里问你 “Should I send the start request?”）。
