Web · Infrastructure 重排：机器和自己配的 provider 是视觉重心，引擎概览退到页尾

现在这一页从「需要处理」提醒条和 7 张引擎卡开始：机器在约 840px 以下，自己的 key 在约 1330px 以下，一个 900px 高的窗口里一台机器也看不到。改后的顺序是 Machines → API keys（每个厂商一张卡）→ Account pools → By engine（一行一个 engine 的列表）。登出的 engine 不再单独起一条提醒，而是画成机器卡上的橙色 chip + Sign in；每台机器的卡头多一行 chips，说这台机器能跑什么。整页从 2900px 缩到 2080px。所有网页帧都是真实页面截图（本分支 src/web 跑在 vite 上，示例数据按你 10-25 的截图搭：4 台机器、5 个厂商 6 把 key、1 个 Codex pool、4 个登出的 engine、1 个没装的 Cursor CLI；名字是样例）；「改后」是同一页面加上 prototype.patch 的原型代码，只为出图。灰色字母标现在的位置，橙色数字标改动。
