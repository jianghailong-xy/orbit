Landing 卡：和合入卡同一套语言

现状（图 1，你 9:07 的截图）：项目 sessions 页的进度卡里只有一行 Landing——圈 + 词 + 状态 + 标题 + 三个时间。同一个页面上，合入这件事是有卡的语言的（Merge check / Merge into main? / Merging… / 合不了）：说得出对象、进度、要不要你管，也有能按的门。落地这行没有：说不了落到哪条线；同时有两个作业时只写 “2 jobs”；没有上报时也只是把词换成 Timed out。
方案 A（图 2–4）：把这一件作业画成和合入卡同一张卡——在途用 Merge check 那种灰卡（图 2、3），没有上报用「合不了」那种琥珀卡加 Retry（图 4）；位置不变，在进度卡下面自己一张；没有在途作业时这张卡不存在，页面和现在一样。方案 B：只想在要人管的时刻成卡——平时保持图 1 的一行，只有图 4 那种状态才换成卡。两种方案的新语言是同一套（图 2–4）。
