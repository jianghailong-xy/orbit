2页头 “Add key” + 每组一个 “Add”，6 个同样的带框按钮。页头 “Add key” 是唯一的带框新增按钮。分组的 “+ Add” 改成无框文字按钮（--text-2，鼠标停留时出背景）。SettingsProviderPages.tsx
3每行 “Edit” + “⋯” 两个带框按钮，右侧成了一列按钮墙。整行可点打开编辑页，鼠标停留时整行出背景，行尾 “›” 提示可进入。“⋯” 改成无框图标按钮，菜单里是 Edit、Delete（危险操作放最后，用分隔线隔开）。ProviderKeyCards.tsx
4余额的刷新图标是全页唯一的蓝色按钮，可点区域约 16px。改成灰色，可点区域 24px，鼠标停留出背景和提示 “Refresh balance”。“⋯” 菜单里也放一份。ProviderKeyCards.tsx
5按钮在多行卡片里垂直居中，和第一行的名字错开。行操作统一和名字那一行顶对齐，单行、多行的卡片都一样。ProviderKeyCards.tsx / css
6元信息换行时，分隔点 “·” 留在上一行末尾。分隔点跟着下一项走，换行后出现在行首。ProviderKeyCards.tsx
