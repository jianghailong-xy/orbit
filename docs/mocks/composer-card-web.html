web 这边具体变什么

  • 框：r10 → r24，1px 描边 + 两层很淡的阴影；聚焦时描边从品牌蓝改成加深的灰，和 iOS 一致。
  • 字：14px → 15px，独占整宽。「+」和发送从字的左右两边挪到下面的控件行。
  • 发送：32px 的圆（现在是 r6 的方块）；颜色仍是品牌蓝。
  • 设置：Provider、Model、Effort、Fast 四个下拉合成一个「Opus 5.5 Max」按钮，下拉里分组（见 ③）。
  • 读数：Plan 条和 Context 环带着百分比，挪进控件行，放在发送键左边；Context 仍然在最右（紧挨发送）。
  • 附件：从条带最上面挪进卡里（见 ②）。

不变的

  • 「+」菜单的内容与顺序、/ # @ 补全浮层、拖拽改高度、Enter 发送 / Shift+Enter 换行、历史 ↑↓。
  • 上面那叠条（Watching、Background、分支条、回复条、项目意图条）的位置和样式。
  • 停止 / 排队 / 回复的判定逻辑，只换外观。
