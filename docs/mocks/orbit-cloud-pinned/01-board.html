Orbit Cloud: pinned first and marked in every machine list

Orbit Cloud is the account's managed runner. Today it sits wherever the drag order puts it, which is near the bottom in the owner's list. It only looks different when its page is open, and that look is the same "selected" tint every row gets. The change: it always comes first, it looks different at rest without looking selected, and your own machines follow it in your own order.

1 · Settings → Machines group

Option A uses a brand-colored cloud icon, a bolder name and a hairline under the row. Option B adds a brand outline to the pinned row. Option C adds two small headings.

4 · Rules (Option A)

RuleDetail
PositionOrbit Cloud always comes first in every list of machines: the Settings Machines group, the account menu's Machines submenu, and the native clients' machine lists. Ordering happens on the client. The saved order isn't changed.
DragThe pinned row has no grip and can't be dropped on. Reordering moves only your own machines, and Orbit Cloud stays first whatever its saved position.
MarkA cloud icon in the brand color (replacing the drive icon) and a semibold name. The background stays plain at rest. The tinted fill still means "this page is open."
SeparatorA hairline right under the pinned row, shown only when you also have machines of your own.
StateNo change: Ready / Asleep / Waking up… from the shared managed-runner display.
No Orbit CloudWithout a managed runner (switch off or older server), the lists look exactly as they do today. The existing "Set up" entry already sits at the top of the group.
Icon noteProviders → "API keys" already uses the cloud icon. Since it's in a different group that's acceptable, but an Orbit-mark glyph is an alternative if the overlap bothers you.
