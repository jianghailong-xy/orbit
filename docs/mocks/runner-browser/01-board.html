Orbit Cloud 浏览器：看 agent 的 Chrome，必要时接管

Orbit Cloud runner 里的 agent 用真的 Chrome 干活；你在自己的浏览器里实时看到它的画面（WebVNC），不对劲时点 Take control 接管；也可以自己在 Settings 里打开它登录网站，登录态一直保存，agent 直接用。整台 runner 共用一个浏览器（已定）。 只给 Orbit Cloud（托管 runner）用，默认部署关闭。设计文档：docs/runner-browser-design.md。界面文案英文，注释中文，页面内容是演示数据。

安全：不开入站端口、不改防火墙；VNC 只在容器内 unix socket 上，每路流先过 apiserver 鉴权；不录屏。保存的登录在 runner 卷上，runner 上所有 agent 都能用，Settings 里可一键清除。
