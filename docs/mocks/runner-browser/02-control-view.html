三个方案，选 C

A 窗口内浮层B 抽屉拉宽C 自己的标签页 建议
地方大中，左边留一条最大：整个标签页，可全屏、可拖到第二块屏
同时看对话不行（盖住）勉强能：两个窗口并排
实现新浮层，画布挪过去Drawer 加宽度档一个新页面，只放现有查看器 + 细栏
注意——每台最多 2 条流：开标签页时让抽屉那条让出来
建议 C。地方最多、能和会话并排，而且做起来最省：查看器本来就是独立组件，新页面只是把它单独放出来。A 不用做了。

不变的

远端屏幕保持 1280×800；不跟着查看器变尺寸（agent 共用同一块屏）
输入共享输入，不打断 agent（P3 = B）；Done / 关标签页只是停止发输入
谁能看只有 runner 的主人（P4 = A）；最多 2 条查看流；标签页地址给别人也打不开
开关关着时页面 404，入口都不出现

落地（按代价排）

1去掉 --no-sandbox 提示条：runner 启 Chrome 时加 --test-type（只关这类提示）；随 runner 镜像发
2粘贴：接管时 ⌘V / Ctrl+V 送本机剪贴板文字，远端复制的回到本机
3标签页 /runners/:id/browser：只看 / 接管、Fit / 100%、Done；Open browser 和 Take control 打开它；抽屉加 Open in new tab，让出查看流
4组件测试 + 真页截图对比本板
