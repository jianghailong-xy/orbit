① 直进 main 的项目：卡为什么出、怎么才能不出

场景取自 2026-11-10 的「核实卡片显示规则」会话：项目选了 Directly into feature/v1.1.1，Automatic 开着，交付方式是默认的 Orbit lands it。规则（契约 M7）是：直进 main 的项目，Orbit 每次合入 main 都要问你；不出卡的唯一办法是 The agent pushes it（AGENT_PUSH，修订 29）。这个开关三端 10-29 就有了，但卡片上看不到为什么问你，Automatic 的说明也没指向它。所以用户以为 Automatic 坏了。

现在建议
卡片为什么问你不说。检查中只有 “Asks you when it passes.”一行理由，只在 Automatic 开着却仍然问你时出现，并直接带到 Delivery
Delivery 放在哪排在 Main branch 下面、Automatic 上面，和 Tasks land on 隔着一行紧跟在 Directly into main 下面：它只对直进 main 的项目有意义
两种交付方式各自的代价只说谁去推写明有没有合并卡、合并检查谁跑、Orbit 做什么
Automatic 的说明“always asks you … never merges by itself”，到此为止后面补半句：要不出卡，改 Delivery
会动到的文件（只改文案和排列，不改规则）：src/web/src/lib/projectStart.ts、ProjectRunSettings.tsx、ProjectPromotionCard.tsx；src/macos/OrbitKit/Sources/OrbitKit/App/ProjectRunSettings.swift、OwnerItemCards.swift；Android ProjectSettings.kt、CardModels.kt。理由那一行要用的事实（line、deliveryMode、coordinatorEnabled）客户端手里都有，onPass 已经下发，不需要改服务端。
