Commits not pushed on iOS, macOS and Android

Board 01 opens the web's Main checkout bar into its commits. This brings the same list to the native apps in the shape they already use for the worktree bar (session-commits-first board 02): tap the bar, and a sheet lists the commits. Tap one, and today's commit screen opens with its message, files and diff. iOS is the reference and Android follows it with Material parts. macOS shares the iOS code (MainCheckoutViews.swift, WorktreeBar.swift) and gets the same, as a sheet over the window. Hand-drawn draft; nothing is built.
