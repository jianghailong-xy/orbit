② 落地会话：点开那一行后进入的页面

落地会话用的是和普通会话相同的外壳：有标题、一条时间线、一个 URL，可以 ⌘F 搜索，也可以 Pin。不同之处在于：时间线由 Orbit 写，不是 agent 写；底部没有输入框，只有一行说明「谁来做判断」；会话不进 Trash。时间线里的每一步、每条检查、每次推送被拒以及是哪些提交推进了 main，都来自作业的已提交事实；检查输出单独存在 project_integration_job_log，两者都不写进 run_event。判断不在这里做，但判断的结果会带着署名记在同一个会话里。合入 main 时，一个会话就是一轮合入：从第一个候选开始，到 MERGED、DECLINED 或 CANCELLED 结束，中间每个候选、每一代检查都是会话里的一节。下面五屏是这样一轮合入的五个时刻（时间和提交是示意）。
