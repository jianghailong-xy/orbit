① Work overview 的落地行：从「一个数」变成「一扇门」

现在这一行只有一个字和一个秒表：看不出在落什么、是不是卡住了，也点不进去。改后每个落地主体都有自己的落地会话（由 Orbit 自己驱动，不启动 engine）：一个任务从 DONE 到落上集成线算一个落地主体，一轮合入 main 也算一个。这一行写清楚四件事：落的是谁、现在跑到哪一步、这一步用了多少预算、输出最后一次动是什么时候。点整行就进入对应的落地会话。例子取材于 2026-10-04 的 34Y7，时间和提交是示意的。按 owner 的决定，Merge to main 推送第一次被抢就交回候选，所以这里显示的是协调会话重跑出来的第 2 代合并检查。
