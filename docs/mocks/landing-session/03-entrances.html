③ 从哪里进落地会话，会话列表为什么不会被刷屏

一个 24 个任务的项目会落地二十多次，还有合入 main 和重跑。所以落地会话默认不进平铺的会话列表（GET /sessions 要带 includeLanding=1 才返回它们），这一期不加新的实时事件，按 §2.7a 的节奏轮询。它们只放在项目自己的 Landings 组里（随项目分组一起上线，在那之前不进任何列表），并从所有「说到这次落地」的地方链过去：Work overview、任务页、写代码的那个会话、协调会话里的待办卡，以及 agent 工具。落地会话的 id 在入队时就生成了，所以待办内容、NEXT_TURN 重放和链接从第一秒起就稳定，不会变。
