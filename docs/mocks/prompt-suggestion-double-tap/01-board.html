建议输入：Use 换成「拍两下」—— iPhone 为准

今天灰字行尾有个 Use 胶囊，点它把建议填进输入框。改成：拿掉 Use，在输入框那一行拍两下，效果和点 Use 一样：填进去、光标到句尾、键盘起来，不发送。 第一下就是今天的「点输入框」，键盘马上起来，不用等第二下；只点一下，照旧是自己打字。 手势看不见，所以灰字后面跟一行小字 Double-tap to use；在这台设备上拍中过一次，它就不再出现。 例句是编的；红点、虚线框、紫字是标注，不是界面。

待定 · 要你拍板

① 提示小字

  1. A. 紧跟灰字，拍中一次后不再出现（推荐）：先 ② 后 ③
  2. B. 一直显示：一直是 ②
  3. C. 不显示，只有灰字：一开始就是 ③；第一次看到的人不会知道能拍

② 范围

  1. A. 触屏一起改（推荐）：iPhone、iPad、手机网页、Android
  2. B. 先只改 iPhone、iPad（同一份代码），手机网页和 Android 留 Use

变与不变

  • 拍两下 = 以前点 Use：填进去、光标到句尾、键盘起来，不发送
  • 单点不变；有字时不认两下
  • 建议什么时候出现、什么时候消失（设计文档 §4.4）不变；不加关闭按钮，设置里的总开关照旧

代价

  • 手势看不见：靠提示小字教一次，每台设备各一次（记在本机）
  • 想粘贴时两下点太快，会填进建议（⑥）
  • 读屏走动作、不走手势（⑨）

落地（按代价排）

  1. iPhone · iPad小：PromptSuggestionLine 在 iOS 去掉 Use 和行尾 64pt，换成提示小字（macOS 分支的 Use ⇥ 不动）； GrowingTextEditor 的 UITextView 在有建议时挂一个双击识别，和系统点按同时识别（第一下不等），认到就走现成的 acceptSuggestion() + PlatformHaptics.tap()，第二下不让系统弹编辑菜单； 加 Use suggestion 读屏动作；「用过」记在 UserDefaults
  2. 手机网页小：hover: none 时不画 .composer-suggestion-use，改画提示；textarea 上认两下（两次点按 ≤ 300 ms、相距 ≤ 24 px）； touch-action: manipulation；读屏用的 Use 按钮视觉隐藏；「用过」记在 localStorage
  3. Android中：SessionComposer.kt 去掉 trailingIcon 的 Use；pointerInput 在 Initial 阶段认两下、不吃第一下； semantics 加 customActions；「用过」记在 SharedPreferences
  4. 测试与文档：三端把「点 Use」的用例换成拍两下，加上单点不填、有字不认、提示只出一次、读屏动作； docs/prompt-suggestions-design.md 改 §4.1、§4.3，§9 补一条
