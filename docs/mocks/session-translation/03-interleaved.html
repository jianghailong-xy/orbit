A 配对单位是 markdown 块：段落、列表项、标题、引用。每块：你的语言（正常）＋原文（灰、小一号、紧贴其下，无分隔线）。块与块之间正常段距。
B 不再需要 “Show English · N lines” 折叠：每段原文就在它的译文旁边，长回复也不用来回找。
C 译文与原文块数不一致（模型合并/拆了段）时，这条消息退回今天的整块显示，不硬配。
代码块、工具行、表格只出现一次（在译文里）。你自己的短消息保持现状（气泡内上中下英）。

⑤ 待你定（每项推荐 A）

  1. 顺序
    A 你的语言在上，原文在下　/　B 原文在上，译文在下
  2. 配对粒度
    A 按段落/列表项（稳，服务器已有的块结构即可）　/　B 按句子（更细，但要让翻译模型逐句对齐，成本和出错更多）
  3. 长回复折叠
    A 去掉，逐段对照后不需要　/　B 保留，原文行默认收起，点 “Show English” 才展开每段
  4. 对不上时（C）
    A 整条退回今天的整块显示　/　B 能配的配，剩下的堆在最后
