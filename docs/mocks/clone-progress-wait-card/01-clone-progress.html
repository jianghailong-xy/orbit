Clone progress in the “Waiting for the clone” card

问题：从 New session 开的会话（不是创建工作区的那个会话）只看到“Waiting for the clone / Starts when the clone is done.”，看不到进度，失败了也没有 Retry。
进度数据已经有（工作区的 cloneState + 流里 git 的百分比，今天只有 CreatedWorkspaceLine 在用）。下面是把它放进这张卡的方案。示意图手绘，类名/颜色取自 index.css 与 MachineSetupCard.css；仓库名、机器名是示例。

① 今天

没有进度、没有仓库名、没有机器名；克隆失败时标题变 “Clone failed”，但卡上没有按钮，文案让人去“对话第一行”重试——这个会话没有那一行。

hello
Waiting for the clone
Starts when the clone is done.

② 方案 A：卡片本身显示克隆进度 推荐

同一张卡，三种状态。标题说在做什么（带仓库名），中间是进度条 + 百分比（复用 .msc-clone-bar 的样式，加宽到 220px），底行说在哪台机器、什么时候开始。失败时原地给出原因和出路，按钮与第一行完全相同（Retry · Workspace settings / Reconnect GitHub / Install on GitHub）。

PENDING — git 还没报百分比
hello
  Waiting to clone acme/orbit
On orbit-ws03. This session starts when the clone is done.
CLONING — 42%
hello
Cloning acme/orbit
42%
On orbit-ws03. This session starts when the clone is done.

hello

Retry·Workspace settings

③ 方案 B：卡片不动，上面加一行和“第一行”一样的状态行

直接复用 CloneStatusLine 组件，代码最少；但同一件事说两遍（状态行说 Cloning，卡片还说 Waiting for the clone），而且进度条只有 120px、字号 12.5，在大空白里不显眼。

左边今天，右边加上百分比（同一个前端 store，不增加请求）。失败时副标题写 “Clone failed”。

要你决定的

  1. 形状：A 卡片本身显示（推荐，一处说一遍）/ B 复用第一行组件放在卡上方。
  2. 还没有百分比时：只显示转圈 + “Waiting to clone …”，不画进度条（推荐，进度条只画真实数字）/ 画一条来回滚动的不定进度条。
  3. 失败时的按钮：卡片上直接给 Retry 等出路，并把 “Retry the clone from the conversation’s first line” 这句删掉（推荐）/ 只改文案。
  4. 列表行副标题显示 “Cloning · 42%”：要（推荐）/ 不要。
  5. 平台：先做 web，Apple、Android 各开一个任务跟进（推荐）/ 三端一起。
