macOS 侧栏 — 照 iPad 的结构，用 Mac 的手感

今天 Mac 的侧栏还是老的「Workspaces 展开组 + 一排板块」：工作区占满上半截、每行两行字，Projects / Tasks / Waiting on you 被挤到最底下；行上也没有「等你 / 在跑」的状态。iPad 的侧栏就是 iPhone 抽屉的同一个视图，结构已经定下来了。建议 Mac 照搬它的结构、顺序、状态记号，但尺寸、选中样式、新建入口、设置入口按 Mac 的习惯来。三张图用同一份示例数据：两台机器 12 个工作区、3 个进行中的项目。红色虚线是 Mac 默认窗口高度 720pt。

  1. 1工作的入口放最上面：Projects · Tasks · Wiki · Waiting on you，和 iPad 的顺序一样。「等你」的数字统一用 iPad 的琥珀色数字（今天 Mac 只有 Waiting on you 带一个实心橙色胶囊，Projects 和 Wiki 没有计数）。同 iPad
  2. 2Workspaces 是 Mac 原生的可折叠分组标题：小号灰字，鼠标移上去右侧出现 Hide / Show（系统 Section(isExpanded:) 的行为），不再是一个可选中的「Workspaces」行 + 展开三角。机器名不再单独占一行分组标题。Mac 习惯
  3. 3工作区一行：文件夹 · 名字 · 机器，和 iPad 同一种写法（同名的 orbit 靠机器区分）。引擎和目录从行里拿掉，放进鼠标悬停的提示（.help）。行高 44 → 30pt：12 个工作区从 528pt 变成 360pt。同 iPad，行高按 Mac
  4. 4右侧只有一个状态位，优先级同 iPad：等你的数量（琥珀胶囊）＞ 正在生成（转圈）＞ 后台任务（呼吸的终端图标）。都没有时，前 9 个工作区显示淡灰的 ⌘1…⌘9 —— 保留 Mac 已有的快捷键提示。同 iPad + Mac 保留 ⌘N
  5. 5进行中的项目接在最后，和 iPad 一样：等你的排前面，然后按最近活动；点开是项目的会话页。同 iPad
  6. 6新建会话和搜索放在侧栏顶部的工具栏（和「备忘录」「邮件」的写新邮件按钮同一个位置），对应 ⌘N 和 ⌘K。iPad 底部那条浮动「New session」胶囊不搬过来：Mac 上新建是工具栏 + 快捷键的事。Mac 习惯（待定 ①）
  7. 7底部保留账户行，右侧加一个齿轮：齿轮 = 打开设置（同 iPad 的齿轮），点头像弹账户菜单。Following、Settings、Admin 三行从侧栏拿掉——iPad 本来就没有这三行：Settings 是齿轮，Admin 在设置和账户菜单里，Following 从会话里的卡片和链接进，菜单栏「Go」里也留一个。同 iPad

Mac 才有的手感：悬停、右键、折叠、深色

这些 iPad 上没有（或者是长按），Mac 上用户会自然去试。都用系统控件，不新造外观。

  1. 1悬停：分组标题右侧出现 Hide；工作区行悬停弹出提示，补回行里拿掉的两样东西：Claude Code via DeepSeek · ~/dev/billing-api。
  2. 2右键工作区：New Session（在这个工作区新建）、Open Sessions、Workspace Settings…、Copy Path、Show Machine。iPhone / iPad 的长按菜单以后可以用同一组。
  3. 3折叠 Workspaces：工作区很多时一下收起，Projects 组直接上来。折叠状态记住（@AppStorage），和今天的 agentsExpanded 同一个作用，只是换成系统分组。
  4. 4账户菜单：邮箱、Settings…（⌘,）、Admin（仅管理员）、Following、Sign out。这样 Admin 和 Following 拿掉侧栏行之后还有固定入口。
  5. 5深色模式：琥珀色和转圈在深色侧栏上照样读得出；选中行用系统的选中色，不用 iPad 的浅蓝底。

待定 · 要你拍板

① 新建会话放哪

方案 A：侧栏顶部工具栏推荐

和「备忘录」「邮件」「Xcode」一样，新建是工具栏上的一个图标按钮，悬停有「New Session ⌘N」提示。侧栏底部只留账户和齿轮，列表一直滚到底。

方案 B：照搬 iPad 底部浮动胶囊

和 iPad 一模一样，但在 Mac 上这种浮动大按钮不常见，还会盖住最后一行，账户行要么拿掉、要么叠在一起。

② 工作区行写一行还是两行

方案 A：一行「名字 · 机器」推荐

同 iPad。12 个工作区 360pt，720pt 的窗口里能同时看到上面四个入口和全部工作区。引擎和目录在悬停提示里。

方案 B：保留两行（名字 / 引擎 · 目录）

信息多，但 12 个工作区要 528pt；你截图里的 16 个要 704pt，项目组一定在窗口外。而且长引擎名（ModelHub SG DeepSeek）总是被截断，看不到目录。

③ 项目组：全部列出，还是只列活跃的

方案 A：同 iPad，全部进行中的项目推荐

你要求参照 iOS / iPad，手机上 11-12 也定了先不折叠，那 Mac 先和它们一致。工作区多的时候用 ② 的折叠 Workspaces 解决。

方案 B：同网页，安静的项目折成一行

网页侧栏 11-12 起只列 24 小时内有动静的项目，其余折成「N quiet projects」。Mac 也是大屏，适合这样；但会和 iPad 不一致。可以等手机也改的时候一起改。

落地（按代价排）

  1. 顺序和行：Mac 的 SectionSidebar 改成 iPad 的顺序，工作区行换成 iOS 已有的 WorkspaceNavigationRow（现在包在 #if os(iOS) 里，放开给 macOS），机器名不再做分组标题。复用 NeedsYouCountCapsule、SpinnerGlyph、BreathingGlyph，不新造外观。
  2. 计数：Projects / Wiki / Waiting on you 的琥珀数字，数据源和 iPad 一样（projects.needsYouCount、wiki.waiting、ownerRequests.waitingCount），侧栏挂载时一起拉。
  3. 进行中的项目组：用 iPad 的 drawerProjects(coordinators:)，点开走项目会话页。
  4. 拿掉 Following / Settings / Admin 行：底部加齿轮（选中设置页，⌘, 不变）、账户菜单加 Settings / Admin / Following，Go 菜单加 Following。
  5. 工具栏：侧栏列加 New Session 和搜索两个按钮。
  6. Mac 手感：系统可折叠分组、悬停提示、右键菜单。

只动 macOS 的侧栏；iPhone / iPad 不变。SwiftUI 在这台机器上编不了，做完要在 Mac 上实机截图对照这张图。
