会话列表：看得出哪个会话还有任务在跑

现状：会话里建的任务只在打开会话后的 Tasks · 2 running 条上看得见；列表行的数据里没有这件事（那条的数据是打开会话时单独读的 sessionCreatedTasksQuery）。 下面四列是同一份列表：①一个会话本身空闲、它建的 2 个任务在跑 1 个排队；②会话本身也在跑；③会话有后台进程（已有的 Background 图标）又有任务在跑；④普通会话；⑤项目行（对照用）。 列表框用的是线上的 index.css 和真实类名，外框和悬停提示是手画的。界面文字按上线时的英文画。

A 的细节：悬停提示、颜色

提示文字：2 tasks running · 1 queued，只有排队时 1 task queued。数字 = 在跑 + 排队。
颜色：左边蓝色（推荐，和"正在跑"同一个蓝，扫一眼能看到）；右边灰色（和 Background 图标一样，但 12px 灰色很难扫到，这正是现在的问题）。
点它：不单独做按钮，点行照常打开会话；打开后 Tasks 条已经在那里。
