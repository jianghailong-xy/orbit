16 还是同一段对话，接着往下说。17 额度条换成 Default 的（每周 34%）；点开 Plan usage，第一行写明 Account：Default，下面是它的三条：

说明

  • 规则（和 web 01-web 一致）

  • a名单。Kimi 进账号引擎名单（keepsAccounts / canAddAccount），Add Account 只看 runner 有没有声明 kimi-account-login/v1。没声明的 runner 一切照旧：区名 Sign-In、一个登录、没有 Add Account；旧版 App 也不受影响。
  • b站点。加账号不预选、不默认；Current 只在 Sign In Again 时出现，标这个账号自己的站点；引擎页每个账号的副标题、运行器页单账号的行都写站点。
  • c额度。每个账号三条：5h limit / Weekly limit / Monthly limit，名字照 Kimi 自己 /usage 的叫法（Codex 的行也是照 Codex 的叫法）。运行器页的行只挂 Next 那个账号的一条；读不到时照旧写 No quota reported。
  • dNEXT / Automatic。和其他引擎同一个规则（CodexAccounts.toStartOn）：掉线的不选；5 小时用到 80%、长窗口用到 90% 的排后面；其余先用最长那个窗口（Kimi 是月度）最早过期的。
  • e换账号。说过话的会话只有在 runner 声明 kimi-account-move/v1 时才列账号；没声明时照旧，服务端也会拒。还没说过话的随便选。输入框里不写站点：名字就是区分，站点在引擎页上。

  • 要改的地方（iOS / macOS 同一批视图；不在这次图里动代码）

  • 1RunnerPageFormat：keepsAccounts / canAddAccount 加 kimi（看 kimi-account-login/v1）；Kimi 的 AccountLine.subtitle 写「站点 · 目录」，站点取账号自己的 kimiRegion（Default 取引擎级的）；手机上一行放不下时从中间省略（.truncationMode(.middle)），站点和目录末尾的 id 都留着。
  • 2RunnerSignInModel.currentSite：加账号时为空；给某个账号重新登录时取那个账号的站点。KimiSite 加「…account you are adding…」一句，进 KimiSiteCopyParityTests 和 web 逐字比。
  • 3CodexAccounts：moveCapability 加 kimi → kimi-account-move/v1；工作区 / 会话 / 草稿的账号和 pinned 加 kimiAccount；Kimi 自己的 deciding env keys（KIMI_CODE_HOME 和 Kimi 的 key）。这几处 switch 现在遇到 kimi 都落到 Codex。
  • 4DTOs：RunnerEngineAccount.kimiRegion；Session / Agent 的 kimiAccount、kimiAccountPinned；Kimi 快照的月度窗口（字段名照 shared 任务定的）。
  • 5macOS 不另画：账号行上直接有 Sign In Again / Pause… 按钮，菜单里打 ✓ 而不是写 Current，Provider 子菜单里账号缩进在 Kimi 那一行下面——都是 Mac 现成的画法。

  • Android 按同一套规则做时的差异

  • a站点要先补上。Android 现在没有 Kimi 站点：登录卡对 Kimi 只有一个「Sign in to Kimi Code」（runner 跑不带参数的 kimi login，站点由 CLI 定），也不读 kimiRegion。加账号要先选站点，所以要把 iOS 的 KimiSite 那一套搬过去：两个站点按钮、设备码写站点、Use … instead、Current、副标题和运行器页写站点。单账号登录、加账号、Sign In Again 是同一张卡（RunnerSignInCard），一起改。
  • b账号的操作在 ⋯ 菜单。Android 每个账号行右边一个 ⋯（Rename… / Sign In Again / Pause… / Remove…），没有左滑和长按；Add Account 是 Accounts 区底部的文字按钮，表单同样先起名（Account 2）再选站点。
  • c副标题。Android 的 AccountLine.subtitle 现在只写目录，改成和 iOS 一样「站点 · 目录」。
  • d换账号是对话框，不是菜单。Android 输入框点模型打开「Model and account」对话框，账号在 Account 一组（Automatic + 每个账号 · 额度），点了就换。ComposerData.accounts 加 kimi；EngineAccounts.moveCapability 现在把 kimi 当成 Codex（落到 codex-account-move/v1），要改成 kimi-account-move/v1。
  • e运行器页不用另做。「N accounts signed in」+「Next: 账号」+ 一条额度 Android 已经有（RunnerPage.engineNextAccount / engineWindows），Kimi 进名单就跟着出现；额度窗口用同一套名字。
