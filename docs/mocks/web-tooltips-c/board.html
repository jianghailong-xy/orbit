Web 提示：C 组（被截断文字的全文）

C 组是放不下的文字（标题、路径、分支名、说明行）上的 title，内容就是文字本身。浏览器的气泡今天不管有没有截断都弹：文字完整时它只是把看得见的字再说一遍；截断时它才有用。改法：应用的 Tooltip 加一个「只在截断时出现」的模式，打开前量一下元素（和它里面被省略的子元素）是否放不下，放得下就不弹。数字来自 main（6ad6c314d3）。
