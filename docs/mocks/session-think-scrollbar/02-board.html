会话流 · 流式思考块不再画自己的滚动条

你截图里右侧并排的两条滚动条，是同一个面板里两个滚动区各自画出来的：外层是会话滚动区 .workspace-sessions；内侧那条属于直播中的思考块 .chat-think-port——它被限制成约 11em 高、自己可滚 （DeepSeek 一轮推理常有几万字，不能让它把回答和工具行挤出屏幕），于是思考块的条就贴在会话条内侧 8px 处。 两条都跟着尾部停在底部，看起来像「右边有两条」。

修改：让思考块继续可滚，但不画自己的滚动条。外层会话条不动；思考块原来的 8px 条槽用 8px 内边距补回 （padding-right: 8px → 16px），所以文字宽度、换行都不变，唯一的区别是少一条条。

一条

修改后 ✓ 只剩会话条。思考块内仍是可滚动的 11em 视口，只是不画条。

  • 为什么原来是两条：思考块为了不被超长推理撑爆，自己是一个滚动区 （max-height: 11em; overflow-y: auto）。两个滚动区都使用全局的 8px 滚动条样式，所以并排。
  • 改法：思考块保留滚动、去掉自己的条。滚轮进入思考块时仍回看历史推理；滚回底部恢复跟随。 overscroll-behavior: contain 保持现状，滚到头不会带动外层会话。
  • 零位移：隐藏滚动条会让内容自动多出 8px 宽，所以右内边距从 8px 改为 16px，行的换行位置与改前完全相同。
  • 范围：只改 Web 控制台的 src/web/src/index.css 一处；组件逻辑、服务端、原生客户端（iOS / macOS / Android）都不动。
/* src/web/src/index.css — .chat-think-port */

scrollbar-width: none;
