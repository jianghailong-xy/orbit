待你确认的选择（每项都有建议）

  1. 标签文字：建议 Queued · runner full，和 runner updating 同一个格式、一样短；备选 Queued · waiting for a slot（会话列表今天用的 “Waiting for slot”）。
  2. 弹层里分开数：建议把“在跑一轮的”和“被后台任务占着的”分开写（③），它直接回答了“明明只有 10 个在跑”；备选只写 “HPC is using all 16 slots”。
  3. run / batch 占满：建议一起做（⑤下），同一套挂法，只是词换成 run full / batch full；备选这次只做 runner full。
  4. 弹层按钮：建议不加。runner updating 有 Later / Update Now，是因为可以对更新做点什么；满了的时候这里没有能直接点的动作，想看是谁占着，去 HPC 的机器页（另一个任务正把后台任务占位也算进 “N of M running”）。
Web / iOS / macOS / Android 一起改。服务器那层：等 Count sessions held by a background job as running 那个任务（迁移 0780，存下后台任务占位的会话）落地后，排队原因按同一份占位来算，并带上两个数（在跑一轮的、后台任务占着的）。
