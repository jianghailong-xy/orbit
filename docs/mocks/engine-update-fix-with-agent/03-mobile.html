Update Engines Now 失败时让 Agent 去修 · iOS / Android 设计图

跟今天上线的网页版同一套规则（三个决定都按推荐）：报告里有红行时，红行下面放一个 Fix with an agent；按一下就在这台机器上最近用过的 workspace 里起会话，不弹窗、页面不跳走。iOS 和 Android 都已经有这个报告（机器页 Engines 区底部，以及每个引擎页的 Update Engines Now 下面），按钮和下面那行灰字直接复用 Install failed 面板现成的组件。黄色虚线框是新增部分。
注意：11-14 的旧图 engine-update-report/02 曾画成每条红行后跟一个链接、引擎坏了就换别的引擎；今天你批的是整个报告一个按钮、坏了就置灰写原因，网页已按今天的做，手机跟网页一致。

落地

1. OrbitKit：RunnerAttentionFixKind 加 engineUpdateFailed；RunnerAgentFixLogic.engineUpdateState(runner)（有红行才有，规则同 installFailedState）；request 对它发空 body。
2. iOS/macOS：SkillsRunnersView.enginesSection 和 RunnerEnginePage.updateSection 的报告行下面放 RunnerAgentFixButton + RunnerAgentFixLine。
3. Android：RunnerPage.agentFixOnUpdate(runner)，RunnerScreens 两处报告行下面放 AgentFixButton + AgentFixLine。
4. 测试：OrbitKit 单测（Linux 上跑不了 SwiftUI，只能跑 OrbitKit），Android 单测 RunnerPageTest；服务端不用改。
