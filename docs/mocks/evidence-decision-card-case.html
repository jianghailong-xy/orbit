「需要你裁决」：同一条真实证据，两种排法

这条证据是真的（任务 34QTEhtb6QEddsXKbNsrt，rev 1）： 主张 1941 字、缺口 5 条、机器已核 3 项、引用 7 条。 iOS 卡片把主张折到 90 字、web 折到 120 字 —— 也就是说这条主张是设计假设的 21.6 倍。 下面左边是它现在的排法，右边是把同样的字段换个顺序之后。一个字都不用重写，只换顺序和层级。

另外两件，跟这张卡同屏发生

语言不一致：这张卡全中文（需要你裁决 / 确认完成 / 退回重做 / 展开全文 / 提交者声明的缺口），而同一个 app 里的确认卡全英文（Confirm this task is done? / Confirm done / Chat about this），卡上还并着一枚英文 FROM ORBIT。同一条会话里会连着弹出两种语言的判决卡，得选一边。
