这一行的规则（实现时照这张表，不另加判断）

放哪：Watching → Background processes → Tasks created here → 分支条。两种产出（任务、代码）挨着。
出现：本会话建过 ≥ 1 条任务就出现；全部完成后照样留着。待确认、被拒的提案不进（它们在确认卡和 Needs you 里）。
计数句：N running · N failed（红）· done/total done。为 0 的段不写。三段都是现成的句子：Background、后台作业、Tasks 标签的进度。
1 条时：写任务名 + 状态胶囊，跟 Watching 条一个做法。
展开：Failed → Running → Queued → Open → Done → Cancelled，同组新的在前；超过 20 条只列前 20，底部 View all in Tasks ›（Tasks 页要补「按来源会话」筛选）。任务属于项目时多一个 Open project ›。
被接替的任务：这一格显示接替它的那条（它的状态 + Replaces ‹原任务›），不画红色 Failed；计数也按它算，所以胶囊数和计数句永远对得上。
