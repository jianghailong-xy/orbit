信封 = 工作区、权限、每周次数、单次时长，只有你按卡才会改写。1 往小改（更少次数、更窄权限、改时间、改内容）直接生效，可 Undo。因为这是你说的收紧，信封跟着缩小。2 再往大改就超出信封，要你按一次 Allow。第 3 版里“扩大权限要卡”是这条规则的一个特例。反过来，如果是任务自己在某次执行里降频（见 ④），信封不缩，之后恢复到每天不用再问：授过的权不问第二遍，收回的权要重新问。
