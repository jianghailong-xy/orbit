没有 workspace 的机器：在对话里建第一个 workspace · Web

用户接上一台机器之后想的是「让 agent 在这台机器上干活」，不是「去配一个 workspace」。今天的路要绕到设置页填表，而且 iPhone、Mac、Android 根本建不了。方案：新会话页就是入口。在这台机器上直接开新会话，卡片只问两件只有你能定的事（文件夹和登录），你发出的第一条消息会把 workspace 一起建出来。
① 今天新账号只有 orbit@austin 一台机器：在线、两个引擎都没登录、0 个 workspace（runner_list 2026-10-31 的真实状态）。都是真页面截图。
