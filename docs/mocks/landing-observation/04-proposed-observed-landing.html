建议的设计：「已落地」是观测出来的状态，不是流水线的副产品

工作身份 = 提交号；落地 = 这个提交是否已在线上；回执退回成观测记录；授权另走一条线。

前提：owner 声明交付方式（和集成线设置同一个入口）
agent 直推：agent 自己推到 feature/v1.1.1（这个项目）平台合入：agent 不碰目标分支，平台按提交号合入
① 任务 DONE：冻结身份
delivered_base_sha、delivered_sha
取会话报的 branch_sha，收敛任务取 checkpoint 提交；之后只认提交号
② 落地观测作业（runner，只读，批量）
fetch 线和 upstream，判断 delivered_sha 是否已被包含
DONE 时agent 一轮结束时回执写下时手动再看一次
只由已提交事实触发，不加时钟
