待你定

  1. 正在跑的任务怎么办？建议：不让搬（F），说清楚停掉或等它结束。另一种：允许，跑完后结果算到新项目。
  2. 协调者能不能自己搬？建议：不能直接搬——这等于从原项目拿走一条判据。协调者可以发一个“建议搬到 …”的待办，你在 done 卡上一按就是确认。
  3. 能撤销吗？建议：不做撤销按钮；要搬回来，在新项目上对同一条判据再用一次 Move（目标选回原项目）。
  4. 项目详情的判据行也给 Move？建议：先只放 done 卡（已定的入口），少一个地方。
  5. 新项目开工：建议：未开工、不自动开协调者；它会出现在项目列表，等你开工。另一种：继承原项目设置并直接开工。
