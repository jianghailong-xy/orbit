Now

Press Continue, or send any message of your own. It runs on what the composer holds — picking another provider first also moves the run off the spent account.

At the reset

The default, and what the switch arms: the server sends the same continue turn when the window resets. It also holds the task's own re-run while it waits, so one outage cannot leave two runs.

Stop it

Switch it off and let it sit: the run's failure does not count against its task, so the task re-dispatches at the reset — as a new run: the same task, without this conversation.
