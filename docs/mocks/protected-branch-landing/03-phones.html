Phone layouts — iOS and Android

iOS is the reference; Android follows its layout with Material spacing and a back arrow. The setting is the workspace’s settings sheet (iOS: agent settings form; Android: WorkspaceSettings). The same option A is drawn; B and C collapse to one row each in a list and need no separate phone drawing. The card’s actions wrap under the detail instead of sitting in one line.

Recommendation: same recommendations as web (setting A, tip in the review state). On a phone, option A’s two radio rows become two full-width tappable rows, which is easier to hit than a menu row.
