# P5.3 真机检查清单（会话工作区）

**状态：待账号所有者于 P7.2 部署后执行。** 本任务没有真机，这一项在证据里记为缺口，不记为通过。HPC Android 模拟器上已跑过的同类检查见 [README](README.md)「模拟器（HPC emulator-5554，API 36，Chrome for Android + Gboard）」；模拟器不能代替真机。

**准备**：P7.2 部署之后（包含 P5.3 的提交）的 Orbit；一台 iPhone（Safari）和/或一台 Android 手机（Chrome），已登录，有一个可以发消息的会话；系统键盘之外装好中文拼音输入法；相册里有一张照片。每项记下：设备型号、系统与浏览器版本、通过/不通过、不通过时的截图或录屏。

| # | 操作 | 预期 |
|---|---|---|
| 1 | 打开一个会话，点输入框。 | 软键盘弹出；输入框整个留在键盘正上方，看得见、能打字；上方对话仍可滚动。收起键盘（下滑或返回）后输入框回到页面底部。 |
| 2 | 切到拼音，在输入框里打 `nihao`，先不选词，看输入框；再选「你好」。 | 选词之前字母带组词下划线，候选栏出现，消息不会发出；选词后「你好」进入输入框，光标在字后。 |
| 3 | 组词进行中按键盘的回车；然后换英文键盘打几个词，按回车。 | 组词中的回车只确认字母（或按输入法的规则上屏），不发送；不在组词时，回车发送消息，输入框清空，键盘保持弹出。（手机键盘没有 Shift+Enter，现有行为里回车即发送。） |
| 4 | 长按一条回复里的一个词，拖动选区两端，点 Copy；长按输入框粘贴。 | 系统选择把手和菜单出现，选区随拖动变化；粘贴进输入框的文字与所选一致。 |
| 5 | 回到会话列表，长按一行（不要移动手指），在弹出的菜单里点 Pin。 | 菜单从手指按下的位置弹出，宽度与以前相同（约 240pt），不选中行里的文字、不出现系统菜单；点 Pin 后菜单关闭，该行进入 Pinned。 |
| 6 | 在列表里点开一个会话，然后：Android 用系统返回键，再点开一次用屏幕左缘向右滑；iPhone 用屏幕左缘向右滑。 | 每次都回到会话列表，列表位置和打开前一样；没有空白页或停在半路。 |
| 7 | 打开会话标题右边的 ⋯，点 Find in session，打一个回复里有的词，再关掉。 | 查找框获得焦点、键盘弹出，命中的词在对话里高亮并显示计数；关闭后高亮消失。 |
| 8 | 点输入框左下的 +，点 Image，在系统相册里选一张照片。 | 系统选图界面打开，选完回到 Orbit，输入框上方出现这张照片的缩略图（右上角有 ×）。 |
| 9 | 点缩略图；在预览里双指张开放大、单指拖动、双指捏回；点右上角关闭。 | 全屏预览打开，图片跟手缩放、移动，缩到原尺寸以下会弹回；工具栏按钮可点；关闭后回到输入框，缩略图还在。 |
| 10 | 点缩略图右上角的 ×；再发一条带照片的消息，在对话里点那张照片。 | × 移除照片；对话里的照片点开同样的预览，关闭方式同上。 |

执行后把每项结果连同设备信息发到 P5.3 任务的评论里；有不通过的项，附截图并说明与旧版本是否相同（有条件时在同一台手机上对照部署前的版本）。
