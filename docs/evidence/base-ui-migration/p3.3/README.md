**最终收益**：P6 之后才能兑现，P7 须实测。
- **体积（估算）**：antd 家族目前占初始 JS 861,892 字节 raw（24.3%）。P6 移除后，扣掉届时多用到的 Base UI 组件（估计再加 30–100 KB raw），初始 JS 预计净减约 21–24%（raw）。gzip 按整体压缩比折算，约减 230–260 KB。

  - CSS 文件里没有 antd 样式，antd 的样式在运行时注入。所以 CSS 文件的收益只有删除约 150 行 `.ant-*` 覆盖，可以忽略；运行时则省掉 cssinjs 的样式计算。
