Step 1 of 3

New workspace

A workspace is one repository on one machine — the place your sessions and tasks actually run.

Recommended

From a git repository

Paste a URL. Orbit clones it onto the machine you pick, turns on worktree isolation and detects the merge target.

From an existing directory

Point at a folder that is already on one of your machines. You will pick the machine first.

Cloning uses the git credentials already on that machine — ssh key, credential helper, or gh auth. Orbit stores no tokens.

① 选来源第一屏就分叉,因为两条路的步骤顺序天然相反:git 路是「仓库 → 机器」,目录路必须「机器 → 路径」。硬凑成统一向导会把 git 路的优势吃掉。
