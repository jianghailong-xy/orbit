# Orbit 0.1.261-beta.84

## Summary

- **Antigravity sign-in in a runner's browser.** A sign-in that Antigravity finishes in the runner's own browser now completes. The runner follows the sign-in tab's navigations, so it sees the code even when the callback page removes it from its address; the previous reader saw only `antigravity.google/oauth-callback` and the sign-in stopped there.

This is the release's only change; everything else is as in 0.1.261-beta.83.

## Upgrade impact

- **Migrations:** none. No migration is added or changed in this release.
- **Runners:** the fix is in the runner, so a self-hosted runner gets it by updating to the runner served at `/dl`, which is built from this tag. Orbit Cloud runners get it from the `orbit-cloud-runner:0.1.261-beta.84` image, which is built from this tag. Until a runner is updated, its Antigravity sign-in still stops at the callback page.
- **Clients:** no client step is needed. The web, macOS, iOS and Android builds change only in their version.

## Security fixes

None in this release.

## Known limitations

- Reading every page's current address is still the fallback. If the sign-in tab's navigations cannot be watched, a callback page that strips the code from its address (Antigravity's does) leaves the card's paste field to finish the sign-in by hand.

## Artifacts and verification

Tag v0.1.261-beta.84, the release commit on `main` after `4bfe3c666d`. `release.yml` publishes the macOS DMG (beta channel), an iOS TestFlight build, the Android APK, and the runner binaries with SHA256SUMS, SBOM and provenance. The Orbit Cloud runner image is published from this tag on the build host. Before it was merged, the runner's sign-in and browser tests (`go test -run 'Login|Browser|Kimi|Antigravity|Cursor.*Login|SignIn|Capabilit|CodeCallback|CloseSignInTab|WatchTab'` in `src/runner-go`) passed, including the new ones in `src/runner-go/login_runner_browser_test.go`: a callback page whose address shows only `antigravity.google/oauth-callback` while the tab's navigation carries the code, and the navigation watch against a stand-in for Chrome's DevTools. No release build had run when these notes were written.

## Rollback

Previous tag v0.1.261-beta.83 (`0ab68f1ee9`). No schema change, so rolling back the application is schema-safe. Clients roll back by installing beta.83's builds. A deploy of a commit before this tag points Orbit Cloud runners back at the beta.83 image, and each moves to it once idle.
