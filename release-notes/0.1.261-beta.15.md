# Orbit 0.1.261-beta.15

## Summary

Everything in [0.1.261-beta.14](0.1.261-beta.14.md), which never published (see Known limitations), plus:

- **Show both languages interleaves each reply block:** every paragraph, list item, heading or quote in your
  language with its original right under it, smaller and grey (web, Mac/iOS, Android).
- **Guests attach images** to their message in a shared session (web, Android, Apple).
- **Create and start leads the single-task create card**, except for a task filed to be held
  (`autoRunWhenReady: false`), which keeps Create first.
- **Fix with an agent on a failed Update engines report** on the machine page.
- **Recap card:** a single × replaces the ⋯ menu (Refresh recap is gone).
- **Web:** the prompt optimizer is a fixed-slot ✦ icon beside Send; the sticky question bar no longer
  flickers over Orbit reply turns; the pending merge line is a row of the branch bar.
- **Merges:** a branch that landed some other way drops its stale "Merge conflict".
- **SubAgents:** Anthropic keys and Claude pools are ruled out on a region-blocked runner, not only Claude's
  own sign-in.
- **Accounts:** removing an added account while Default is in use asks a shorter question.
- **Android:** a test-only fix for `PromptOptimizerFramesTest`, which failed the beta.14 Android build.

## Upgrade impact

- **Database migrations.** Two, both additive: `0870_account_remove_sessions` (from beta.14, a defaulted
  `UUID[]` column on `runner`) and `0880_attachment_guest_uploader` (a nullable `attachment.uploaded_by_guest_id`,
  catalog-only, no rewrite). An older apiserver neither reads nor writes either.
- **Runners.** Runners on the beta channel move to 0.1.261-beta.15 once the server is deployed after this
  tag. This release changes the runner (beta.14's account-removal report, SubAgent record sweep and remote
  resume refusal, and the shorter remove-account question).
- **Server.** Guest uploads, the create-card order, merge-status clearing, SubAgent region rules and the
  beta.14 server changes take effect when the server is deployed.
- **Configuration.** No changes required.
- **Clients.** Each client builds from this tag: macOS beta users, TestFlight (marketing version 0.1.261,
  build number = commit count) and Android via `android-update.json` are offered it.

## Security fixes

None in this release.

## Known limitations

- **beta.14 did not publish.** Its Android job failed on `PromptOptimizerFramesTest` (a stale test, not a
  product bug), so no GitHub Release, DMG update or Android update went out; only its TestFlight build
  uploaded. This release supersedes it.
- The iOS ☰ count badge fix stays reverted (since beta.14): on iOS 26 the badge is still clipped at the
  drawer button's edge.

## Artifacts and verification

The release identity is `package.json` `0.1.261-beta.15` and tag `v0.1.261-beta.15`. This tag publishes the
macOS DMG and Sparkle payload (beta channel), the iOS TestFlight build, the runner binaries, and
`orbit-android-0.1.261-beta.15.apk` with its `.sha256` and `android-update.json` on the same GitHub Release.
The Android test fix passed `PromptOptimizerFramesTest` and `PromptOptimizerShellTest` (15 tests) locally;
each other change landed with its own tests, and the release run's builds compile this tag.

## Rollback

Roll back to 0.1.261-beta.13 (beta.14 never published). Migrations 0870 and 0880 only add columns that
beta.13 ignores, so an application-only rollback is schema-safe. Runners do not move back by themselves:
roll them back with the `/api/runner/release` pointer. See
[Release process](../docs/release-process.md#rollback-decision-and-procedure).
