# Orbit 0.1.261-beta.22

## Summary

Changes since [0.1.261-beta.19](0.1.261-beta.19.md), the last beta that published. beta.20 and beta.21 did not
publish (see Known limitations); this release carries everything in their notes and the fix that stopped them.

- **Resuming a remote SubAgent:** `delegate` with `resume` now continues a SubAgent that ran on another workspace,
  with its conversation, on the workspace and runner it ran on, in a new worktree of that workspace's HEAD.
  Before, the resume was refused as "left no conversation to resume".
- **Runner:** a background job that ends just as the runner stops still wakes its session; a `/compact` turn
  completes instead of hanging RUNNING.
- **iOS and macOS — Chat about this with an image:** an image staged beside the words of a "Chat about this"
  reply now goes with the message, as on the web; a send that fails hands the image back with the words.
- **iOS — Optimized prompt sheet:** as tall as its content, the gloss in your own language first, the prompt sent
  to the agent beneath, and Use / Edit full width at the bottom.
- **Settings on iOS and Android** take the web nav's groups: Personal, Machines, Providers.
- **Composer:** Tab optimizes a draft (web and Mac); the Mac's ✦ tooltip names Tab and ⌘⇧O.
- **Web:** a bare machine's card makes a workspace from a folder and a name; an engine row's update warning offers
  Fix with an agent; a question answered on another client leaves the web card; account menu levels draw each
  icon after its label; the session's Tasks strip drops its View all in Tasks link.
- **Clients:** an Agent block and its group head show no cost.
- **Server:** a check stopped at its time limit says so on its open item and offers a rerun only with a reason;
  the owner's card over a timed-out promotion check says it must finish, not pass.
- **Managed runners:** a runner with no login waits for one instead of failing, and is ready by itself once one
  is signed in.
- **Apple:** a user message's state reads as the web's; the setup card's Folder step carries no step number.
- **Upgrade:** a two-stage build makes room on the build host first.

## Upgrade impact

- **Database migrations.** None since beta.19.
- **Runners.** Runners on the beta channel move to 0.1.261-beta.22 once the server is deployed after this
  tag. This release changes the runner: it keeps an ended remote SubAgent's conversation for 7 days after its
  last run, continues it on a resume, and declares `subagent-remote-resume/v1`; a job ending as the runner
  stops still wakes its session; and a `/compact` turn completes.
- **Server.** The server side of remote resume is already deployed. Until the target workspace's runner declares
  `subagent-remote-resume/v1`, the server refuses a remote resume as too old. The timed-out check wording takes
  effect once the server is deployed from this tag or later.
- **Configuration.** No changes required.
- **Clients.** Each client builds from this tag: macOS beta users, TestFlight (marketing version 0.1.261,
  build number = commit count) and Android via `android-update.json` are offered it.

## Security fixes

None in this release.

## Known limitations

- beta.20 failed in Android's unit tests: the Mac's ✦ tooltip had added its keys to a string Android must share
  word for word. beta.21 carried the same failure, and its run was cancelled. Neither published; their notes
  remain for the record.
- A remote resume works only once both the parent's runner and the target workspace's runner run this release.
  A resumed remote SubAgent starts from the workspace's current HEAD, its earlier changes discarded. Its
  conversation is kept for 7 days after its last run; a resume fails, with the reason, if the workspace has moved
  to another runner or now runs another engine, and Claude Code cannot reopen it if the workspace's Claude
  account changed in between.
- A "Chat about this" reply on iOS and macOS still needs typed words; an image alone does not send from it.

## Artifacts and verification

The release identity is `package.json` `0.1.261-beta.22` and tag `v0.1.261-beta.22`. This tag publishes the
macOS DMG and Sparkle payload (beta channel), the iOS TestFlight build, the runner binaries, and
`orbit-android-0.1.261-beta.22.apk` with its `.sha256` and `android-update.json` on the same GitHub Release.
The tooltip fix built for OrbitKit and the Mac app on macOS, with the prompt optimizer tests passing (33 of 33).
Remote resume was checked by the runner's SubAgent tests and the remote SubAgent PostgreSQL spec before it merged;
it has not been run end to end across two machines.

## Rollback

Roll back to 0.1.261-beta.19. No migrations since then, so an application-only rollback is schema-safe.
Runners do not move back by themselves: roll them back with the `/api/runner/release` pointer. See
[Release process](../docs/release-process.md#rollback-decision-and-procedure).
