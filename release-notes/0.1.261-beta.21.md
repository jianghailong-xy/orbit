# Orbit 0.1.261-beta.21

## Summary

Changes since [0.1.261-beta.20](0.1.261-beta.20.md).

- **iOS and macOS — Chat about this with an image:** an image staged beside the words of a "Chat about this"
  reply to one of the session's requests, or to a project's exception card, now goes with the message, as on
  the web. Before, only the words were sent and the image stayed in the composer looking unsent. A send that
  fails hands the image back with the words.
- **iOS — Optimized prompt sheet:** as tall as its content, with a standard header, the gloss in your own
  language first, "Sent to the agent in English · Show" opening the prompt beneath, and Use / Edit full width at
  the bottom. The Mac card is unchanged.
- **Server — timed-out checks:** a check the platform stopped at its time limit says so on its open item ("at its
  4h limit after running 4h 0m") instead of "exited with code null", and its next step offers a rerun only with a
  reason. The owner's card over a timed-out promotion check says it must finish, not pass.

## Upgrade impact

- **Database migrations.** None since beta.20.
- **Runners.** No runner changes since beta.20. Runners on the beta channel move to 0.1.261-beta.21 once the
  server is deployed after this tag.
- **Server.** The timed-out check wording takes effect once the server is deployed from this tag or later.
- **Configuration.** No changes required.
- **Clients.** Each client builds from this tag: macOS beta users, TestFlight (marketing version 0.1.261,
  build number = commit count) and Android via `android-update.json` are offered it.

## Security fixes

None in this release.

## Known limitations

- A "Chat about this" reply on iOS and macOS still needs typed words; an image alone does not send from it,
  as on the web for a request.
- The image fix was checked by the OrbitKit wiring tests and by macOS and iOS simulator builds; it has not been
  run on a physical iPhone.

## Artifacts and verification

The release identity is `package.json` `0.1.261-beta.21` and tag `v0.1.261-beta.21`. This tag publishes the
macOS DMG and Sparkle payload (beta channel), the iOS TestFlight build, the runner binaries, and
`orbit-android-0.1.261-beta.21.apk` with its `.sha256` and `android-update.json` on the same GitHub Release.

## Rollback

Roll back to 0.1.261-beta.20. No migrations since then, so an application-only rollback is schema-safe.
Runners do not move back by themselves: roll them back with the `/api/runner/release` pointer. See
[Release process](../docs/release-process.md#rollback-decision-and-procedure).
