# Orbit 0.1.261-beta.101

## Summary

The Help Center is now readable in Simplified Chinese, and its Ask is answered by the server instead of by starting a session on one of the person's machines. The open coordinator question card wears the product's brand tone on web and Apple and now draws the pictures a coordinator attaches to it, and a sub-agent transcript that a page starts in the middle of stays in its card on web, macOS, iOS and Android.

- **Help Center: all 39 articles in Simplified Chinese, and a Language picker (f885b463d3, 44b8f9591b, b1d6dd7c45).** English stays the source in `docs/help/<category>/<slug>.md`; a translated copy ships beside it under `docs/help/<language>/<category>/<slug>.md` and carries only its title, summary and body, so its routes, errors, platforms and date stay the English article's and cannot drift. The three help doors take `?lang=<code>`, a language without a copy falls back to English article by article, and search segments a Chinese query into words. A Language picker in the help nav switches the list, articles and search between English and 中文; the choice is remembered in the browser and wins from then on, and without one a signed-in account whose Translation language the library has starts there. Only article content is localized — the help center's chrome stays English — and read time counts two Chinese characters as a word.

- **Help Center: Ask is answered on the server's DeepSeek key (75e10eea88, 4b0b2cee8b, 6ad6c314d3).** The drawer's Ask no longer picks a machine and engine to run on: a question goes to `POST /api/help/ask` and the server answers it with DeepSeek, from every article the person may read and the account reads (machines, sessions, tasks, quota). Conversations live in the new `help_ask_conversation` table (migration 1668); a follow-up, Your questions and Still stuck → Ask your admin keep working on it, and an answer that did not come says why. The Runs on routes (`GET /help/ask/choices`, `GET /help/ask/sessions`) are gone. Asks made before this release ran as sessions and keep their runner doors and fence, unchanged.

- **Server: translation keeps Orbit's own links whole (8fefaea9b8).** The translator's prompt asks it to keep URLs, but protection masked only `https?://`, so an attached mock written as `![Option A](orbit-attachment:354…)` could come back as prose with the id left where a person reads. Attachment, list, task, session, project, settings, wiki, drive and document links are now masked the way code is — an id can only come back whole, or the translation is refused and offered again — and the prompt says an image stays one picture with its alt text translated.

- **Web and Apple: an open coordinator question wears the brand tone (c56e6ca514).** Its heavier edge was the warning tone (`--warning-solid` on web, `.orange` on Apple) around a card whose surface, mark and action were brand blue, so it read as a warning frame. Both now draw the edge in the brand tone at the same 1.5px/1.5pt weight; the answered card is still the grey record. Android already drew the question in the brand tone and needed no change.

- **Web: the coordinator question card draws its attached pictures (e04ec12ecd).** The card's Markdown kept only Orbit's list/task/session/project/settings links, so an attachment arrived as an empty image source and the mocks a coordinator attached never appeared; a translated question could also flatten an image into the text "Option A: orbit-attachment:…". The card now reads the pictures from the question as asked, whatever the translation did to the words, removes their ids from the shown text and the collapsed summary, and draws them under the question as tiles that open the viewer: one at its own shape, two or more in a two-column grid (one column on a phone). The answered record keeps what it kept before.

- **Web, macOS, iOS and Android: a sub-agent card when the page starts mid-workflow (025c714e8a, 961416ac0c, 40b9ac7ceb).** A page loaded into the middle of a workflow left the agent's replies, steps and result at the top level: web drew the result as a raw JSON dump, Android drew the replies as the session's own and the result as a raw "Tool output" row, and Apple dropped a result whose call was not in the window, so the card stayed running after scrolling up. Web and Android now nest those events under a stand-in for the missing call, a result naming an unloaded call no longer attaches to whichever call is open, and Apple holds the result and matches it when the older page arrives, as top-level results already were.

- **Web: a failure toast has no buttons and leads to the problem (d2f5ff026f).** Copy error and the merge conflict's Resolve in session are gone (the session's merge bar still offers Resolve in session); a press on the card opens its session, or the route it was raised on, which the toast store now records. The page-failed card reloads on a press. A failure raised on the page already on screen has nowhere to go, so a stray press leaves it up for its ×.

- **Web: toasts, fields and buttons take the menus' rounder corners (43f857f91f, d38cf0b426, c3149a7fde).** A card toast has 18px corners and the menus' soft shadow, with 10px action buttons and error-reason block. Text fields, text areas, select fields and number fields are 10px (small 6px, large 12px), and buttons take the same; height, border, padding and the focus and error rings are unchanged, so no form moves.

- **Web: 157 more sites take the app's own Tooltip (5ce48770b4, 21d9204dd2).** Text tips open after 600 ms and on hover only, so a pointer crossing a list opens none, and a multi-line tip keeps its lines. Groups B and D of the tooltip review move from the browser's grey `title` bubble to the app's Tooltip — 157 of the 164 sites, with the 7 whose tip repeats the shown text left native, as group C and B-b are.

- **Web: a task session's header links its task, and the title's › stops reserving space (f0fb1754ab, 037cdcfded).** A task's session is named after its task, so the "← task" line above the title only repeated it; a Task › badge beside the title now opens the task, as a coordinator's project badge does, and the wide header is the title line alone. The hidden › and its gap kept about 17px empty after a long title, so the title stopped short of the Task or Coordinator badge beside it; it is now out of the layout until hover or focus.

- **Server: a coordinator's pre-start plan takes nothing from its 8 card-free creates (0b92d18eaf, 1466bb80d5).** The start card already reviews the tasks a coordinator filed into a project it coordinates, so counting them meant a coordinator that filed a plan of nine had its very next ordinary create carded. Those tasks are now left out of the count, and the `task_create` / `task_create_batch` descriptions say a coordinator's pre-start creates are never asked.

- **Docs and CI.** The API reference is regenerated after merging main (6ad6c314d3). The Model routing menu test now expects Help center above Settings, where 43d6998a37 moved it, so main's web suite is no longer red on it (faa6a986af). The boards behind this range are in `docs/mocks`: tooltip groups B and D, the coordinator question card's border conformance and its colour schemes, and the question card's attachments (d1f29e3287, 96ee841c83, 88dfb8ea09, 6967e01211, dc14bbba37).

## Upgrade impact

- **Migrations:** one, applied by the apiserver on boot.
  - `1668_help_ask_conversation` — **additive:** it creates the `help_ask_conversation` table (owner, title, page, messages, status, and the admin fields Still stuck writes once) with its owner index. It writes no row, changes no existing table, and drops nothing; a server one release older neither reads nor writes it. The foreign keys take SHARE ROW EXCLUSIVE on `user` and `task` for a moment, so the lock is taken in 2 s tries, 1 s apart, up to 45, and every statement is safe to run twice.
- **Backfill:** not a separate step. Asks made before this release (sessions with `help_ask` set and their hand-off rows) are left as they are.
- **Configuration:** none added. Help Center Ask uses `DEEPSEEK_API_KEY`, the server key already used for session title and tag enrichment; when it is empty, Ask answers that it is not available on this server and says an admin sets the key. Web Push and the other optional variables are unchanged.
- **Server:** the Help Center serves the translated library and takes `?lang=` on its three help doors; Ask's routes are `POST /help/ask`, `GET /help/ask/conversations`, `GET /help/ask/:id`, `POST /help/ask/:id/messages`, `GET /help/ask/:id/stuck` and `POST /help/ask/:id/admin`, and the Runs on routes are removed. The translation protection now masks Orbit's own links. A coordinator's pre-start tasks no longer count against its 8 card-free creates. Help articles ship with the apiserver (the library is read from `docs/help` at boot), so the Chinese library arrives with the server image, not a client build. No other route, field or payload changes shape or name.
- **Runners:** the runner served at `/dl` is built from this tag. This range has no runner behaviour change, so a runner older than this release behaves as it does today.
- **Clients:** web arrives with the deploy of this commit; macOS (beta-channel DMG), iOS (TestFlight) and Android (APK) come from this tag. macOS and iOS share the sub-agent fix in `OrbitKit`. An older client than this release keeps the amber open-question edge (Apple), does not draw the pictures a question attaches, keeps the failure toast's buttons, and does not hold a sub-agent result for a call that loads later.

## Security fixes

None in this release.

## Known limitations

- Help Center Ask needs `DEEPSEEK_API_KEY` on the server; while it is empty, Ask answers that it is not available. Ask conversations are the person's: deleting the person deletes them, and deleting the admin leaves the Ask sent with no admin.
- The Language picker localizes article content only; the help center's chrome, routes, error names and platform names stay English, as the article contract requires.
- A failure toast raised on the page already on screen has nowhere to go, so it stays until its × is pressed.
- Seven tooltip sites whose tip repeats the shown text keep the browser's `title`, and group C and B-b stay native by the owner's scope.
- A coordinator question asked before this release keeps what it had; the pictures are read from the question as asked, so an attached mock appears where the question carries it.

## Rollback

Previous tag v0.1.261-beta.100 (`97dab035f7f5dec31fdbb9de6ae5bfec7c2aa34c`). Application-only rollback is **schema-safe for this release**: 1668 only adds a table nothing older reads or writes, writes no row, and records no down-migration — leave the table in place.

Client rollback is to v0.1.261-beta.100's DMG, TestFlight build and `orbit-android-0.1.261-beta.100.apk`; a beta.100 client keeps working against this release's server, since no payload it reads changes shape, and it lacks the new cards and copy. One thing a rollback must keep together: the help Ask routes changed — the Runs on routes are gone — so a deployment must run the web bundle and the apiserver of the same commit; an older web bundle pointed at this server loses Ask, and this server's web loses it against an older one.
