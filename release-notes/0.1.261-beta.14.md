# Orbit 0.1.261-beta.14

## Summary

Changes since [0.1.261-beta.13](0.1.261-beta.13.md), on the beta channel.

- **Prompt optimizer is on by default** on every client. Only an explicit off in Settings turns it off; a
  server without a DeepSeek key still offers nothing. With Translation on, an unedited optimized prompt is
  sent with its agent-language version, so no translator call is needed.
- **A refused engine-account removal names the sessions in the way.** The runner reports which sessions
  still use the account, and the runner page (web, Mac/iOS, Android) lists them with Open session, instead
  of a generic "in use by a session".
- **Guests see a shared session's images** on web, Mac/iOS and Android.
- **SubAgents:** `provider_list --workspace` says which provider × engine pairs a remote delegate could run
  there and why not; resuming a remote SubAgent run is refused with a clear reason; the runner sweeps the
  SubAgent records of sessions that are over.
- **Managed runners:** with `ORBIT_MANAGED_RUNNERS_ENABLED` on, every signed-in account gets its managed
  runner, including sessions that signed in before the switch.
- **Open items:** "Ask the coordinator again" and "Chat about this" agree on whether the coordinator can be
  reached.
- **Transcript:** a guest's or Feishu member's message no longer draws an "Orbit attached: sender note" line.

## Upgrade impact

- **Database migrations.** One: `0870_account_remove_sessions` adds `runner.codex_account_remove_sessions`
  (`UUID[]`, default empty). Backward compatible; an older apiserver neither reads nor writes it.
- **Runners.** Runners on the beta channel move to 0.1.261-beta.14 once the server is deployed after this
  tag. This release changes the runner (account-removal report, SubAgent record sweep, remote resume refusal).
  Older runners keep working; the page falls back to the runner's own message.
- **Server.** The prompt-optimizer default, provider_list `workspace`, managed-runner backfill and open-item
  reach changes take effect when the server is deployed.
- **Configuration.** No changes required.
- **Clients.** Each client builds from this tag: macOS beta users, TestFlight (marketing version 0.1.261,
  build number = commit count) and Android via `android-update.json` are offered it.

## Security fixes

None in this release.

## Known limitations

- The iOS ☰ count badge fix (8094f1c21) was reverted before this tag: it shifted the drawer button 10pt and
  the title 20pt right. The badge is drawn as in beta.13, clipped at the button's edge on iOS 26.
- The Swift side of the account-removal list was not run on a Swift toolchain when it landed.

## Artifacts and verification

The release identity is `package.json` `0.1.261-beta.14` and tag `v0.1.261-beta.14`. This tag publishes the
macOS DMG and Sparkle payload (beta channel), the iOS TestFlight build, the runner binaries, and
`orbit-android-0.1.261-beta.14.apk` with its `.sha256` and `android-update.json` on the same GitHub Release.
Each change landed with its own tests; the release run's macOS, iOS and Android builds compile this tag.

## Rollback

Roll back to 0.1.261-beta.13. Migration 0870 only adds a defaulted column that beta.13 ignores, so an
application-only rollback is schema-safe. Runners do not move back by themselves: roll them back with the
`/api/runner/release` pointer. See
[Release process](../docs/release-process.md#rollback-decision-and-procedure).
