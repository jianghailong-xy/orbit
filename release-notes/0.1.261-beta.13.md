# Orbit 0.1.261-beta.13

## Summary

Two fixes on top of [0.1.261-beta.12](0.1.261-beta.12.md), on the beta channel.

- **Runner: removing one secret no longer holds up delivering another.** When a secret a runner held was
  removed, the runner scanned every session checkout for its value before it would fetch or acknowledge any
  other secret. On a busy runner with hundreds of checkouts that took over an hour, and an owner's newly
  submitted key sat on "Key is on its way" the whole time. The value now leaves the runner at once, the scan
  runs in the background, and the removal is reported to the server when the scan ends. The scan also reads
  only the files that differ from their committed version (plus assume-unchanged and skip-worktree entries)
  instead of every file of every checkout.
- **SubAgents: remote delegates run what was asked for, and move on login failures.** A remote delegate that
  names a model runs it on the target runner, or is refused at once with `SUBAGENT_TARGET_CANNOT_RUN` listing
  what that workspace can run. Without a model, an engine the target runner reports uninstalled, signed out,
  over quota or blocked is skipped, and the skip is recorded. A login failure (Failed to authenticate, Not
  logged in, OAuth session expired) now moves the run to a fallback like a limit failure does, at most twice;
  a model the caller named is never moved.

## Upgrade impact

- **Database migrations.** None.
- **Runners.** Runners on the beta channel move to 0.1.261-beta.13 once the server is deployed after this tag
  (`/dl` serves the newest tag at deploy time). This release changes the runner (secret removal, SubAgent fallback on login failures).
- **Server.** The SubAgent routing change is in the apiserver and takes effect when the server is deployed.
- **Configuration.** No changes required.
- **Clients.** No client changes. Each client still builds from this tag: macOS beta users, TestFlight
  (marketing version 0.1.261, build number = commit count) and Android via `android-update.json` are offered it.

## Security fixes

None in this release.

## Known limitations

- While a removal scan is running, that runner refuses merges and pushes (the secret-taint record fails
  closed), so a slow scan now delays publishing instead of key delivery. The narrower scan keeps that window
  short, but its speed-up on a runner with hundreds of checkouts was not measured before this tag.

## Artifacts and verification

The release identity is `package.json` `0.1.261-beta.13` and tag `v0.1.261-beta.13`. This tag publishes the
macOS DMG and Sparkle payload (beta channel), the iOS TestFlight build, the runner binaries, and
`orbit-android-0.1.261-beta.13.apk` with its `.sha256` and `android-update.json` on the same GitHub Release.

The runner fix (`ecc8d5bc0`) passed its secret, taint and removal tests, including
`TestSecretRemovalScanDoesNotHoldUpDelivery` under `-race`. The landed `src/runner-go` builds and passes
`go vet`. The fix's own full runner-go run had two failures in link and wiki connection tests outside the
secret code, at a host load of about 128.

## Rollback

Roll back to 0.1.261-beta.12. This release has no migrations, so an application-only rollback is schema-safe.
Runners do not move back by themselves: roll them back with the `/api/runner/release` pointer. See
[Release process](../docs/release-process.md#rollback-decision-and-procedure).
