# Orbit 0.1.261-beta.17

## Summary

- **Mac/iOS: a message waiting for a full runner says so.** A message the server has accepted but no
  runner has picked up reads "Queued · runner full" (or "Queued · runner updating") under its bubble,
  in place of "Sending…", as web does. Tapping the reason explains the wait.
- **Mac/iOS: a send goes where the server put it.** A message the server queues behind another turn
  moves to the tray above the composer as "Queued for next turn", with Withdraw, instead of sitting
  in the conversation on "Sending…". A message waiting only for its translation stays in the
  conversation.
- **Runner: switching an idle session to another account frees the old account.** The switch now
  moves the conversation (Claude, Kimi, Codex's thread; Antigravity records the switch) right away,
  so the account it left can be removed without another turn first. The refusal to remove an account
  in use now says first how to keep its sessions: switch them to another account, or end them (web,
  Mac/iOS, Android).

## Upgrade impact

- **Database migrations.** None.
- **Runners.** This release changes the runner (the idle account switch). Runners on the beta channel
  move to 0.1.261-beta.17 once the server is deployed after this tag.
- **Server.** No server changes. The web wording for an account in use ships with the web image.
- **Configuration.** No changes required.
- **Clients.** Each client builds from this tag: macOS beta users, TestFlight (marketing version
  0.1.261, build number = commit count) and Android via `android-update.json` are offered it.

## Security fixes

None in this release.

## Known limitations

- The iOS ☰ count badge fix stays reverted: on iOS 26 the badge is still clipped at the drawer
  button's edge.
- Client CI's navigation check fails on `ProjectsView.swift:138` (a stored project selection). It is a
  code-structure check, not a build failure, and is not fixed in this release.

## Artifacts and verification

The release identity is `package.json` `0.1.261-beta.17` and tag `v0.1.261-beta.17`. This tag publishes
the macOS DMG and Sparkle payload (beta channel), the iOS TestFlight build, the runner binaries, and
`orbit-android-0.1.261-beta.17.apk` with its `.sha256` and `android-update.json` on the same GitHub
Release. The runner change landed with its Go tests. The Mac/iOS queued-message change landed with new
OrbitKit tests (send placement, translation hold, the runner-full tag's target), but was not compiled
before this tag: the release run's `dmg` and `testflight` builds are its first compile.

## Rollback

Roll back to 0.1.261-beta.16. No migrations, so an application-only rollback is schema-safe. Runners do
not move back by themselves: roll them back with the `/api/runner/release` pointer. See
[Release process](../docs/release-process.md#rollback-decision-and-procedure).
