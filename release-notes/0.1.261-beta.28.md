# Orbit 0.1.261-beta.28

## Summary

- **Removing a secret no longer freezes every merge and every diff while the removal scans.** The merge/push
  guard now reads what it would publish against the removed values still pending in memory — held by the removal
  scan — instead of refusing everything until the scan ends. A commit that carries a removed value is still
  refused, but other merges go through during the scan. A turn ending during a scan waits up to 30 seconds for
  it, and a diff that is still withheld says why. The secret-file warning now logs its real reason: "holds a
  secret's value" only when there is a match. The scan reads four checkouts at a time, and a multi-line secret's
  lines become patterns only when, trimmed, they are distinctive.
- **The web, Mac, iPhone and Android clients are unchanged in this release.** Each builds from the same source
  as v0.1.261-beta.27.

## Upgrade impact

- **Database migrations:** none. There are no migration files between v0.1.261-beta.27 and this tag.
- **Configuration:** nothing to change.
- **Server:** the change is in the Go runner only; no apiserver change is in this release, so no server upgrade
  is needed for it.
- **Runner:** the runner served at `/dl` is built from this tag, so runners update to it and take the fix above.
- **Clients:** each client builds from this tag, unchanged from v0.1.261-beta.27. macOS beta users, TestFlight
  (marketing version 0.1.261, build number = commit count) and Android via `android-update.json` are offered it.

## Security fixes

None in this release. The secret guard stays in force: a commit that holds a removed value is still refused.

## Known limitations

- A turn that ends while a removal scan is running waits up to 30 seconds for it; until the scan finishes a diff
  can still be withheld, though it now says why.

## Artifacts and verification

The macOS DMG and Sparkle appcast, an iOS TestFlight build, and the Android APK with `android-update.json`, all
from this tag; the runner served at `/dl` is built from it as well. The runner change was reviewed before it
merged: its new tests in `src/runner-go/secret_removal_scan_test.go` and every existing secret and taint test
(68 in all) were re-run on the fix commit and passed. The run that wrote it reports that the full runner suite
(`go test -timeout 60m .`) passed too. It was not exercised on a live runner, so how long a removal scan takes
over hundreds of checkouts is not measured. Beyond that, verification rests on `release.yml`'s identity gate
and its macOS, iOS and Android build jobs.

## Rollback

The previous tag is v0.1.261-beta.27, commit 2002e92c1. No migration separates the two, so a client or server
rollback to it is schema-safe. A runner rolled back to it loses the merge-and-diff fix above.
