# Orbit 0.1.261-beta.63

## Summary

This release is a single Android change, not a new feature. **Every card in an Android conversation now draws at one
width — 720 dp, the web's `--chat-card-max` and OrbitKit's `ConversationCardWidth.max`** (`4e37f831e6`,
`837103c01a`, `00d6a0496a`); it follows the one-width conversation card iOS and web already shipped (`f97139e742`,
`cea912823`, both before beta.62). Cards that filled the column or were uncapped — rail decisions, owner requests,
crossings, schedule, repair/auto-retry/main-checkout/error cards, run-start, tasks, machine setup, handoff and the
created-workspace card — now end on one line on a wide column. A phone is narrower, so nothing changes there. This
release carries **no database migration**, no server or web source change, and no runner change.

## Upgrade impact

- **Database migrations: none.** No file under `src/apiserver/prisma/migrations/` changes in this range, so the
  schema this release needs is the one beta.62 already carried through `1270_receipt_source_sha_task_updated_idx`.
  Nothing is applied on boot and no migration is additive or destructive here, because there is no migration.
- **Configuration: nothing to fill in.** No new `ORBIT_*` variable is read and no `.env` edit is needed.
- **Server and web: no change.** Every file this range touches is under `src/android/`, so the apiserver and web an
  instance runs are beta.62's; upgrading to this tag changes nothing on the server side beyond the version lines.
- **Clients:** macOS beta users get the DMG and Sparkle appcast from this tag on the beta channel; TestFlight gets
  marketing version 0.1.261, with the build number as the commit count; Android gets `versionName` `0.1.261-beta.63`,
  the next `versionCode` and `android-update.json` from this tag. No minimum client version is enforced, and no
  one-time step is required on a Mac, iPhone or Android device. The macOS and iOS source is unchanged in this range, so
  those builds differ from beta.62 only by their version.
- **Runner:** `src/runner-go/` does not change in this range. **The runner served at `/dl` is built from this tag**, so
  a runner fetched from it carries the same runner code beta.62's tag had; an older runner keeps working with this
  server unchanged.

## Security fixes

None in this release. No commit in this range names a security fix, an advisory or a CVE.

## Known limitations

- **The one-width change is Android only, and applies only to cards inside a conversation.** Prose, tool output and
  code are not cards and keep the column; cards on the project page and in sheets are not in a conversation, so they
  are unaffected (`4e37f831e6`). On a phone the column is already narrower than 720 dp, so every card still fills it —
  the commit states nothing changes there.

## Artifacts and verification

The tag is v0.1.261-beta.63, and this file is in its tree. The release commit, which the tag names, sets the version
lines in `package.json` and `package-lock.json` and carries these notes on top of `origin/main`
`d409eefdddc96d92e741d3e299d6a2114445dabb`. The release publishes the macOS DMG and Sparkle appcast (beta channel),

measurement, and the merge commit `d409eefddd` records none either.

## Rollback

The previous tag is v0.1.261-beta.62, commit `3fc0234787a13026e12a90a3c300fbeb2bf4b108` (its tag object is
`c815f471d63d2e723bb5965b7030ba7f6db8d602`), the `chore(release): prepare 0.1.261-beta.62` commit. A server deployed
from this tag rolls back to that commit; the native clients roll back by installing beta.62's build from its tag.

An application-only rollback to beta.62 is schema-safe: this release carries no migration, so both releases expect the
same schema (through `1270_receipt_source_sha_task_updated_idx`). No backup or restore step is needed. See
[Release process](../docs/release-process.md#rollback-decision-and-procedure).

Rolling back to beta.62 reverts the commits in this range: on a wide screen, Android conversation cards that filled the
column or were uncapped return to that behavior, and the one-width constant and its tests are removed. No other code in
this range changes.
