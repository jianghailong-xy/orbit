# Orbit 0.1.261-beta.19

## Summary

Changes since [0.1.261-beta.16](0.1.261-beta.16.md), the last beta that published (beta.17 and beta.18 did
not; see Known limitations).

- **iOS 26: the ☰ waiting count is the system's toolbar badge** — red, drawn whole outside the bar's glass,
  instead of an orange count clipped by the button's circle and washed out by the glass.
- **Android: Scheduled** in the drawer, its timeline, detail sheet and quick-add line, schedule cards in a
  conversation and in Waiting on you.
- **Setup card:** the Folder step is one folder name in the machine's home.
- **Fix with an agent** under a failed Update Engines Now report on iOS and Android.
- **Composer:** Tab takes the optimized prompt (web and Mac).
- **Runner:** an engine account frees up once its sessions are switched away; a background Agent's end is
  reported under its launch call.
- **Session rows:** a background process no longer takes a row's recap; rows draw a clock when queued and a
  still terminal for a left-up process (iOS, Android).
- **Apple:** a message held by a full runner says so and is filed where the server placed it; a transcript
  seeded by the stream's replay keeps its older edge.
- **Web:** a new session's opening held for translation draws once; the decision strip points at a
  coordinator's open question; account menu submenu rows match the menu's height.

## Upgrade impact

- **Database migrations.** None since beta.16.
- **Runners.** Runners on the beta channel move to 0.1.261-beta.19 once the server is deployed after this
  tag. This release changes the runner (account release after a switch, background Agent end reports).
- **Server.** The server-side changes take effect when the server is deployed.
- **Configuration.** No changes required.
- **Clients.** Each client builds from this tag: macOS beta users, TestFlight (marketing version 0.1.261,
  build number = commit count) and Android via `android-update.json` are offered it.

## Security fixes

None in this release.

## Known limitations

- beta.17 and beta.18 did not publish (their Android release jobs failed or were cancelled); their TestFlight
  builds uploaded. This release supersedes both.
- The iOS 26 badge's look on a real device was checked only in the simulator, which does not render the
  glass's tinting. With the system badge, VoiceOver reads the count alone ("2") rather than "2 waiting on you".

## Artifacts and verification

The release identity is `package.json` `0.1.261-beta.19` and tag `v0.1.261-beta.19`. This tag publishes the
macOS DMG and Sparkle payload (beta channel), the iOS TestFlight build, the runner binaries, and
`orbit-android-0.1.261-beta.19.apk` with its `.sha256` and `android-update.json` on the same GitHub Release.
The badge change built for macOS and the iOS simulator and was photographed on an iPhone 17 Pro Max
simulator (iOS 26.5); main's Android CI passed on c8303ac0a.

## Rollback

Roll back to 0.1.261-beta.16. No migrations since then, so an application-only rollback is schema-safe.
Runners do not move back by themselves: roll them back with the `/api/runner/release` pointer. See
[Release process](../docs/release-process.md#rollback-decision-and-procedure).
