# Orbit 0.1.261-beta.85

## Summary

- **SubAgents run in their parent session's permission mode, on every engine.** A read-only SubAgent (`type: explore`, or a definition with `readonly: true`) on Kimi, Cursor, DeepSeek Harness, OpenCode or Antigravity used to be put in Plan. Depending on the engine, it then filed an approval card for every command, refused every command, or, on DeepSeek Harness, was refused before it started. Now it keeps its engine's own read-only setup (its edit tools stay off), and what it asks is answered the way the parent's mode answers it:
  - Under an Auto or Bypass parent it runs with no card.
  - Under Don't Ask it is refused.
  - Under any other mode it gets the card the parent would.
  - Its edits are refused in every mode.

  A SubAgent delegated to another workspace now gets its parent's mode too; before, only the mode it was claimed in reached that runner. An engine that cannot run the parent's mode now gets the nearest mode it can run that is not wider, instead of a refusal (DeepSeek Harness: Plan → Don't Ask, Accept Edits → Default, Bypass → Auto; Cursor: Default → Plan).

This is the release's only change; everything else is as in 0.1.261-beta.84.

## Upgrade impact

- **Migrations:** none. No migration is added or changed in this release.
- **Server:** a remote SubAgent's claim gains `parentPermissionMode`. Runners from before this release ignore it and read the child's own mode, as before.
- **Runners:** the read-only handling is in the runner. A self-hosted runner gets it by updating to the runner served at `/dl`, which is built from this tag. Orbit Cloud runners get it from the `orbit-cloud-runner:0.1.261-beta.85` image, which is built from this tag. Until a runner is updated, its read-only SubAgents on engines other than Claude and Codex keep running in Plan.
- **Clients:** no client step is needed. The web, macOS, iOS and Android builds change only in their version.

## Security fixes

None in this release.

## Known limitations

- Under an Auto or Bypass parent, a read-only SubAgent on Kimi, Cursor, DeepSeek Harness, OpenCode or Antigravity is read-only only through its disabled edit tools and its instructions. The runner does not check each shell command, so a command that writes files still runs. Only Claude (edit tools removed) and Codex (its read-only sandbox) enforce read-only below the shell. Anyone who needs a hard guarantee should delegate read-only work to Claude or Codex.
- OpenCode and Antigravity take the parent's mode when the SubAgent starts. A change to the parent's mode while the SubAgent runs reaches Kimi, Cursor and DeepSeek Harness SubAgents but not these two.
- A SubAgent that is not read-only and inherits Auto on Kimi, OpenCode or Antigravity runs as Bypass on that engine, as these engines' Auto does for a session.

## Rollback

Previous tag v0.1.261-beta.84 (`3773282f5e`). No schema change, so rolling back the application is schema-safe. Clients roll back by installing beta.84's builds. A deploy of a commit before this tag points Orbit Cloud runners back at the beta.84 image, and each moves to it once idle.
