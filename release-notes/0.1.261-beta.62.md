# Orbit 0.1.261-beta.62

## Summary

This release is a small polish pass between two feature releases, not a new feature. An operator will notice
three things: **every card in a macOS/iOS conversation now draws at one width — 720 pt, the web's
`--chat-card-max`** (`f3605f6078`, `579afe5e80`, `84256af896`, `c18a9528a4`); **the SubAgent router reads
Antigravity's quota where its runner reports it**, instead of ranking a reporting Antigravity after every engine
whose quota it could read (`57bf4d7b35`); and **the Prisma config's `effect` dependency is patched for
GHSA-7589-6fvf-x4pw** (`0cee080104`). The web project row's ⋯ menu gets icons on every item so the labels line
up (`ce2ac99323`), Android's composer card gets a lighter light-mode shadow measured against an iPhone
(`f0655a5636`), and the rest of the range is test, build and documentation fixes. This release carries **no
database migration** and no runner change.

## Upgrade impact

- **Database migrations: none.** No file under `src/apiserver/prisma/migrations/` changes in this range, so the
  schema this release needs is the one beta.61 already carried through `1270_receipt_source_sha_task_updated_idx`.
  Nothing is applied on boot and no migration is additive or destructive here, because there is no migration.
- **Configuration: nothing to fill in.** No new `ORBIT_*` variable is read and no `.env` edit is needed. The
  `scripts/npm-audit-allowlist.json` entry for `picomatch` (GHSA-fc5q-39xc-vjpf) is removed because `npm audit`
  no longer reports that advisory (`0cee080104`); that is a repository file, not deployment configuration.
- **Server and web:** the router fix (`57bf4d7b35`) and the project-row menu icons (`ce2ac99323`) are apiserver
  and web source changes; each reaches an instance only when it is upgraded from this source — tagging does not
  deploy the server or rebuild web.
- **Clients:** macOS beta users get the DMG and Sparkle appcast from this tag on the beta channel; TestFlight gets
  marketing version 0.1.261, with the build number as the commit count; Android gets `versionName`
  `0.1.261-beta.62` and `android-update.json` from this tag. No minimum client version is enforced, and no
  one-time step is required on a Mac, iPhone or Android device.
- **Runner:** `src/runner-go/` does not change in this range. **The runner served at `/dl` is built from this
  tag**, so a runner fetched from it carries the same runner code beta.61's tag had; an older runner keeps
  working with this server unchanged.

## Security fixes

- **GHSA-7589-6fvf-x4pw: the Prisma config's `effect` dependency is patched (`0cee080104`).** Prisma config pins
  an Effect release affected by this advisory; the commit scopes a `3.22.1` override to `@prisma/config` in
  `package.json` and refreshes its lock entry, moving `node_modules/effect` from `3.20.0` to `3.22.1` (the
  lockfile marks it `devOptional`). An instance built from an earlier tag still pins `3.20.0` and carries the
  advisory; this release is the fix. The commit does not state the advisory's reachability beyond naming it, and
  it records no test or audit run beyond saying the audit no longer reports the `picomatch` advisory that its
  now-removed allowlist entry had accepted.

No other commit in this range names a security fix, an advisory or a CVE.

## Known limitations

- **A Cursor account's quota is still read as unknown, by design.** `57bf4d7b35` folds Antigravity's buckets in
  from the runner's engine health; the same commit says Cursor reports no usage share for an account it does not
  count (`dto.ts` `percentUsed`), so a Cursor account still ranks with its quota unknown versus an engine whose
  quota can be read.
- **The one-width conversation card is macOS/iOS only in this range.** Web already drew its cards at
  `--chat-card-max` (beta.61, `cea9128233`), and no Android commit in this range changes card widths; Android keeps its
  earlier widths.
- **The lighter composer-card shadow is light mode only.** `f0655a5636` changes the light-mode shadow; dark
  keeps no shadow, as before (iOS shows none on black).

## Artifacts and verification

The tag is v0.1.261-beta.62, and this file is in its tree. The release commit, which the tag names, sets the
version lines in `package.json` and `package-lock.json` and carries these notes on top of `origin/main`
`32e553e8226e7a15109772ccfecb71f587d6edc0`. The release publishes the macOS DMG and Sparkle appcast (beta
channel), an iOS TestFlight build, and the Android APK with its `.sha256` and `android-update.json` on the same
GitHub Release, all from this tag. **The runner served at `/dl` is built from this tag.** This release's own
`release.yml` run is the build of record: link it here only once it has finished.

The checks a commit message records in this range are few. `2c88095685` records three runs in a row (light,
light, dark) of the Android session-page journey, each capturing the composer and no reconnect line.
`f0655a5636` records a measurement rather than a test run: the composer card's light-mode shadow now spreads
about 55px and reaches `#f8` over the page, against an iPhone 17 Pro's 50px and `#f7` (it was 90px and `#f5`).
`0cee080104` records that the audit no longer reports GHSA-fc5q-39xc-vjpf. `c18a9528a4` says
`ConversationCardWidth` builds on Linux (it swapped `CoreGraphics` for `Foundation`) but records no run.

Every other commit in this range records no run or measurement: the Apple card-width changes (`f3605f6078`,
`579afe5e80`, `84256af896`), the router fix (`57bf4d7b35`), the web menu icons (`ce2ac99323`), and the test-only
commits (`32e553e822`, `4eabdf0cc7`, `f4b1ff82a2`, `09f13dcd9d`).

## Rollback

The previous tag is v0.1.261-beta.61, commit `e17f9d65f76b4bfb5de385d69b1e71fa8ad16d5b` (its tag object is
`89b0c2804eddb3faaf7cccb8beda70abc34c5f09`), the `chore(release): prepare 0.1.261-beta.61` commit. A server
deployed from this tag rolls back to that commit; the native clients roll back by installing beta.61's build from
its tag.

An application-only rollback to beta.61 is schema-safe: this release carries no migration, so both releases
expect the same schema (through `1270_receipt_source_sha_task_updated_idx`). No backup or restore step is
needed. See [Release process](../docs/release-process.md#rollback-decision-and-procedure).

Rolling back to beta.61 reverts the commits in this range: the macOS/iOS conversation cards return to their
earlier widths (720 for several cards, 620 for the machine setup card, the full column for answered questions,
the settled-fold row and session replies), Android's composer shadow returns to alpha 0.065 and 28dp blur, the
web project row's ⋯ menu loses the icons on all but Complete, Antigravity's quota reads as unknown again, and
the Effect override returns to `3.20.0`, bringing GHSA-7589-6fvf-x4pw and the `picomatch` allowlist entry back.
