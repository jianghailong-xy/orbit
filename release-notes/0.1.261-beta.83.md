# Orbit 0.1.261-beta.83

## Summary

- **Orbit Cloud: new version and Update Now.** An Orbit Cloud runner now shows its release version and an Update card when a newer one is out. Update Now restarts it on the new image, and a running turn continues after the restart.
- **Session list.** Rows are ordered by what changed for you, grouped into Pinned, Needs you and Working, so background activity no longer moves them.
- **Clearer states.** Sessions read Finished, On hold, Ended or Interrupted on web, iOS/macOS and Android.
- **Failed landings go back to the task.** A landing whose check fails is handed to the task's own session to fix, and web, Apple and Android show where it stands.
- **Composer + menu.** Upload File, Upload Image and Add from Orbit Files, in one menu.
- **Monitoring for self-hosters**, on by default: Grafana on loopback, alerts, container logs and metrics.

## Upgrade impact

- **Migrations:** 1441, 1442, 1490 and 1537 are additive. 1443 and 1444 drop an unused column and index, which is safe from v0.1.261-beta.82 on.
- **Self-hosted:** the monitoring profile turns on with the upgrade. `ORBIT_WATCHDOG_URL` is renamed `ORBIT_ALERT_HEARTBEAT_URL`.
- **Runners:** the runner at `/dl` and the Orbit Cloud runner image (`orbit-cloud-runner:0.1.261-beta.83`) are built from this tag. No client step is needed.

## Security fixes

None in this release.

## Known limitations

- Update Now on a busy runner cuts the running turn at the restart, and the turn then continues on the new runner.
- Loki stops taking log lines while its disk is 90% full.

## Artifacts and verification

Tag v0.1.261-beta.83, the release commit on `main` after `9a46e8d89c`. `release.yml` publishes the macOS DMG (beta channel), an iOS TestFlight build, the Android APK, and the runner binaries with SHA256SUMS, SBOM and provenance. The Orbit Cloud runner image is published from this tag on the build host. The commits record PostgreSQL and OrbitKit test runs. No release build had run when these notes were written.

## Rollback

Previous tag v0.1.261-beta.82 (`b0e1af01e6`). Rolling back the application is schema-safe. Clients roll back by installing beta.82's builds. Orbit Cloud runners keep the beta.83 image after a rollback, because beta.82 has no release-built image.
