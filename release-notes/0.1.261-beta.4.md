# Orbit 0.1.261-beta.4

## Summary

The work merged since [0.1.261-beta.3](0.1.261-beta.3.md), on the beta channel.

- **SubAgent: read-only SubAgents work on Codex.** A read-only SubAgent (the built-in `explore` type, or a
  definition marked read-only) that Orbit routes to Codex used to run in plan mode, which on Codex refuses
  every command; since Codex reads the repository through its shell, it came back with nothing. It now
  runs under Codex's own read-only sandbox with no network: it can list, read and search the worktree,
  and any write fails. A session's own plan mode is unchanged. A cross-workspace SubAgent's result now
  names the model it ran on instead of an empty string.
- **Scheduled tasks (S1)**: the scheduled-task model and its envelope rule on the server.
- **OrbitKit**: the copy-parity and clock tests are restored on main.
- **CI**: an accessibility-snapshot race no longer decides the macOS runtime crash gate.

## Upgrade impact

- **Runners.** Runners on the beta channel move to 0.1.261-beta.4 and pick up the read-only SubAgent fix.
  A runner on 0.1.261-beta.3 keeps working; its read-only SubAgents on Codex still return nothing.
- **Clients.** macOS users who enabled "Receive beta updates" get this build. iOS ships to TestFlight
  (marketing 0.1.261, build number = commit count). Android offers the APK to every install via
  `android-update.json`.
- **Database migrations.** Added since 0.1.261-beta.3: `0790_schedules` (the scheduled-task tables).
  Applied by the apiserver on boot.
- **Configuration.** No changes required.

## Security fixes

None in this release. The read-only SubAgent change keeps a read-only child unable to write: Codex's
read-only sandbox refuses writes, and escalations, file changes and third-party MCP tools that reach
Orbit are refused.

## Known limitations

- The known limitations of [0.1.261-beta.3](0.1.261-beta.3.md) still apply.

## Artifacts and verification

The release identity is `package.json` `0.1.261-beta.4` and tag `v0.1.261-beta.4`; `release.yml`'s
identity job refuses a tag whose name and package version disagree or whose notes are missing. This tag
publishes the macOS DMG and Sparkle payload (beta channel), the iOS TestFlight build, the runner
reference binaries, and `orbit-android-0.1.261-beta.4.apk` with its `.sha256` and
`android-update.json` on the same GitHub Release. The read-only SubAgent fix passed the full runner-go
suite, and a real codex 0.169 child that lists and greps the worktree while its writes fail and the
worktree stays byte for byte unchanged.

## Rollback

Roll back to 0.1.261-beta.3. `0790_schedules` only adds tables, so an application-only rollback is
schema-safe. Runners do not move back by themselves: roll them back with the `/api/runner/release`
pointer. See [Release process](../docs/release-process.md#rollback-decision-and-procedure).
